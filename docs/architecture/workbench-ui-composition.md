# Workbench 界面组合合同

> 状态：当前合同
> 适用版本：6.4.0 未发布开发分支
> 最后核验：2026-09-06

本文件是 ARCH-003 的当前拆分合同，不是新的功能计划。2026-09-06 用户将交付断点调整到整体架构拆分完成；内部可以分组验证与本地提交，不能在单个模块迁出后当作整体完成交付。版本保持 6.4.0，不推送、不发布。

## 完成条件

主入口仅组合明确类型的控制器、现有状态权威与页面区域。仪器动作、教学计时、模式切换、快照采集、文件历史以及各实验的具体渲染分别有可追踪的模块所有者。不能以新增一个同样庞大的控制器或数百字段的通用上下文代替职责拆分；不能仅以入口行数减少判定完成。

## 边界与方向

| 职责 | 输入与所有权 | 输出与允许副作用 |
| --- | --- | --- |
| 启动恢复 | 现有会话、模式存储、教程恢复数据 | 初始化文件与 UI，保持原规范化顺序 |
| 文件与参数动作 | 读取当前文件集合、显式运行时和保存端口 | 通过现有提交入口更新文件，保留命名和参数交互 |
| 历史与窗口动作 | 历史栈、当前文件及布局投影 | 按原顺序捕获、更新、撤销、重做 |
| 保存与恢复 | 延迟读取当前权威、模式检查点、刷新会话 | 单一调度器；刷新、退出和切换保留原时钟锚点 |
| 绝热膨胀控制器 | 现有物理运行时、教学状态和模式协调器 | 仪器动作、教学计时、场景恢复；不另建物理或模式权威 |
| 活塞控制器 | 现有会话、曲线和教学流程 | 仪器动作、主周期采集及精确计算接线；不改变算法 |
| 布局与临时交互 | DOM、拖动、焦点和打开状态 | 原动画及窗口临时状态；不写领域模型 |
| 只读呈现与视图 | 显式只读数据与回调 | 文案、几何、面板与分实验组件；不直接写持久化 |
| 外壳组合 | 上述有界接口 | 顶层窗口、区域布局和控制器接线 |

只读计算模块不依赖 React、DOM 或保存实现；DOM 测量与纯几何分开。视图通过回调调用动作，不能借全局事件或可变单例绕过所有者。运行时资源由单一生命周期释放，不能因拆分重复创建计时器或逐帧持久化。

## 不变合同

- 文件集合仍是当前工作区权威；历史只按原 scope 捕获文件、工作区或布局。
- 窗口关闭先捕获布局；窗口更新仍在更新器内读取最新文件并重新规划。
- 文件切换保留旧模式暂停和保存、新模式激活及目标检查点保存的顺序。
- 未提供检查点与显式空检查点具有不同语义。等待场景恢复时保留原模式存储及刷新时间锚点。
- 桌面退出冻结后的迟到回调、旧文件回调与替换后的计时器仍被拒绝；恢复只执行一次。
- 活塞按用户可见且已舍入的数据逐步计算，严格相等判断。最少两个主周期和局部小峰过滤保持不变。
- 主曲线、物理步进、采样频率、撤销容量、文件持久化格式及版本号保持不变。

## 验证

每个内部检查点运行相关直接测试、严格 TypeScript、全量测试和生产构建，随后在固定 5174 端口检查实际界面。测试应导入真实动作工厂或纯函数；确需源码合同的测试分别读取真实所有者并检查入口接线，不能拼接整个目录来掩盖职责位置。

整体交付前复查文件切换、模型加载、模式切换、参数调整、菜单与窗口、撤销/重做、刷新恢复、桌面退出防护及活塞精确计算。性能在独立新浏览器上下文中串行比较，测量时不并发类型检查、测试或构建；记录偶发长帧及证据边界，不将其解释为物理标定问题。
