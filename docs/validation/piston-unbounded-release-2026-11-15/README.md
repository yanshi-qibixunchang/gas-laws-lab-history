# 松手不同步：取消附加损耗上限

用户已确认：只取消 0.15 s 封顶，保留 0.06 s 正常操作容差。正常空气与氦气的其他参数保持原值。

## 本次模型

令 x = (|松手时间差| − 0.06 s) / (0.15 s − 0.06 s)。小时间差仍用既有的平滑增长关系；x > 1 时，附加损耗强度系数继续按 x 增长，不再固定为 1。原来的 3 N·s/m 变为参考时间差处的初始附加阻尼，不再是大时间差的最大阻尼。阻力仍施加在运动方程中，并随释放后的时间衰减。

该延伸为软件的现象模型，并非从本装置大时间差实测压强曲线拟合所得。当前仍是一维时变阻尼模型，没有新增倾斜自由度或粘滑接触方程；可以产生少峰或接近不往复的回弹过程，不能据此声称复现了实物所有怪异峰形。没有人为添加随机波峰或剪短曲线。

大初始损耗使用逐采样段的数值步长控制；恢复较小阻力后放宽步长，避免整个平缓尾段都使用最小步长。旧 v1 模型保留原求解行为。

## 兼容

- 松手模型 v2 作为独立版本保存于新实验参数快照。
- 缺少该版本字段的旧参数继续使用封顶的 v1；读取时不自动继承新模型。

- 空气 v10、氦气 v7 的气体与传感器参数不变；松手损耗版本单独记录。
