# v4.2.2

发布日期：2026-07-07

继续完善自由模式真实/理想参数体系，加入空气与氦气气体类型联动，校准氦气 1.67 组的正常结果和错误操作偏差，并统一过程回顾、下拉菜单、悬浮提示和桌面更新说明。

## 新增

- 自由模式加入空气 / 氦气气体类型：普通参数区现在可以选择空气或氦气。空气使用双原子分子理论 gamma = 1.400，氦气使用单原子分子理论 gamma = 1.667，并同步切换底层物理参数、过程回顾和数据结果中的理论值。
- 过程回顾使用标准流程参考快照：过程回顾保存同一参数条件下的标准操作参考曲线、记录窗口和操作上限，用于对比实际操作与标准流程，并移除旧的合成标准过程模型。

## 改进

- 校准氦气 1.67 组的正常区间和错误偏差：氦气标准操作现在稳定贴近 1.67；旋塞长开和 U2 迟记等错误会围绕氦气理论值产生更明显偏差，避免错误操作只与正常结果相差很小。
- 优化过程回顾窗口和下拉菜单样式：过程回顾页签、窗口标题、实验组下拉菜单和真实/理想状态菜单的层级、边距、字号、箭头动效和菜单边框保持一致，减少视觉拥挤。
- 增强演示模式视角引导：演示模式会在调零、打气、阀门和旋塞动作时切换到更合适的观察视角，操作完成后自动回到默认视角，不显示引导模式面板。
- 统一悬浮提示和禁用说明：气体类型、真实/理想状态、参数说明和禁用状态现在使用统一固定样式的悬浮提示；已有进程或实验组时会说明为什么不能切换。

## 修复

- 清理旧模型和旧字段残留：删除旧标准过程实现，保留必要的旧文件兼容迁移，并增加静态回归测试，防止旧处理页、旧字段、旧多组引导和旧标准参考路径重新进入源码。
- 桌面自动更新资产保持完整：本版本继续发布 NSIS 安装包、latest.yml 和 blockmap，已安装的 4.2.1 客户端可以通过应用内更新检测到 4.2.2。
