# v4.2.3

发布日期：2026-07-11

本版本完成工作台架构收口和发布前稳定化，拆分大型界面职责，统一持久化、参数、更新器与热容实验运行边界，并清理不再使用的旧模型、旧样式和重复测试约束。

## 改进

- 工作台核心界面按职责拆分：顶部命令、设置窗口、更新窗口、参数对话框、空工作区和文件展示逻辑现在由独立组件与模块维护，降低主工作台文件的耦合度。
- 统一实验持久化边界：标准模拟与理想气体共享运行态恢复规则，热容实验使用独立的配置快照、恢复归一化和标签页注册表，同时保留必要的旧存档兼容读取。
- 统一热容模型指标：过程回顾、评分和标准参考共用同一套放气起点与相对误差计算，避免不同界面以后出现计算口径偏差。
- 收口参数与更新器状态：高级参数可见性、输入归一化、桌面更新状态和版本说明元数据均由单一策略维护。
- 优化热容实验导航：左侧栏子项字号和粗细与“3D 预览”保持一致；实验说明入口在演示、引导和自由模式均可使用，新建热容实验时会自动展示一次。

## 修复

- 修复实验说明在非引导模式下被错误关闭的问题，并确保说明弹出期间暂停分子动画、引导提醒计时和后续强提醒队列。
- 修复演示模式暂停时退出特定观察视角或重置当前步骤等待时间的问题；恢复后会从原进度继续。
- 删除未引用的工作台样式、旧 PDF 查看器、旧全局 UI 状态、重复持久化归一化器、重复过程指标和无生产用途的导出接口。
- 增加生产构建输出边界、导出器源码指纹和发布元数据校验，防止旧导出器或不完整更新资产进入桌面发布。
- 更新第三方版权清单生成流程，并验证当前 465 项依赖记录完整。
