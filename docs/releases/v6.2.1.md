# v6.2.1

发布日期：2026-08-29

6.2.1 是活塞振动法稳定性补丁，集中修复自由模式第一次采集、周期框选、回弹速度验证、动画故障恢复、跨重启状态和显示保护问题，同时恢复松开锁紧螺钉后的可见下沉。

## 简体中文发布说明

### 第一次采集与周期框选

- 修复自由模式第一次记录刚触发、正式曲线尚未完整时，监测图因无效显示范围导致整个页面进入白屏或故障恢复界面的问题。
- 第一次按压、触发、实时曲线增长、暂停、保存和自动进入下一组现在可以连续完成。
- 框选统计中的样本序号和周期计数会在进入界面前转换为明确、安全的数值类型，兼容旧版本保存的大整数形式。
- 保持原有框选方式、端点选择、周期规则和数据精度；第一次框选、重新框选、极短合法区间、切换组、返回修改和最后一组自动计算均继续按原规则运行。

### 回弹与真实稳定位置

- 删除加载气体状态、参考绝热状态和预留初速度入口中的固定速度范围。速度现在只要求是有限有效数字，不再把正常的 `2.38 m/s` 峰值截断为 `2 m/s`。
- 活塞位置、刚性底部、气体体积、压强、温度及数值求解发散检查保持不变，松手瞬间初速度仍默认为零。
- 如果回弹或短暂平衡动画真的发生软件执行错误，系统会停止计时器和动画帧，按软管、螺钉、气体和平台状态静默恢复稳定位置，保留已生成数据且不会卡在“回弹中”。
- 三维仪器会在螺钉、软管、平台和活塞状态变化时主动刷新。松开锁紧螺钉后，活塞重新可见地轻微下沉到真实加载平衡位置。

### 分层白屏保护

- 数据处理或计算内容发生显示错误时，只替换出错的内容区域；顶部栏、实验文件标签、左侧栏、模式切换、控制台和已保存实验数据继续保留。
- 局部恢复界面提供“重试显示”和“返回仪器”，不会清除自由模式、实验计划、曲线、框选、草稿或答题记录。
- 工作台主体更外层发生显示错误时，继续保留软件原有的最小化、最大化/还原和关闭按钮，并复用真实 Electron 窗口逻辑。
- 测试故障注入只在开发环境中可用，不存在于正式产品入口。

### 重启恢复与完整流程

- 重新打开软件时不再继续按压、手持、自由下落、回弹或短暂动画，而是根据当前软管、螺钉、气体和平台条件恢复稳定位置。
- 自由模式实验计划、系统与自定义高度、已完成组数、当前目标、已保存曲线、草稿、框选、端点、核验、每次作答、拟合、计算和过程记录继续保留。
- 只有用户主动执行“重置自由模式”才会清除整轮计划和数据。
- 3、4、5、6 组及系统高度与自定义高度混合方案均通过端到端流程验证；最后一组核验后仍自动进入计算，不增加额外按钮或固定三组提示。

### 兼容性

- 保持既有应用 ID、产品名、安装身份、公开更新仓库和用户资料目录不变，可直接从 `v6.2.0` 覆盖更新。
- 旧版本保存的框选数据和自由模式可靠数据继续恢复，不要求用户重新完成已有实验。

- `3–6` 組及系統與自訂高度混合方案均按實際組數完成週期、計算、擬合、結果和返回儀器流程。

## English release notes

### Acquisition, selection, and rebound fixes

- Fixed the Free Mode white screen that could occur while the first run had just triggered and its formal curve was still incomplete. Pressing, triggering, live plotting, pausing, saving, and advancing now remain continuous.
- Period-selection sample indices and counts are converted to safe numeric types before rendering, including bigint-shaped values restored from earlier saves. Gestures, endpoints, period rules, and precision are unchanged.
- Removed all three fixed velocity ranges. Velocity only has to be finite, so normal rebound peaks above 2 m/s are not clipped or misreported; the existing position, volume, pressure, temperature, rigid-stop, and divergence checks remain.
- Restored visible screw-release settling. Genuine motion-runtime failures now stop their timers and frames, silently recompute the stable position from current physical conditions, retain generated data, and cannot leave the UI stuck in rebounding state.

### Layered render and restart recovery

- Processing or calculation render errors replace only the failed content region while retaining the top bar, experiment tab, sidebar, mode controls, console, and saved data, with Retry Display and Return to Instrument actions.
- An outer workbench render failure retains the real minimize, maximize/restore, and close controls. Development fault injection is absent from production entry points.
- Restart clears non-resumable pressing, holding, free-fall, rebound, and short-animation state while preserving plans, heights, saved curves, drafts, selections, answers, fitting, calculations, and audit history.
- End-to-end coverage verifies 3–6-run and mixed system/custom-height plans through period verification, automatic calculation, fitting, results, instrument return, persistence, and explicit reset.
