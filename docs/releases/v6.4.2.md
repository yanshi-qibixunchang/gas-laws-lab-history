## 历史失败与保留边界

2026-09-15 的构建修复提交 `7dc55b5` 曾通过 347 个测试和本地打包，但实际 Windows 6.4.0→6.4.1 检查中旧文件在数据库保留、UI 未恢复。根因是嵌套 Free schema8→10 未被外层 V3 识别为已知迁移。该旧失败保留，不能改写为 6.4.1 升级成功；本次以新构建验证两条到 6.4.2 的路径。

当时本机诊断误用忽略独立资料参数的旧 6.4.0，写入默认资料目录的体验配置、测试标记并新增测试文件。已停止并保存版本库外的事后副本；这不是事前备份，不能宣称恢复了测试前设置。用户随后确认原资料保持现状，仅在副本修复、验收后继续发行。后续不再访问或清理原目录，不把其中数据作为公开夹具；旧版安装运行只在干净托管 Windows 进行。

旧周期证据保留不等于沿用旧容差判分，新计算仍只使用显示并舍入后的值。模型扫描仍不等于实物标定，既有偶发长帧的证据边界保留；本批不新增物理或架构范围。
