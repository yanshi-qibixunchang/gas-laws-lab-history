# v5.3.1

发布日期：2026-08-01

5.3.1 完成 Gas Laws Lab 绝热膨胀法实验从多次操作、整组计算与评价，到图表、报告和实验包导出的完整闭环。

## 中文发布说明

### 多组实验与自动推进

- 自由模式统一使用“第几组、第几次实验”的层级，一个实验组可以连续完成多次实验。
- 完成一次实验后自动推进到下一次，不再通过容易误解的主界面按钮重新选择次数。
- 当前组完成实验和必要计算后，才允许新建下一组；新组可以重新选择真实或理想参数类型及实验次数。
- 真实组保留独立参数、计算结果、图像和整组评分；理想组自动计算，仅用于图像和结果比较，不参与评分。

### 计算、评分与过程回顾

- 计算界面的每次实验已知条件完整显示记录值，包括 U₀、U₁、U₂。
- 真实参数实验按整组评分，汇总各次实验的操作、记录和计算表现，避免简单叠加扣分造成组数越多分数越低。
- 完成三次实验后显示整组棒棒糖图，区分理论参考、本组平均值和 A 类不确定度，并支持按组、按次查看过程结果。
- 产品介绍中的结果演示已同步为新的多次实验、整组评分和过程回顾界面。

### 报告与图表导出

- 绝热膨胀法实验支持“导出报告”“导出图表”和“导出实验包”。
- 导出覆盖实验文件中的全部真实组和理想组，并按真实组、理想组分别组织记录、计算、评分、比较图和整组图。
- 报告采用明确的编号层级、三线表和统一科学图形规范；中文统一使用宋体，西文和数字统一使用 Times New Roman。
- 优化表格列宽、表头换行、正文对齐和数字居中规则，避免单字换行并提高长表可读性。

### 重新开始操作修复

- 移除自由模式旁边和主视图区中语义错误、可能重新创建实验组的重置入口。
- 实验进度省略号中提供“重新开始第 X 次实验”和“重新开始本组实验”两个独立操作，并使用统一的二次确认窗口。
- 重新开始本次实验只清理当前未完成实验；重新开始本组实验清理当前组，同时保留其他已完成组及本组参数配置。

## English release notes

### Multi-group workflow and automatic progression

- Free Mode now uses a clear experiment-group and experiment-number hierarchy, allowing multiple experiments in each group.
- Completing an experiment automatically advances to the next one without reopening group setup.
- A new group can be created only after the current group and its required calculations are complete.
- Real groups keep independent parameters, calculations, figures, and group scores. Ideal groups calculate automatically for visual comparison and are not scored.

### Calculation, review, and export

- Each calculation table includes the recorded U₀, U₁, and U₂ values as known conditions.
- Real experiments are scored at group level, with balanced aggregation across operation, recording, and calculation performance.
- Groups with at least three completed experiments show a lollipop chart with the theoretical reference, group mean, and Type A uncertainty.
- Adiabatic-expansion files can export a report, figures, or a complete experiment package covering all real and ideal groups.
- Reports use numbered hierarchy, three-line tables, consistent scientific figures, and unified Chinese/Latin font rules.

### Scoped restart controls

- Removed ambiguous reset actions that could recreate or replace an experiment group.
- The experiment-progress overflow menu now provides separate actions for restarting the current experiment and restarting the current group, both with consistent confirmation dialogs.
- Restarting the current experiment preserves completed experiments. Restarting the group preserves other completed groups and the configured parameters for the current group.
