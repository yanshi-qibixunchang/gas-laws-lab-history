# v5.2.0

发布日期：2026-07-20

5.2.0 是 Gas Laws Lab 的稳定性与兼容性版本，重点解决长时间实验逐渐卡顿、旧工作区无法打开，以及保存失败中断完整操作流程的问题。

## 中文发布说明

### 保存与运行稳定性

- 工作区保存分为语义操作、15 秒运行检查点和生命周期刷新。参数、模式、文件、U0/U1/U2、组完成和计算结果使用 750 ms 防抖并在 2 秒内提交；连续 100 ms 实验刷新不再重复触发整工作区保存。
- V3 投影、指纹计算、候选代写入和回读校验在后台 Worker 中执行。请求按最新快照合并；Worker 异常时保留待保存内容并重启一次，主线程降级仅在空闲期执行。
- 暂停、停止、窗口隐藏和退出会立即刷新，并继续使用桌面关闭等待机制。意外崩溃时，纯连续运行最多回退 15 秒；已记录的测量值、组完成和计算结果不受该窗口影响。

### 旧数据兼容

- 正式兼容由 4.2.3 和 5.1.1 写入的标准模拟、理想气体和热容比工作区。已撤回的 5.1.2 废版实验数据不在兼容承诺内；从该版本升级时可重置本地工作区。
- 首次从 V2 恢复后会提交并回读验证 V3；后续只写 V3，同时保留原 V2 数据，不删除、不清空。
- 当前代损坏时可回退上一代；单文件结构错误和未来版本文件会作为 opaque 原始记录隔离，健康文件仍可正常打开、操作和保存。

### Free 模式耐久性

- Free 轨迹升级到版本 6：每分支最多 800 个采样和 320 个详细事件，每试验最多 4 个详细分支，每参数域最多保留 7 个已完成试验和 1 个当前试验。
- 超限内容写入版本化压缩摘要，保留 U0/U1/U2、计算、评分、阶段和安全事件的权威关系；v4、v5 轨迹会在读取时迁移。
- 自动耐久测试覆盖 30 分钟逻辑运行和连续 7 组实验，持续检查交互耗时与全部轨迹硬上限。

### 保存错误恢复

- 临时事务错误按 250 ms、1 秒和 3 秒重试。
- 空间不足时先清理无效候选代再重试；所有失败均保留最后成功代，并以非阻断状态提示代替致命窗口。

## English release notes

### Save and runtime stability

- Workspace persistence now has semantic, 15-second runtime-checkpoint, and lifecycle lanes. Parameters, modes, files, U0/U1/U2 records, completed groups, and calculations use a 750 ms debounce with a 2-second maximum wait, while 100 ms experiment ticks no longer trigger repeated whole-workspace saves.
- V3 projection, fingerprinting, candidate writes, and read-back verification run in a background Worker. Requests coalesce to the latest snapshot; one Worker restart preserves the pending save, and the main-thread fallback runs only during idle time.
- Pause, stop, window hiding, and exit flush immediately through the existing desktop close coordinator. A crash during uninterrupted running can lose at most 15 seconds, while recorded measurements and calculated results use semantic saves.

### Legacy compatibility

- Standard simulation, ideal-gas, and heat-capacity workspaces written by 4.2.3 and 5.1.1 are supported. Experimental data written by the withdrawn 5.1.2 build is outside the compatibility guarantee and may be reset during upgrade.
- A restored V2 workspace is committed to V3 and verified by read-back once. Later saves write only V3 while retaining the original V2 records unchanged.
- A damaged current generation can fall back to the previous verified generation. Structurally invalid or future-version files are retained as opaque source records so healthy files remain usable.

### Free-mode endurance

- Free trace version 6 limits each branch to 800 samples and 320 detailed events, each trial to 4 detailed branches, and each parameter domain to 7 completed trials plus the active trial.
- Versioned compaction summaries preserve authoritative U0/U1/U2, calculation, scoring, phase, and safety relationships. Trace versions 4 and 5 migrate on read.
- Automated endurance coverage exercises a logical 30-minute, seven-group run while continuously checking interaction timing and every trace bound.

### Save recovery

- Temporary transaction failures retry after 250 ms, 1 second, and 3 seconds.
- Quota failures prune invalid candidate generations before retrying. Every failure keeps the last verified generation and uses a non-blocking status instead of a fatal recording-disrupting dialog.
