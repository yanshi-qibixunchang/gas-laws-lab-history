# v5.2.2

发布日期：2026-07-25

5.2.2 是 Gas Laws Lab 的开屏流程热修复，解决 5.2.1 在工作区恢复达到 100% 后仍停留在加载界面的问题。

## 中文发布说明

### 开屏与工作区恢复

- 修复开屏进度到达 100% 后无法退出的问题。
- 将“工作区已就绪”“开屏淡出”和“进入工作台”拆分为连续且互不取消的三个阶段，避免 React 状态切换提前清除退出计时器。
- 正常动画与 Windows“减少动态效果”两条路径均会在工作台完成绘制后可靠关闭开屏。
- 本次修复不修改工作区内容、实验数据结构或本地用户资料目录，可直接覆盖安装 5.2.1。

## English release notes

### Startup and workspace restoration

- Fixed the startup screen remaining visible after progress reached 100%.
- Workspace ready, splash fade-out, and workbench entry now run as three consecutive stages that cannot cancel one another, preventing React state cleanup from clearing the exit timer.
- Both normal animation and Windows reduced-motion paths reliably dismiss the splash after the workbench has painted.
- This hotfix does not change workspace contents, experiment data formats, or the local user-data directory and can be installed directly over 5.2.1.

## Desktop update assets

The stable update must publish these three matching files together:

- `heat-capacity-lab-setup-5.2.2.exe`
- `heat-capacity-lab-setup-5.2.2.exe.blockmap`
- `latest.yml`

The installer name, version, SHA-512, download URL, and release assets in `latest.yml` must match exactly.
