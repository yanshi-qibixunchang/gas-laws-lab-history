# v5.1.1

发布日期：2026-07-16

5.1.1 是面向所有 4.2.x 用户的公开稳定更新。本版本完善热容比实验的温度与热力学模型、分子和仪器反馈、演示 / 引导 / 自由三模式会话及精确视角恢复，并重建工作区持久化、GLB 运行和桌面更新可靠性。

## 改进

- 统一真实与理想参数下的温度、压力、放气和回温过程，使 U0、U1、U2、γ、标准参考与过程回顾使用一致的物理口径，并让空气和氦气实验保持可解释的正常结果与错误偏差。
- 分子运动、旋塞与阀门动效、压力表和数字显示、调零与打气反馈现在与同一实验状态同步；快速操作、全局静音、0% 音量、模式恢复静音和放气停止使用统一音频生命周期。
- 所有同文件模式变化通过同一强类型切换协调器，等待真实仪器或相机运动完成并采用最后一次目标。五分钟等待、首次预热、计时器、实验记录、粒子状态、焦点和精确相机姿态可在模式切换、刷新及文件往返后恢复。
- 统一工程工作台、实验仪器模型、菜单与结果页的层级和反馈；离线界面仅保留随应用分发的 Noto Sans SC 与 JetBrains Mono，演示和引导等待过程保持清晰、可恢复且不遮挡关键仪器状态。

## 可靠性修复

- 使用原生 IndexedDB 分离保存工作区元数据、文件状态与每个热容模式的唯一规范状态，采用 750 ms 防抖、2 秒最长等待及文件 / 模式切换和页面隐藏即时刷新。
- 为 4.2.3 本地存档提供一次性隔离迁移：只有在完整写入、逐记录核验和运行态重建均成功后才删除旧数据；事务、配额或损坏记录会保留最后一次成功版本并显示错误。
- GLB 克隆只释放自身拥有的材质、运行时几何和 CanvasTexture，不释放共享 geometry / texture；资源重试与运行时重试分离，运行时重试不会重新下载 GLB。
- 渲染帧、事件、Promise、延迟回调和音频解码异常统一进入可重试错误卡，并停止相关计时与音频；模式切换看门狗在运动屏障异常时安全完成并解锁。
- 更新下载改为 single-flight，同一更新的重复点击复用一个任务；更新窗口保留结构化三语言说明、手动下载和重试入口。

## 桌面更新资产

本次公开稳定更新必须同时发布以下三个文件：

- `heat-capacity-lab-setup-5.1.1.exe`
- `heat-capacity-lab-setup-5.1.1.exe.blockmap`
- `latest.yml`

`latest.yml` 中的安装器文件名、版本、SHA-512、下载地址与发布资产必须完全一致。
