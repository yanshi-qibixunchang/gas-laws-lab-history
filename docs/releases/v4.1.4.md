# 热容比实验室 v4.1.4

## 更新日志（简体中文）

本次更新内容基于 `v4.1.3..v4.1.4` 的实际提交范围整理。

### 新增

- **热容自由实验参数调整体系**：自由实验现在可在新实验组开始前调整环境基准、状态方程、热交换、传感扰动、泄漏修正、记录判定、安全阈值和可视化参数。
- **热容自由实验过程回顾与评分**：新增轨迹数据、最佳记录窗口、过程评分和过程回顾面板，用于复盘放气、回温、记录时机和结果质量。
- **参数按实验组生效并隔离历史结果**：已完成实验组保留原始参数快照，重置到下一组后才重新允许调整组级参数。
- **实验文件保存恢复与数据版本**：新增热容、理想气体和标准模拟的数据 schema 与迁移路径，工作区文件可保存参数、记录、结果和运行状态。
- **更新失败后的手动下载入口**：自动下载多次失败后，可直接打开 GitHub Release 中的 Windows 安装包。
- **结构化更新说明**：新版更新弹窗按新增、变更、修复和兼容性说明展示本次更新内容。

### 变更

- **参数界面统一为工程软件风格**：热容、理想气体和标准模拟的参数行样式完成统一，并补齐亮暗模式适配。
- **热容自由实验记录判定更严格**：`U0`、`U1`、`U2` 记录现在会结合零点容差、压力/温度稳定斜率、最小有效读数和安全阈值，拦截不可靠记录。
- **热容可视化与性能控制调整**：小球可视化改为独立显示开关，粒子数量和速率由高性能、均衡、低负载三档性能模式控制。
- **工作台交互性能优化**：降低拖拽分栏和热容演示动画的状态提交频率，减少运行时 UI 抖动和不必要重渲染。
- **网络波动自动重试**：更新下载遇到临时网络错误时最多尝试 3 次，并在界面显示当前尝试次数。

### 修复

- **热容自由实验物理模型边界修复**：修复热交换、泄漏、传感滞后、噪声、压力安全和理论参考值相关边界，使参数调整后的变化方向与模型含义一致。
- **失败信息更明确**：下载失败会说明已重试次数，并保留稍后重试和手动下载两种恢复路径。

### 兼容性说明

- **仅桌面安装版可自动更新**：浏览器预览和开发模式仍只显示更新状态，不执行安装包下载和重启安装。
- **旧版 `v4.1.3` 更新弹窗兼容**：`latest.yml` 提供纯文本简体中文更新说明，避免旧版把 GitHub HTML release notes 当作代码文本显示。

## Release Notes (English)

This release note is based on the actual `v4.1.3..v4.1.4` commit range.

### Added

- **Heat-capacity free-experiment parameter controls**: Free experiments can now adjust environment baseline, equation-of-state, thermal exchange, sensor disturbance, leakage correction, recording validation, safety thresholds, and visualization parameters before a new group starts.
- **Heat-capacity free-experiment process review and scoring**: Adds trace data, best recording windows, process scoring, and review panels for release, recovery, recording timing, and result quality.
- **Per-group parameter effect with isolated history**: Completed groups keep their original parameter snapshots, and group-level parameters become editable again only after resetting to the next group.
- **Experiment persistence and data schema versions**: Adds data schemas and migration paths for heat-capacity, ideal-gas, and standard simulations so workspace files can persist parameters, records, results, and runtime state.
- **Manual download after update failure**: After repeated automatic download failures, the app can open the Windows installer asset from the GitHub Release.
- **Structured release notes**: The new update dialog groups release notes by added, changed, fixed, and compatibility sections.

### Changed

- **Engineering-style parameter interface**: Heat-capacity, ideal-gas, and standard-simulation parameter rows now use a consistent engineering UI style with light/dark theme support.
- **Stricter free-experiment recording validation**: `U0`, `U1`, and `U2` recording now combines zero tolerance, pressure/temperature stability slopes, minimum valid readings, and safety thresholds to block unreliable records.
- **Heat-capacity visualization and performance controls**: Particle visualization now uses a separate visibility switch, while particle count and rate are controlled by performance, balanced, and low-load modes.
- **Workbench interaction performance improvements**: Reduces state commits during split resizing and heat-capacity demo animation to avoid UI jitter and unnecessary re-renders.
- **Automatic retry for transient network failures**: Update downloads retry up to three attempts for transient network errors and show the current attempt count.

### Fixed

- **Heat-capacity free-experiment physics boundary fixes**: Fixes thermal exchange, leakage, sensor lag, noise, pressure safety, and reference-value boundaries so parameter changes follow the intended model direction.
- **Clearer failure information**: Download failures show the completed attempt count and keep both retry and manual download recovery paths available.

### Compatibility

- **Automatic updates remain desktop-installer only**: Browser previews and development mode still show update status only and do not download installers or restart to install.
- **Legacy `v4.1.3` update dialog compatibility**: `latest.yml` provides plain-text Simplified Chinese notes so the old dialog does not show GitHub HTML release notes as code text.
