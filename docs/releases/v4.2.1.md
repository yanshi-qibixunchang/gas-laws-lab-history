# v4.2.1

发布日期：2026-07-07

本版本重构空气比热容比实验的真实/理想参数体系、引导与演示流程、过程回顾和 GLB 交互细节，并清理旧模型与旧 UI 残余，使自由实验、引导实验和演示实验的边界更清晰。

## 新增

- 自由模式新增“真实模拟 / 理想状态”参数组合。理想状态会锁定可调参数、关闭非理想干扰、隔离实验组编号，并在数据与过程回顾中单独显示，不参与真实模拟平均值和评分。
- 数据与结果、过程回顾新增统一的实验类型菜单，可在真实模拟和理想状态之间切换，并保持两类实验各自独立编号。

## 改进

- 演示和引导流程现在明确展示 120 mV 打气目标、五分钟回温等待和完成后的退出状态。完成后可继续查看左侧栏数据，点击退出后再回到自由模式。
- 普通参数和高级参数界面重建：参数行使用统一左右制表位布局，单位固定在输入框右侧；高级参数按语义分组。
- 高级参数确认、恢复默认确认和理想状态说明统一为文件级提示。
- 过程回顾整合实际曲线、标准曲线、记录窗口、事件时间轴和操作评分。理想状态下理论上限固定为 1.400，并以占位符说明不参与评分。
- 更新 GLB 默认视角、聚焦视角和性能档位映射，改进控件悬浮提示、打气球高亮扩散、强提醒遮罩与可操作区域的命中逻辑。

## 修复

- 修复引导完成后自由模式电源异常。
- 修复打气阀门提示残留、压强报警后仍可继续聚焦打气、U1 记录时机过早等交互边界问题。
- 修复完成实验组删除失效。
- 删除旧的合成标准过程模型，统一使用当前标准流程和真实/理想参数域。
- 继续清理旧温升字段、旧多组引导结构、旧性能和旧处理页相关路径，降低后续维护污染。
