## 本轮改动

- 增加可选择的本地候选输出目录。构建、更新描述生成和资产校验使用同一目录，已有候选或指向其他位置的目录链接会被拒绝；普通 `release/` 构建入口保留。
- 桌面程序尊重显式的绝对 `--user-data-dir` 参数。普通启动继续使用原有用户目录；无效的相对路径不会悄悄退回日常数据。

## 建议人工验收顺序

1. 从 `启动验收.cmd` 打开，确认四类实验的模型、参数与模式切换符合预期，重点感受连续操作和动画。
2. 新建活塞实验，完成三组、每组至少两个主周期；检查断电转入计算、按显示值重算，以及接近但不相等的答案判错。
3. 切换文件、关闭再打开程序，核对参数、实验记录、模式和结果；检查结果窗口标签与撤销/重做。
4. 在桌面程序导出报告，核对中文、图表、数值和分页，特别是理想气体单图报告的结论。

收到验收反馈后先修复问题。只有用户另行决定发布，才确认新版本号、复核 `private` / `public-history` / `origin` 的实际职责、更新发布说明并重新执行发行检查。本次未推送、未发布，也未覆盖任何远端内容。

## 再次生成本地候选

使用已安装的构建依赖，选择 `output/local-acceptance/` 下一个尚不存在的目录：

```powershell
$env:HSL_RELEASE_OUTPUT_DIR = 'output/local-acceptance/next-candidate'
npm.cmd run desktop:installer
Remove-Item Env:HSL_RELEASE_OUTPUT_DIR
```

目录必须是新的，重复名称会拒绝构建。命令会重新生成本地导出器与安装包，但发布参数始终为 `never`。如需下载缺失依赖，应遵循本机下载确认规则。
