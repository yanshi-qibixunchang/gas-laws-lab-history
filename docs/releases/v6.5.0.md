# 气律实验室 6.5.0 发行记录

日期：2026-11-15。范围：用户授权正式发布 6.5.0；发布后的反馈纳入后续补丁版本。

[正式 Release 与下载](https://github.com/yanshi-qibixunchang/gas-laws-lab-release/releases/tag/v6.5.0) · [版本源码](https://github.com/yanshi-qibixunchang/gas-laws-lab-history/tree/v6.5.0)

## 本次内容

- 收录两种比热容比实验已确认的空气、氦气理想与真实参数。验收范围来自预先确认的工况标准；氦气部分范围由空气标准按理论值等比例换算，不作为氦气实测证据。
- 活塞使用缸内平衡压强，理想条件加入回馈气体内能的内部耗散，采集上限为 3 秒；保留真实工况标定和正常操作容差，取消大松手时间差的旧损耗上限。
- 平台回弹采用项目提供的两段现场录音及运行时声音处理。移除旧 Freesound 平台振动备用文件、播放分支和来源登记；其他仍在使用的第三方机械音效保留许可。项目自有音效与第三方音效分别展示。
- 统一计算、不确定度说明、变量气泡、焦点跳转和自动滚动；两个可视化开关统一为无尖角说明面板，悬停 1 秒后滑入淡入，移出后立即开始滑出淡隐。
- 修复采集设置过早锁定、理想活塞曲线保存与连续测量、较大工作区退出保存超时、桌面导出环境误报和部分窗口显示问题。
- 绝热膨胀法支持输入或选择至少 3 次的自由实验次数，增加连续温度色条；实验名称在所有类型及已关闭文件中自动避重，加载旧重名文件时只调整名称。
- 重写三语 README、更新三语版本说明和网页版桌面下载入口，重新生成依赖、许可及素材来源清单。
