# Blender 模型接入规则 v4.0.1

本文件用于冻结空气比热容比实验的 3D 仪器模型骨架。该骨架以 FD-NCD-C 为主要结构参考之一，供独立 Blender 建模人员按本版本制作后续可接入的 GLB/GLTF 模型；它不表示本软件是该型号仪器的官方仿真或数字复刻。v4.0.1 之后，实验控件骨架、交互命名和状态绑定视为稳定契约；后续主要调整实验过程逻辑、教学提示、阈值和计算方法。

## 1. 模型定位

- 模型对象固定为空气比热容比测定仪；FD-NCD-C 作为主要结构参考之一，不再回退到硬球单原子气体或通用理想气体仪器。
- 3D 模型只负责教学可视化和交互承载，不参与 `P0`、`P1`、`P2`、`U_p`、`U_T`、`gamma` 的真实计算。
- 实验状态机是唯一数据源；Blender 模型只能读取状态机给出的开关、旋塞、打气、读数和高亮状态。
- 程序内骨架优先于外观模型。GLB 替换时必须服从本文件的节点名、pivot、hitbox 和状态绑定要求。

## 2. 固定整体布局

- 左侧为透明集气瓶/贮气瓶，右侧为电子测量主机/仪表箱，两者并排放置在同一桌面水平面上。
- 集气瓶略高于主机，主机前面板朝向观察者。
- 整体风格为教学仪器简化模型，优先保证结构识别和交互清晰，不追求复杂写实细节。
- 第一批正式接入模型不制作外部导线、气管、打气球、后方支架、侧边把手。
- 参考图中的“打气控制”拨杆必须删除，不作为最终模型控件。

## 3. 必须保留的结构

- 透明方形或近似立方体集气瓶，带浅蓝透明玻璃材质。
- 顶部瓶口、橡皮塞、玻璃旋塞和短瓶颈结构。
- 瓶内竖直杆状传感器，用于表达温度传感器位置。
- 右侧矩形电子测量主机，带前面板。
- 左侧数字显示屏：表示 `U_T / mV` 温度信号。
- 中间数字显示屏：表示 `U_p / mV` 压强差信号。
- 圆形指针压力表。
- 电源开关。
- 压强调零旋钮。
- 打气阀门或打气入口交互点，用于表达打气通路控制。
- 打气动作触发点可用简化按钮、泵柄或隐形 hitbox 表达，但不得恢复“打气控制”拨杆。

## 4. 不可变更控件清单

以下控件名称和交互含义在 v4.0.1 固化，Blender 模型不得擅自合并、删除或改变含义：

| 控件 | 含义 | 状态来源 |
|---|---|---|
| PowerSwitch | 主机通电/断电 | `powerOn` |
| PressureZeroKnob | 压强调零旋钮 | `pressureZeroOffset` / 调零状态 |
| GlassStopcock | 顶部玻璃旋塞，控制瓶内与外界通断 | `stopcockAngleDeg` / open-closed 映射 |
| PumpValve | 打气阀门或打气通路控制点 | `pumpValveOpen` |
| PumpBulb | 打气动作触发点 | 打气动作事件 |
| RecordU0Button | 记录 `U0` | 手动实验步骤 |
| RecordU1Button | 记录 `U1 / U_T1` | 手动实验步骤 |
| RecordU2Button | 记录 `U2 / U_T2` | 手动实验步骤 |
| NextTrialButton | 进入下一组实验 | 组间状态 |
| CalculateButton | 计算结果 | 数据处理状态 |

可在 UI 层显示这些按钮，也可在 3D 模型中提供对应 hitbox；无论采用哪种表现，控件语义不得改变。

## 5. 节点命名要求

GLB/GLTF 顶层建议使用 `HeatCapacityInstrumentRoot`。关键节点必须保持下列名称，便于程序按名称绑定：

```text
HeatCapacityInstrumentRoot
  GasBottle
  GasBottleGlass
  BottleNeck
  RubberStopper
  GlassStopcock
  GlassStopcockHandle
  InnerSensorRod
  InstrumentBox
  FrontPanel
  TemperatureDisplay
  PressureDisplay
  PointerGauge
  GaugeNeedle
  PowerSwitch
  PressureZeroKnob
  PumpValve
  PumpBulb
  HitboxPowerSwitch
  HitboxPressureZeroKnob
  HitboxGlassStopcock
  HitboxPumpValve
  HitboxPumpBulb
```

允许增加装饰性子节点，但不得重命名、删除或复用以上关键节点。装饰节点不得承担新的实验数据语义。

## 6. Pivot 与动画约束

- `GlassStopcockHandle` 的 pivot 必须位于旋塞中心轴线上，动画只表达开/关两态之间的旋转。
- `GaugeNeedle` 的 pivot 必须位于压力表圆心，允许由程序根据压强状态旋转。
- `PowerSwitch` 的 pivot 应支持轻微按下、拨动或亮灭状态，不改变控件位置。
- `PressureZeroKnob` 的 pivot 必须位于旋钮中心，允许绕面板法线旋转。
- `PumpValve` 的 pivot 应支持开/关状态表达。
- `PumpBulb` 可用缩放或位移表达打气动作，但不产生真实物理压力；压力变化仍由状态机决定。

## 7. Hitbox 规则

- 每个可交互控件必须有独立 hitbox，命名为 `Hitbox...`。
- Hitbox 可以是透明几何体，必须覆盖用户可点击的视觉区域。
- Hitbox 不得互相大面积重叠，避免点击歧义。
- Hitbox 尺寸可以略大于视觉控件，便于教学软件操作。
- 空白区域、仪表箱主体和瓶体主体不得误触发具体操作。

## 8. 状态绑定边界

- Blender 模型读取状态：通电、调零状态、旋塞开闭、打气阀开闭、泵动作、读数文本、高亮控件、警告状态。
- Blender 模型不写入状态机内部数值，不自行计算压强、温度或比热容比。
- 显示屏文本由程序注入；模型只提供显示区域材质或文字承载面。
- 高亮、闪烁、警告颜色由程序驱动，模型只提供可被替换或调色的材质槽。

## 9. 材质建议

- 集气瓶：浅蓝透明玻璃，保持内部传感器可见。
- 玻璃旋塞：透明或半透明玻璃材质，与瓶体略有区分。
- 橡皮塞：米黄、浅黄或浅棕色哑光材质。
- 主机外壳：浅灰或白色，保留蓝灰边框。
- 数字屏：蓝色或深蓝发光材质，文字由程序覆盖或动态注入。
- 压力表：白色表盘、黑色刻度、红色或黑色指针。
- 交互高亮材质：需预留可由程序切换的 emissive 或 outline 通道。

## 10. 交付格式

建模人员交付时必须包含：

- `.blend` 源文件。
- `.glb` 或 `.gltf + bin + textures` 运行文件。
- 一张节点树截图，能看到关键节点名称。
- 一张正面截图和一张 3/4 视角截图。
- 简短交付说明，列出是否完整包含本文件要求的关键节点、pivot 和 hitbox。

交付模型不应包含未授权贴图、外链材质、真实品牌商标或会阻碍打包的绝对路径引用。

## 11. 禁止事项

- 不得把 `U_p` 标成 kPa 或把 `U_T` 标成摄氏度；本模型显示的是 mV 信号。
- 不得让 GLB 自行决定实验是否完成、是否可记录或是否可计算。
- 不得新增会改变实验流程的真实控件。
- 不得恢复被删除的“打气控制”拨杆。
- 不得把顶部玻璃旋塞建成上下推动式活塞；它是旋转通断的 glass stopcock。
- 不得用复杂物理引擎替代现有实验状态机。

## 12. 接入验收

接入前至少检查：

- 所有关键节点名称存在且唯一。
- 旋塞、压力表指针、调零旋钮和电源开关 pivot 正确。
- hitbox 可独立点击，不遮挡相邻控件。
- 通电、调零、打气、封闭等待、快速放气、回温、记录和计算步骤都能由程序状态驱动显示。
- 模型替换后，原实验流程、结果计算和数据记录不发生接口层改变。
