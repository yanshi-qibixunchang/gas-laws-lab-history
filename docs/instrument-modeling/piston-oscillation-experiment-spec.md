# 活塞振动法实验固定规范

## 文档用途

- 本文是活塞振动法实验操作、计算过程和仪器建模约束的唯一现行版本。
- 本文固定已经确认的实验事实、三维仪器物理状态、软件分幕、实时采集必需内容和计算步骤。主工作区的阶段结构、当前引导闭环以及自由模式的会话、Run 保留和采集设置边界已经固定；自由模式的评分和导出策略按当前开发路线图逐项确认。
- 仪器模型以 `public/models/piston-oscillation/piston-oscillation.glb` 为唯一正式资产；交互状态和实验流程由软件层驱动。

## 已固定的核心结论

- 实验仪器以 PASCO `TD-8572A Heat Engine/Gas Law Apparatus` 为一比一复刻对象，压力传感器为 `PS-2181`。
- 正式采集量为绝对压强；气缸只通过一根软管连接压力传感器。
- 六个正式可用高度按从高到低的顺序依次为：`80、70、60、50、40、30 mm`。
- 新建实验文件的机械待机状态为：仪器端软管断开、锁紧螺钉松开、活塞在重力作用下落到 `0 mm` 的刚性下限。此时活塞不能继续下压，零刻度以下的软管、接口和传感器腔体仍保留固定死体积，因而不能通过继续按压产生可用振动曲线。
- 相邻系统候选高度间隔为 `10 mm`。自由模式每轮先通过可直接输入、也可下拉选择的次数控件确定 `3–6` 次实验，再从六个系统候选或任意数量的自定义候选中框选恰好相同数量的测量点。自定义高度只接受 `10–80 mm` 整数，其中 `10–29 mm` 显示为非推荐但不阻断；首次进入时次数与高度均为空，不暗中带入默认计划。确认后统一按目标高度从高到低推进和拟合。
- 采样频率必须允许用户直接输入并调整；PS-2181 的最高采样频率为 `1000 Hz`，软件接受 `1–1000 Hz` 的整数，本实验的正确目标设置为 `1000 Hz`。范围内但低于正确值的设置必须真实降低时间分辨率，不能被系统自动改回正确值；具体结果影响和评价分级随观测模型确定。
- 本轮所选次数的原始采集全部完成后，再统一处理压力曲线和计算比热容比。
- 计算压力 `P` 默认取 `1.01 × 10^5 Pa`；后续物理模型需允许调节该参数。
- 质量 `m` 是随活塞共同上下运动的组件总质量，而不是只指某一块外加重物。
- 当前引导模式固定使用本机铭牌运动质量 `48.5 g`、活塞直径 `32.5 mm`，以及包含气缸、软管、接口和传感器腔体的有效气体体积。
- 软件空气的版本化客观物性固定为 `γ = 1.40`；底层状态方程、原始测量物理快照和相对误差必须使用同一来源，同一次拟合不得混用不同空气物性的 Run。
- 当前 `0.434 N·s/m` 是三种模式共同使用的版本化临时等效损耗，只用于维持已经验收的产品衰减曲线，不代表已经确定了真实机械摩擦或热力学阻尼；加入显式热交换模型后必须重新审查、缩小或删除。
- 三维实验默认从仪器已固定在支撑杆上、压力传感器已接入数据接口的状态开始；支架夹紧旋钮、传感器端软管接头和传感器数据线不作为核心实验交互。
- 三维仪器的核心物理交互只有三个对象、四类动作：仪器端软管的拔下与接回、活塞侧面锁紧螺钉的旋松与旋紧、活塞平衡高度的调节，以及活塞的向下按压与松手激振。
- 首次设置 `80 mm` 时，仪器端软管初始处于断开通大气状态，侧面锁紧螺钉初始处于松开状态；从一个已完成的 Run 切换到下一高度时，不沿用该初始例外。
- 采集时只显示当前压力曲线；已保存曲线通过本轮 Run 状态列表选择查看，默认不叠加显示。
- 当前引导模式在下降触发后固定截取 `0.500 s / 501` 点，达到时长后允许用户暂停并冻结这段固定记录；自由模式由用户手动开始、暂停并保存当前候选，实际采样率和阈值随 Run 一同保存。
- 正式周期测量由用户在曲线上选择两个同相位点并跨多个完整周期完成；自动峰值识别只能作为后续辅助，不替代正式操作。
- 主工作区只包含两种实验状态：A 幕“仪器操作与压力采集”和 B 幕“逐条曲线测周期”。A 幕保留三维仪器，B 幕隐藏三维仪器并把中央区域交给数据处理。
- A 幕中，点击开始只表示采集系统进入持续监测和等待触发状态；绝对压强下降穿过用户设置的触发阈值后，正式压力曲线才开始实时生成。
- A 幕停止采集后保留并冻结本次正式曲线，供用户保存本次 Run 或重做。自由模式中，被重做或删除的尝试从正式拟合数据中排除，但其原始观测、操作事件、采集设置和物理快照仍作为可恢复的排除记录保存，用于撤销和过程评价。
- 线性拟合以及比热容比与误差计算不占用主工作区，使用与绝热膨胀法一致的独立计算窗口；B 幕选点、C 阶段拟合和 D 阶段计算统一由左侧栏“数据处理”进入并回顾。

## 仪器结构与作用

### 气缸和活塞组件

- 精密 Pyrex 气缸内装有超低摩擦石墨活塞。
- 石墨活塞、长活塞杆和顶部承载平台构成共同上下运动的活塞组件。
- 气缸侧面的毫米刻度用于确定活塞平衡位置对应的气柱高度。
- 按 TD-8572A 官方规格，活塞直径为 `32.5 mm`，横截面积按 `A = πd²/4` 计算。

### 快接接口、软管和压力传感器

- 仪器底座上的快接接口与气缸内部连通。
- 软管接上后，气缸、软管和压力传感器形成密封气路。
- 软管拔下后，气缸内部与外界大气连通，活塞才可在不对密闭气体持续做功的情况下自由调整到新的平衡高度。
- PS-2181 虽有多个测量能力，本实验只使用连接气缸的单根软管和绝对压强测量通道。

### 侧面手钮锁紧螺钉

- TD-8572A 官方结构图明确将该部件标为 `Locking Screw`；它是仪器本体的一部分，不是实验指导中假设存在的外加工具。
- 螺钉位于气缸上部保护框架的侧面、顶部承载平台下方附近。
- 外露部分是短圆柱形滚花手拧头；螺纹轴沿水平方向、径向指向活塞中心线。
- 真实动作是绕自身水平轴旋转，并因螺纹产生少量轴向进退；它不是按钮、拨杆、悬臂或只旋转不进退的装饰旋钮。
- 沿旋紧方向转动时，螺钉向内推进并锁住活塞组件的竖直运动；沿旋松方向转动时，螺钉向外退让，活塞恢复自由运动。官方资料未说明螺纹旋向，因此本文不固定具体的顺时针或逆时针方向。
- 官方公开资料没有给出内部剖面。根据螺钉固定位置、长活塞杆和完整活塞行程，螺钉尖端直接压紧活塞杆是目前最合理的结构推断；该推断不等同于已确认的内部结构，最终建模前仍需用实物近照、拆解图或实物测量复核。可以确定的是，它不应直接顶压玻璃气缸，也不是固定随高度变化的平台边缘。
- 该锁紧螺钉与模型现有的 `RodClampKnob` 不同：后者位于支撑杆处，只负责把整台仪器固定在立杆上。

## 三维仪器物理交互范围与状态

### 核心交互对象

三维仪器只要求以下对象参与正式测量中的物理操作：

1. 仪器底座处的软管和快接接头；
2. 活塞侧面手钮锁紧螺钉；
3. 由石墨活塞、长活塞杆和顶部承载平台构成的完整活塞运动组件。

同一个活塞运动组件承担两种不同操作：慢速调节平衡高度，以及在密封状态下向下按压、松手并振动。两种运动必须由不同的物理状态管理，不能用一段固定动画同时代替。

### 软管和气路状态

仪器端软管至少具备以下状态：

- `connected_sealed`：软管已接回，气缸、软管和压力传感器形成密封气路；
- `transitioning`：正在断开或接回；
- `disconnected_open_to_atmosphere`：软管已拔下，气缸与外界大气连通。

软管断开后，活塞可以用于重新设定平衡高度，但无法形成正式实验所需的密闭气体弹力和压力振动。软管连接密封后，不允许直接拖拽活塞重新设定平衡高度，但活塞仍必须能够被按压并围绕平衡位置振动。

相邻两次测量之间，停止采集并等待活塞完全停止振动后，实验者先托住顶部平台，再把软管从 `connected_sealed` 切换到 `disconnected_open_to_atmosphere`。断开过程中必须持续托住平台。

### 锁紧螺钉状态

侧面锁紧螺钉以连续行程控制旋转和轴向进退，并按统一阈值形成两个功能状态：

- `loose`：行程低于 `60%`，活塞仍可竖直运动；螺钉越靠近松开端，失去手部支撑后的下落加速度越大；
- `locked`：行程达到或超过 `60%`，活塞组件的竖直位置被固定。

锁紧状态下停止调节高度、向下按压和振动。松开状态下是否允许调高或激振还要同时由软管状态和气路状态决定。

跨 Run 调高时，活塞稳定后由实验者持续托住顶部平台并断开软管。到达下一目标高度后旋紧螺钉，随后接回软管。

### 活塞高度状态

- 活塞机械高度 `h` 可在 `0–80 mm` 范围内连续变化；`0 mm` 是不能继续下压的刚性下限。引导和系统推荐高度使用 `30–80 mm`，自由模式计划允许 `10–80 mm` 整数目标，不把三维运动做成离散跳转姿态。
- 系统提供 `80、70、60、50、40、30 mm` 六个候选；自由模式还可加入任意数量的 `10–80 mm` 整数自定义候选，一轮最多选择六个点。当前引导模式的放行误差为 `0.25 mm`；自由模式不即时提示目标高度做错，实际操作和名义目标分别保存，最终按名义目标参与学生计算。
- 调高时必须区分“被实验者托住”“正在移动”“到达目标但尚未锁定”“已由锁紧螺钉固定”和“接管后恢复自由运动”。
- 只有在软管断开、气缸通大气、锁紧螺钉松开且实验者托住顶部平台时，才允许重新设定平衡高度。

### 活塞按压与振动状态

密封后的活塞运动至少依次经历：

1. `sealed_locked_atmospheric`：气路已经密封，活塞仍被螺钉固定在名义高度；
2. `settling_under_weight`：螺钉松开后，活塞在 `0.2 s` 内平滑、单向下沉，无振荡；
3. `sealed_loaded`：活塞自重与真实内外压强达到唯一加载平衡，后台保存真实高度、体积、压强、温度和内能；
4. `pressing`：实验者正在向下按压，软管连接且螺钉松开时这一动作必须改变气体状态；
5. `depressed`：活塞位于本次按压后的最低位置；
6. `released_oscillating`：松手后围绕真实加载平衡高度做衰减振动；
7. `settled`：振幅衰减后重新稳定。

界面向学生显示名义高度，真实加载平衡高度只在后台参与物理生成和模型检验。振动位移必须叠加在真实加载平衡高度上，不直接复用固定初始高度、固定振幅的内置动画作为正式结果。重复锁紧和松开不得累计下沉；自由模式退出、刷新或恢复文件时必须恢复同一热力学阶段，不能再次补做一次下沉。

### 不作为核心物理交互的对象

- 支撑杆夹紧旋钮 `RodClampKnob`：保持仪器已固定的静态状态；
- 压力传感器、数据接口及二者之间的数据线：保持已连接状态，不允许在桌面上拖动；
- 传感器第二压力端口：保持未连接，不参与测量；
- 气缸、底座、支架和毫米刻度：只承担结构或读数作用；
- 顶部承载平台：随完整活塞组件共同运动，不作为独立运动对象；
- 相机旋转、平移、缩放和恢复视角：属于软件查看行为，不属于物理实验操作。

## 一轮实验的固定操作过程

### 一、实验准备

1. 确认已安装在支撑杆上的 TD-8572A 稳定；该安装和夹紧动作是实验前提，不要求用户在三维实验中重新完成。
2. 确认活塞杆、顶部平台和石墨活塞能够平顺运动，侧面锁紧螺钉能够旋紧和旋松。
3. 确认 PS-2181 已连接电脑数据接口，在采集板块中选择单路绝对压强测量通道。
4. 在可调的采样频率设置中选择 `1000 Hz`。
5. 将正式记录的开始条件设置为：绝对压强从高位下降并穿过触发阈值，即 `Falls Below`。
6. 关闭预记录，或将预记录时间设为 `0`，使向下按压产生的高压瞬态不写入正式振动数据。
7. 首次进入自由模式时，先直接输入或从下拉菜单选择 `3–6` 次实验，再从系统候选和自定义候选中框选恰好相同数量的目标点。次数和高度初始均为空；未达到相同数量时不得确认实验计划，确认后按目标高度从高到低执行。

### 二、首次设置 `80 mm`

首次设置使用仪器端软管初始已断开、气缸已通大气、侧面锁紧螺钉初始已松开的状态：

1. 托住顶部平台。
2. 沿气缸轴线移动活塞，使刻度读数达到 `80 mm`。
3. 保持 `80 mm` 不变，旋紧侧面锁紧螺钉，临时锁住活塞组件。
4. 将压力传感器软管接回仪器底座快接接口，恢复密封气路。
5. 旋松侧面锁紧螺钉，使活塞恢复自由运动。

旋松后，活塞在 `0.2 s` 内平滑、单向下沉到真实加载平衡高度；该时间属于物理时间。如果采集已经处于立即记录路径，这段下沉必须进入曲线。引导模式只有在气路已密封、螺钉已完全松开、双手已释放并完成加载平衡后才继续；真实高度只存在于后台，不主动显示给学生。

首次设置的固定顺序为：

`托住并调至 80 mm → 旋紧 → 接管 → 旋松 → 第一次按压`

```mermaid
flowchart LR
    A["初始：软管已断开、螺钉已松开"] --> B["托住平台并调至 80 mm"]
    B --> C["旋紧螺钉"]
    C --> D["接回软管，恢复密封"]
    D --> E["旋松螺钉"]
    E --> G["第一次按压与采集"]
```

### 三、激发并记录一次衰减振动

1. 使电脑采集进入待触发状态。
2. 实验者平稳向下按压顶部活塞组件。当前产品仍以约 `120–130 kPa` 和约 `1.1 s` 作为待校准演示参数，它们不是科学标准、物理常数或评分阈值；最终按压幅度和时间将在后续参数扫描中确定。
3. 达到本次按压状态后不要求故意停留，双手应尽量同时释放；正确操作的理想释放时间差为 `0`。旧演示中的额外停留不再解释为正确操作，释放后活塞围绕真实加载平衡位置做衰减振动。
4. 待触发期间仍持续读取绝对压强；实时监视图可以用灰色或淡色显示向下按压产生的高压段，但该部分不写入正式 Run。
5. 当前引导基线使用 `120 kPa` 下降阈值；最终值仍待后续参数扫描。自由模式使用用户提交的 `96.0–130.0 kPa` 阈值：若开始时真实压强已经达到或高于阈值，立即开始记录并保留下沉、按压、停留和释放过程；否则等待压力从高位下降穿过阈值后开始正式记录。
6. 正确实验设置固定为 `1000 Hz`，正式记录固定持续 `0.500 s`，保存包含 `t=0` 在内的 `501` 个样本。记录结束后，进入下一节的停止和高度切换流程；如果当前是本轮最后一个高度，则按“完成本轮采集”中的最终 Run 规则结束。

当前阶段顺序、周期选区、物理门禁和后续参数校准统一见 `piston-oscillation-integration-plan.md`；不再保留并行的旧基线文件。

### 四、相邻两次测量之间切换高度

完成当前高度的按压、松手和压力采集后，按以下顺序切换到下一个目标高度：

1. 停止当前 Run 的采集并保留该高度的独立原始时间序列和高度值；停止采集不会使仍在振动的活塞瞬间静止。
2. 等待活塞完全停止振动，回到当前平衡高度。
3. 托住顶部平台，并在后续断管过程中保持托住。
4. 从仪器底座快接接口断开压力传感器软管，使气缸通大气。
5. 沿气缸轴线移动活塞，使刻度读数达到下一个目标高度。
6. 保持目标高度不变，旋紧侧面锁紧螺钉，临时固定活塞组件。
7. 将压力传感器软管接回快接接口，恢复密封气路。
8. 旋松侧面锁紧螺钉，使活塞恢复自由运动。
9. 进入下一次按压、松手和压力采集。开始采集前仍由后台执行与首次采集相同的内部安全检查。

跨 Run 的固定顺序为：

`停止并稳定 → 托住 → 断管 → 调高 → 旋紧 → 接管 → 旋松 → 下一次按压`

```mermaid
flowchart LR
    A["停止当前 Run 的采集"] --> B["等待活塞完全停止振动"]
    B --> C["托住顶部平台"]
    C --> D["保持托住并断开软管"]
    D --> E["移动到下一目标高度"]
    E --> F["保持高度并旋紧螺钉"]
    F --> G["接回软管，恢复密封"]
    G --> H["旋松螺钉"]
    H --> J["下一次按压与采集"]
```

操作约束：

- 相邻两次测量之间，必须先停止采集并等待活塞完全停止振动，再托住平台并断开软管。
- 断管过程中必须持续托住顶部平台。
- 软管仍连接、气路密封时，不直接拖拽活塞改变实验平衡高度。
- 到达目标高度后必须先旋紧螺钉，再接回软管。
- 锁紧螺钉未最终旋松时，不得按压活塞、激发振动或开始正式采集。
- 正式采集时，软管必须接好、锁紧螺钉必须完全松开，双手已释放，且活塞处于静止的正确高度；这些条件由软件在后台守卫。

### 五、完成本轮采集

1. 首次在 `80 mm` 完成正式采集。
2. 每次都按“相邻两次测量之间切换高度”的固定顺序调整到本轮下一个目标高度；完整的六次方案依次调整到 `70、60、50、40、30 mm`。
3. 每个高度最终指定一条用于后续计算的正式原始曲线。引导模式按当前重做流程替换尚未保存的候选；自由模式必须保留错误操作事件和必要的尝试摘要用于过程评价，但不得把多个尝试同时冒充该高度的正式拟合点。
4. 本轮最后一个目标高度达到 `0.500 s` 正式记录后，暂停并冻结该固定 Run，再等待活塞完全停止振动；最后一个 Run 不再切换高度。
5. 本轮所选次数的曲线全部保存后，结束仪器操作阶段；一轮最多保存六条正式曲线。
6. 采集期间不穿插完整的周期计算和线性拟合；统一数据处理在本轮全部采集完成后进行。

## 软件分幕与主工作区内容结构

本节只固定每一幕承担的任务、必须呈现的内容和状态变化，不固定像素级排版、面板比例、按钮位置、控件样式或具体输入方法。

### A 幕：仪器操作与压力采集

A 幕在本轮各目标高度的正式采集中重复使用同一套主工作区，不为不同 Run 分别创建不同界面。

- 左侧保留可见且可操作的三维实验仪器，用于完成软管、锁紧螺钉、活塞高度和按压激振等真实物理操作。
- 右侧保留压力采集与曲线区域，用于呈现采集设置、采集状态、当前 Run 信息和本次绝对压强—时间曲线。
- 三维活塞振动与压力曲线来自同一轮物理过程。曲线表示压力传感器测得的绝对压强 `P(t)`，不是活塞位移曲线；活塞运动到气体压力、再到传感器输出的响应关系由后续底层模型实现。

A 幕的曲线区域依次经历以下四种呈现状态：

1. **设置完成、尚未开始**：采集设置已经准备好，但本次 Run 尚未进入待触发状态，正式曲线为空；此时是否仍显示传感器即时读数留待后续界面细化。
2. **已经开始、等待触发**：用户点击开始后，系统持续读取绝对压强并判断触发条件；此时只是待触发，不写入正式 Run。
3. **已经触发、实时记录**：活塞按压后松手，绝对压强从高位下降并穿过触发阈值时开始正式记录；`P(t)` 曲线随本次振动过程实时生长。
4. **已经停止、曲线保留**：用户停止采集后，正式曲线停止生长并冻结保留。活塞如仍有剩余振动，应继续按物理过程衰减直至稳定，停止采集不能使三维活塞瞬间静止。

停止后，用户必须能够查看本次完整曲线并判断其是否适合后续周期测量。接受并保存后，该曲线成为当前目标高度唯一参与后续处理的正式 Run，并进入下一目标高度；不接受则重采当前高度。重采只替换该高度的正式候选，不物理擦除旧尝试；旧尝试转为排除记录，不参与拟合。

点击开始、正式触发和停止采集是三个不同事件：

`点击开始并持续监测 → 等待下降穿越触发阈值 → 正式曲线实时生成 → 用户停止并冻结曲线`

等待触发期间是否在曲线区域显示滚动监视波形，或只显示当前压力和待触发状态，已经明确留待后续界面细化；无论采用哪种呈现，按压产生的触发前高压段都不写入正式 Run。

### 自由模式会话退出、恢复和重新选择计划

- “退出自由模式”只暂停当前自由模式会话，不等同于终止实验、重置数据或放弃本轮。对应按钮必须使用“退出”语义的图标与可访问名称，不使用“停止/终止”图标表达退出。
- 退出时保存本轮计划、各 Run 状态、当前目标高度、已提交采集设置、三维仪器状态、排除记录和操作审计；再次进入自由模式时直接恢复同一轮，而不是自动回到计划选择窗口。
- 若退出时正在等待触发，系统停止本次等待但保留会话，恢复后由用户重新点击开始；若正在记录，系统停止增长并把已有样本保留为尚未保存的候选，不得自动保存为正式 Run。
- 重新选择次数或高度只能从默认视角下方的进度组件打开三点菜单并执行“重置自由模式”。重置需要二次确认并提供可撤销恢复；完成后仍停留在自由模式，在原位置显示“设置新实验计划”，由用户主动打开空白计划窗口。
- 重置后创建全新的活动轮；旧轮不得继续参与新轮拟合，也不得与新计划共享 Run 编号。重新点击自由模式、刷新或重新打开文件都只恢复当前活动轮，不提供第二条改计划入口。

### 自由模式 Run 与删除层级

- 进度组件至少显示当前是第几个 Run、总 Run 数、当前目标高度，以及每个目标高度的未进行、候选待保存、已保存、已排除或待重采状态。
- “重做当前 Run”针对当前尚未保存的候选：候选转为排除记录，当前目标高度恢复为待采集；它不改变本轮次数和高度计划。
- “删除已保存 Run 并重采”针对一个已经保存的正式 Run：该 Run 从周期处理和拟合输入中移出并转为排除记录，该目标高度恢复为待采集。其他高度已保存的 Run 保持不变，当前进度回到按正式高度顺序最靠前的缺失项。
- “重置自由模式”是唯一允许改变本轮次数和目标高度集合的动作，不能用删除单个 Run 暗中改变计划数量。
- 任一高度同时只能有一条活动正式 Run。排除记录不能冒充正式拟合点，但必须保留原始样本、设置快照、主要物理状态、排除原因或触发动作和时间，保证撤销、恢复及过程评价有证据可用。

### B 幕：逐条曲线测周期

本轮所选次数的正式采集全部完成后，主工作区切换到 B 幕：

- 三维仪器区域完全隐藏，不继续占用可见空间；
- 压力曲线和周期测量区域扩展为中央主内容；
- 用户从本轮已接受曲线中逐条选择数据，在同一套界面中依次完成对应的周期测量；一轮最多处理六条曲线；
- 当前曲线默认以手型工具任意方向平移观察；点击工具键或按 `Shift` 切换为十字框选，完成一次有效框选后自动返回手型模式；
- 框选矩形只用于确定横向时间范围。软件从原始采样中标记范围内的全部波峰和波谷，以最左、最右极值点确定端点和半周期倍数 `N`，不从图像像素反推数据；
- 工具栏固定为“移动/框选”、“清除选区”、“恢复默认视图”三个图标键。普通滚轮始终滚动主工作区；鼠标位于图框内时，`Shift + 滚轮` 横向平移时间轴，`Ctrl + 滚轮` 缩放时间轴，只有这两种图表手势会阻止页面滚动；
- 当前曲线必须得到端点时间 `t₁`、`t₂`、周期数 `N`、时间差 `Δt`、平均周期 `T` 和 `T²`；
- B 幕只负责逐条曲线选点和周期测量，不在主工作区内完成最终线性拟合、比热容比或误差计算。

曲线区与测量结果区采用上下、左右或其他具体分隔方式，已经明确留待后续排版阶段根据主界面一致性确定。

### C、D：独立计算窗口

- C 阶段汇总本轮各组 `h`、`T`、`T²`，完成数据换算和 `h-T²` 线性拟合。
- D 阶段使用拟合斜率计算空气比热容比 `γ`，再计算相对误差并检查结果。
- C、D 不成为新的主工作区状态，而是使用独立弹出计算窗口；其产品逻辑与绝热膨胀法的计算窗口保持一致。
- B、C、D 在功能归属上统一进入左侧栏“数据处理”。完成后双击该节点首先打开 B 幕只读回顾，再由 B 幕中的“查看拟合与计算”打开 C、D 计算回顾窗口。

### 结果与过程回顾

结果输出不作为第三种主工作区状态。本轮正式曲线、周期选点、用户答案与校验次数保存在 B 幕回顾中；拟合结果、比热容比和误差保存在 C、D 窗口回顾中。回顾状态可切换 Run 和调整图表视图，但不能改写已保存的选区、答案、拟合或计算结果；本轮引导不设置额外的左侧栏子节点。

引导尚未完成时，终止或重置按既有规则清除本轮数据；引导完成后，“退出引导”只结束当前模式选择，不删除正式观测记录、选点、答案、拟合和计算结果。用户可从左侧栏重复打开回顾，也可再次选择引导模式回到已完成状态；只有显式重置才开始一轮新的空白引导。

自由模式的过程回顾同时读取活动正式 Run 与排除记录。删除、重做或放弃本轮不会让错误操作证据参与最终拟合，但也不能使这些证据从过程评价中消失；恢复文件后仍须保持这一区分。

## 实时采集板块的固定内容

本节只固定采集阶段必须提供的信息和状态，不固定它们在界面中的具体位置、尺寸、控件外形或输入方式。

### 采集设置

实时采集板块必须允许用户查看和设置：

- 测量来源：PS-2181 的单路绝对压强通道；
- 采样频率：允许用户调整，最高和正确目标设置为 `1000 Hz`；
- 开始条件：绝对压强 `Falls Below`；
- 触发阈值及其压力单位；
- 预记录：正式实验中关闭或设为 `0`；
- 当前引导停止方式：下降触发后固定保留 `0.500 s / 501` 点，达到时长后允许暂停并冻结。

当前引导实现使用 `1000 Hz` 和 `120 kPa` 下降触发，其中触发压强仍是后续待校准参数。自由模式使用以下唯一输入与提交规则：

- 采样频率接受 `1–1000 Hz` 的整数；`1000 Hz` 是正确基线，也是 PS-2181 的最高采样频率。
- 下降触发阈值接受 `96.0–130.0 kPa` 的绝对压强，输入和显示粒度为 `0.1 kPa`。软件必须在这个完整区间内动态调整纵轴，使阈值线上下各保留可读空间；`120.0 kPa` 是当前引导实现值，不是最终科学标准。
- 输入框在编辑期间允许为空或保留尚未完成的数字草稿；`Enter` 或失焦提交，`Escape` 放弃草稿并恢复上次已提交值。输入过程中不得逐键截断、钳制或自动替换用户内容。
- 语法无效或超出仪器能力的草稿不能应用，也不能开始本次采集；界面只在字段附近说明该设置尚未应用并保留上次有效值，不弹出“实验步骤做错了”的业务提示。
- 仪器能力范围内但偏离正确基线的值必须允许提交和开始采集。系统不弹错、不自动纠正；采样不足、提前触发、无法发生下降穿越等后果进入曲线、实验进程和过程评价。
- 未开始或已经停止时允许修改设置；等待触发和正式记录期间锁定本次设置。每个候选与正式 Run 都保存实际使用的设置快照，不要求一轮内各 Run 使用相同设置。
- 数字输入框、增减控件或其他展示入口必须读写同一份“草稿值/已提交值”状态，不得保留只对某些预设数字生效的第二套输入路径。采样率输入按 `Enter` 后将焦点移动到触发阈值；阈值输入按 `Enter` 后只提交并退出输入状态，不自动开始实验或记录。

自由模式由用户手动暂停并保存候选；最后一个 Run 完成周期核验后自动打开独立计算窗口，不显示固定组数提示或额外“进入计算”按钮。

### 实时图像和数值

采集阶段只要求一张核心实时图像：绝对压强—时间曲线 `P(t)`。

该图和相邻状态信息必须呈现：

- 横轴时间及单位、纵轴绝对压强及单位；
- 当前绝对压强数值；
- 当前压力基线；
- 触发阈值线；
- 采集状态：未准备、等待触发、正式记录、已停止；
- 当前高度和 Run 编号，例如完整六次方案中的 `80 mm · 1/6`；
- 已记录时间或样本数；
- 本轮目标高度各自的状态：未进行、等待触发、记录中、已保存或需要重采；目标高度最多六个。

等待触发期间是否显示灰色或淡色的监视数据留待后续界面细化。正式 Run 必须从压力下降穿过阈值后开始，按压高压段不进入已保存数据；触发后实时生成、停止后冻结展示的正式曲线只包含正式 Run。

### 已保存曲线和质量提示

- 采集时默认只显示当前曲线，不默认叠加本轮其他曲线。
- 已保存 Run 通过本轮状态列表选择查看；切换查看不改变原始数据。
- 引导模式应对未触发、超出传感器量程、振幅过小、完整周期过少或噪声过大等情况给出对应提示，并按教学流程允许或要求用户重采。
- 自由模式不弹出“这一步做错了”的业务提示，也不为得到理想结果而自动纠正操作；错误只通过真实模型改变实验进程、曲线和结果。系统在后台保留操作事件、严重程度依据和结果影响，供过程回顾统一评价。
- 自由模式中，确实无法继续的物理状态可以自然阻断后续动作；仍能得到数据的错误状态必须允许用户继续处理，即使最终得到较差或有偏差的结果。

### 采集阶段不需要呈现的内容

- 第二路绝对压强、表压或差压曲线；
- 温度、体积、活塞速度等未参与本次采集的量；
- `h-T²` 拟合图、比热容比和相对误差；
- PASCO Capstone 的完整菜单、工具栏或电脑桌面复刻。

## 数据处理与计算过程

本轮全部采集完成后，数据处理固定分为三个主阶段：逐条曲线测周期、汇总并线性拟合、计算比热容比与相对误差。本轮曲线在第一个阶段内依次处理，不拆成彼此独立的计算流程。

### 第一阶段：逐条曲线测量振动周期

对每一条压力-时间曲线：

1. 从本轮 Run 列表中选择一条已保存曲线。
2. 在手型模式下平移或缩放时间轴，找到衰减振动的清晰区段。
3. 切换为十字模式并横向框选时间范围。软件直接分析原始时间—绝对压强采样，自动给出范围内极值点、左右端点坐标和周期数 `N`。
4. 用户首先输入并一次校验信息框中的横坐标 `t₁`、`t₂`，确认读取的是时间轴。
5. 根据 `Δt = t₂ - t₁` 和系统确定的 `N` 计算平均周期，再单独提交校验：

   `T = Δt / N`

6. 校验通过或查看正确值后，软件记录该 Run 的选区、端点样本索引、相位类型、`t₁`、`t₂`、`N`、`Δt`、`T`、`T²` 和活塞高度 `h`。
7. 按同样方法完成本轮其余曲线。

计数规则：如果从第一个波峰量到第 `n` 个波峰，两者之间的完整周期数是 `n - 1`，不能直接用波峰个数作为除数。

正确操作的选区不从 `t=0`、触发穿越点或释放瞬间起框。先越过触发后的非周期启动段，以第一个清晰、完整的波峰或波谷为起点，并以同相位极值结束。默认选择 `3` 个完整周期；第 `4` 个周期只有在振幅、弧线和周期宽度仍清晰时才纳入，末端接近噪声或出现额外小峰、小谷时必须舍弃。不得为了使拟合或 `γ` 更接近理论值而反向移动选区。

如果第一个完整周期已经明显畸变，并且后面仍保有至少三个完整周期，可以将起点顺延到下一个同相位极值；当前规则不统一强制舍弃第一个完整周期。自由模式允许用户用少于三个周期继续处理，但必须记录该操作及其结果影响，不把它判定为正确操作基线。

正式结果以用户框选范围和两次校验确认的结果为准。自动极值识别只在用户指定的时间范围内运行，不得跳过用户框选、端点读数校验或周期计算校验。

### 第二阶段：汇总与线性拟合

1. 汇总本轮各组 `h`、`T` 和 `T²`。
2. 将进入拟合与公式计算的量统一换算为 SI 单位。
3. 以 `T²` 为横轴、活塞高度 `h` 为纵轴作图。
4. 对本轮各高度的数据进行线性拟合：

   `h = sT² + b`

5. 给出拟合斜率 `s`、截距 `b` 和决定系数 `R²`，并保留查看残差的能力。

其中 `s` 是计算比热容比所需的拟合斜率，截距 `b` 与刻度零点以下的等效死体积高度有关。`R²` 和残差用于帮助判断拟合质量，不单独代替有效曲线判据。

### 第三阶段：计算空气比热容比与相对误差

拉氏法的小振动模型给出：

`h = [γAP / (4π²m)]T² - h₀`

因此：

`s = γAP / (4π²m)`

空气比热容比为：

`γ = 4π²ms / (AP)`

该阶段依次执行：

1. 取活塞直径 `d`，计算横截面积 `A = πd²/4`；
2. 使用总运动质量 `m`、拟合斜率 `s`、横截面积 `A` 和计算压力 `P` 计算 `γ`；
3. 将实验结果与空气参考值 `1.40` 比较；
4. 计算并显示相对误差。

计算时统一使用 SI 单位：

- `h`：米；
- `T`：秒；
- `m`：千克；
- `A`：平方米；
- `P`：帕；
- `s`：米每平方秒。

参数定义：

- `m`：石墨活塞、活塞杆、顶部平台及所有随其共同振动的附加质量之和；
- `A`：活塞横截面积；
- `P`：平衡状态下气体的绝对压强，本实验默认用 `1.01 × 10^5 Pa`；
- `h₀`：标尺零点以下未直接标出的等效气柱高度。

可将实验值与空气的理想参考值 `γ = 1.40` 比较，并计算相对误差：

`相对误差 = |γ实验 - 1.40| / 1.40 × 100%`

## 已固化的模型与基础交互约束

### 1. 唯一正式模型

- 正式资产路径为 `public/models/piston-oscillation/piston-oscillation.glb`。
- 模型内已经固化 `32.5 mm` 活塞直径、`0–85 mm` 刻线、`10–80 mm` 数字、加长玻璃气缸与保护框架、后侧实心读数背景、低反光深蓝灰塑料材质以及顶部主光源适配。
- 正式运行只加载该资产；模型来源、哈希、尺寸和状态合同记录在同目录 `model-provenance.json`。

### 2. 活塞和刻度

- `PistonAssembly_MOV` 沿世界 `Y` 轴运动，石墨活塞下沿作为高度读数基准。
- 石墨活塞下沿到达最高位置时对准 `85 mm` 刻线；推荐实验范围为 `30–80 mm`，自由模式计划允许 `10–80 mm` 整数目标。
- 石墨活塞、活塞杆和顶部平台作为同一个运动组件同步移动；在最低允许按压位置仍保留结构间隙，不发生穿模。

### 3. 侧面锁紧螺钉

- 正式模型包含滚花手拧头、螺纹轴、安装螺纹座、接触端和旋转见证标记。
- 软件操作行程固定为旋转 `3` 圈并轴向移动 `4 mm`；鼠标完成全行程同样保持 `3` 圈，只将每圈轴向推进距离放大为原来的两倍。
- 螺钉行程达到 `60%` 后锁定活塞组件竖直平移；低于该阈值时，剩余压紧量连续影响平台失去手部支撑后的下落加速度。

### 4. 软管和快接接口

- 模型同时包含接通软管和断开放置软管两种形态。
- 大白色旋转环及六个防滑环固定在仪器平台上；小白色接头随软管拔出和接回。
- 软管拖拽使用半透明幽灵预览和磁吸判定；接通与断开使用同一磁吸范围。

### 5. 运行时状态分离

- 软件层分别保存软管状态、锁紧螺钉进度、连续平衡高度、活塞运动状态和相对振动位移。
- 密封状态只禁止直接重新设定平衡高度；螺钉松开时，活塞仍可被按压并围绕平衡位置振动。
- 压力传感器拖动、数据接口拖动、支撑杆夹紧旋钮和数据线插拔不进入核心状态机。

## 正式观测数据与数值处理口径

用户实验数据必须经过传感器观测层，固定数据链为：底层物理过程 → `1000 Hz` 离散采样 → 绝对压强按 `0.01 kPa` 向零截断 → 保存正式观测样本 → 绘图、识别极值、框选端点、计算周期、拟合和计算 `γ`。底层高精度压力不得绕过传感器观测层进入用户图表或后续计算。

- 正式采样时刻由样本序号唯一确定，只能为 `0.000 s`、`0.001 s`、`0.002 s`……，界面固定显示三位小数。
- 正式压强固定显示两位小数；CSV 省略末尾零只属于导出格式，不改变 `0.01 kPa` 的仪器粒度。
- 压强量化只在传感器观测阶段执行一次；正式原始记录保存量化后的时间—压强样本，并另存物理参数快照、物理模型版本和观测模型版本。
- 压力图由正式观测样本逐点直线连接，不进行曲线平滑；普通样本点可以按显示密度弱化，但不得因此抽稀计算或持久化数据。
- 波峰、波谷和左右端点只在正式观测样本中确定。端点以样本序号为恢复依据，同时保存对应的三位小数时间和两位小数压强；不读取连续极值时间，也不进行亚采样插值。
- 用户先分别提交 `t₁`、`t₂`，精确校验通过后，再按系统给出的 `N` 计算并提交 `T=(t₂-t₁)/N`。`t₁`、`t₂` 和规定精度的 `T` 都有唯一标准结果；数值正确但书写精度不足时必须单独反馈精度错误。
- 传感器观测阶段的压强使用向零截断；用户实验计算中凡要求保留小数位或有效数字，统一使用“四舍六入五成双”。两套规则不得混用。
- `T²`、线性拟合、斜率、`γ` 和相对误差都从通过校验的正式 `T` 继续计算，使离散采样与仪器精度误差正常传递。
- 极值识别、线性拟合和公式计算分别保存算法或模型版本。恢复时只允许按已支持版本重算；当前唯一旧格式中缺失的拟合版本可显式迁移为 `ordinary-least-squares-v1`，未知版本不得静默套用当前算法，而应退回对应的重新选点或重新拟合阶段。

## 外部事实缺口与已明确的后续细化项

本节严格区分两类内容：第一类是必须依靠实物、可靠资料或测量才能消除的外部事实缺口；第二类是已经明确安排到后续阶段再决定的设计参数。第二类不视为当前流程中的未知假设，也不阻碍本文已固定内容成立。

### 仍需外部证据消除的事实缺口

1. **锁紧螺钉内部接触结构**：官方确认有侧面锁紧螺钉，也确认其用于固定活塞；但公开资料没有内部剖面。当前将其理解为螺纹轴径向压紧长活塞杆，这是结构推断。
2. **锁紧螺钉实物规格**：螺纹旋向、直径、螺距、接触端形状和准确安装尺寸尚无可靠公开数据。软件模型已经固定操作行程，该行程不作为实物尺寸证据。
3. **压力传感器的精确端口名称**：已确认使用 PS-2181 的绝对压强和单根软管，但真实传感器上的物理接口标识、软件测量项名称及二者映射尚未固定。
4. **额外随动质量**：本机铭牌已经确认基础活塞与平台总质量为 `48.5 g ± 0.6 g`；如果后续实物实验增加配重或其他随动部件，其质量和是否随活塞共同运动仍需逐项确认，不能沿用基础质量猜测。

以上事实缺口不得由软件设计自行猜测；取得可靠证据后直接替换为唯一有效结论。

### 已明确留待后续细化的项目

以下项目的处理阶段已经确定，不属于未识别的假设：

1. **目标高度判定容差**：当前引导模式放行容差固定为 `0.25 mm`；自由模式中怎样把偏离量划分为合理、小过失和严重错误，留待评价设计阶段确定。
2. **按压动作的定量规则**：当前约 `120–130 kPa` 和约 `1.1 s` 只作为待校准产品参数，不视为科学标准；最终按压幅度、时间、是否停留，以及小过失与严重错误区间，留待后续资料核验和参数扫描确定。
3. **触发与记录**：采样率范围、自由模式 `96.0–130.0 kPa` 阈值范围、立即记录与下降穿越两条路径已经固定；引导最终阈值、按压范围和不同错误设置的评分影响仍待后续模型阶段校准。
4. **后台前置与曲线质量阈值**：松开螺钉后的 `0.2 s` 单向加载平衡已固定；引导还按气路、螺钉、双手和 `0.25 mm` 名义高度容差放行。周期宽度变异、尾部最低振幅、噪声和曲线畸变的正式阈值留待真实模型与评分阶段确定。
5. **周期测量细则**：已经固定用同相端点跨多个完整周期计算 `T = Δt/N`，现行选区规则统一记录在 `piston-oscillation-integration-plan.md`。端点继续采用原始采样数据中的实际波峰或波谷，不启用亚采样极值时间。
6. **环境与热交换**：底层平衡计算使用精确标准大气压和真实加载后体积，学生计算仍使用 `1.01 × 10^5 Pa` 与名义高度。温度、内能等状态已经预留但当前保持惰性；显式热交换接入后再确定准静态压缩和绝热振动中的热交换响应。
