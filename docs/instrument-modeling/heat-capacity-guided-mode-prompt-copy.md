# 热容比实验引导模式提示文案草稿

本文档记录引导模式的当前约定文案和交互规则，用于后续 UI 继续细化时对齐口径。

## 核心规则

- 引导模式按最佳实验流程推进，错误或提前点击只给反馈，不记录数据、不推进状态。
- 常规流程说明显示在右侧实时数据面板的“当前提示”区域。
- 用户提前点击、点错控件、触发提醒或报警时，提示显示在三维窗口中心区域。
- 到达三个目标时机后暂停三维物理演进和分子可视化：U1 等待满 5 分钟、放气开阀满 0.35 秒、U2 等待满 5 分钟。
- 暂停后 10 秒内未完成目标操作，或累计两次点击非目标控件/提前记录，进入强提醒。
- 强提醒统一文案：请点击目标控件，继续实验。

|---|---|---|

## 强提醒

- 触发条件：目标时机到达后 10 秒未操作，或累计两次错误/提前点击。
- 显示方式：三维窗口出现半透明蒙版、圆形高亮框和统一提示文案。
- 当前实现先提供遮罩与圆形提示；后续可继续细化为“只允许圆形目标区域点击生效”。

## 备注

- 可视控件的错误点击可做回弹反馈：电源开关、玻璃旋塞、打气球、压力调零旋钮。
- 记录按钮错误点击只显示反馈，不做回弹动画。
- 三个暂停点解除后，实验只能通过目标操作继续推进。
