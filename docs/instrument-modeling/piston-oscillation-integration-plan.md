# 活塞振动法完整开发路线图

## 文档用途

- 本文是活塞振动法实验模式的唯一现行开发路线图。
- 当前目标是在已有接入基础上完成活塞振动法的仪器操作、压力采集、数据处理、计算、结果、保存与回顾闭环。
- 已确认的真实物理操作顺序、仪器状态、采集内容和计算关系，以 `piston-oscillation-experiment-spec.md` 为准；本文只规定开发先后顺序、阶段边界、交付物和验收门禁。
- 各阶段尚未开始时，不提前假定该阶段的具体交互、数值或物理参数。用户已经明确安排到后续阶段再确认的内容，不视为当前工作流中的不确定性。

## 当前开发基础

- 活塞振动法拥有独立文件类型 `kind: 'heatCapacityPistonOscillation'`，不进入 standard、ideal 或绝热膨胀法运行时。
- 已有独立的持久化载荷、文件创建与恢复路径、工作区外壳和实验入口。
- 已固化唯一正式 GLB，并建立模型来源与哈希记录、加载失败处理和关键节点合同测试。
- 已有总览、前视、侧视、顶视和恢复默认视角能力。
- 模型只在活塞振动法激活时挂载，多文件不得共享会被修改的场景实例；文件切换和卸载仍需正确停止动画并释放组件拥有的资源。
- Three.js Scene、Object3D、Renderer、材质、纹理、相机控制器和动画播放器等运行时对象不得直接写入实验持久化数据。

## 2026-08-25 当前执行断点（覆盖下文历史阶段的先后顺序）

下文阶段 1–6 保留为已经形成的历史开发分解和资产边界；从 2026-08-25 起，当前实现与验收改按以下四个断点推进：

1. **基础正确性和数值处理**：分离物理状态、传感器观测、派生结果和交互会话；正式记录采用 1000 Hz 离散时间与 0.01 kPa 向零截断压力；图表、极值、端点和计算只使用正式观测样本；实现五成双实验计算、版本迁移、恢复重算及引导闭环。
2. **物理模型基线校准**：在不把单一真实数据集当作唯一真值的前提下，校准周期量级、随高度趋势、衰减持续时间、压力口径、触发与记录策略，并建立新的物理模型版本说明。
3. **自由模式骨架**：引入动态 experiment plan，支持 3–6 组 Run、高度设置、返回、重做、删除、重新框选、动态拟合、过程回顾以及完整保存恢复；先使用断点二的固定模型版本。
4. **模型深化和变量开放**：利用自由模式分析高度、按压幅度、质量、摩擦、阻尼、采样率、噪声和触发策略，只把具有实验意义且可解释的变量开放给用户。

工作流测试使用固定观测记录，不随物理参数调整；科学结果测试必须绑定明确的物理模型版本。真实实验参考数据只用于断点二的量级和趋势约束。2026-08-25 用户另以本机铭牌确认 `48.5 g ± 0.6 g` 运动质量和 `32.5 mm ± 0.1 mm` 活塞直径，断点二据此建立 `piston-oscillation-rk4-pasco-td8572a-v2` 基础版本；这属于仪器直接证据更新，不是用四组曲线反拟合质量。

### 断点二最终边界（2026-08-25 确认）

- 断点二只完成引导模式固定基础模型，不开始自由模式或完整真实物理模型；
- `γ = 1.40` 是版本化的软件空气客观物性，状态方程、原始测量物理快照和相对误差共用同一来源；
- 正式固定参数为 `48.5 g` 运动质量、`32.5 mm` 活塞直径，以及包含气缸、软管、接口和传感器腔体的有效气体体积；
- 正式观测继续使用 `1000 Hz` 和 `0.01 kPa` 向零截断；
- 现有 `0.434 N·s/m` 只作为版本化临时等效损耗保留，以维持已验收引导曲线，不解释为真实机械摩擦或热力学阻尼；
- 零损耗绝热模型仅用于后台不变量测试，不成为第二套产品模型；
- 热交换、熵变化、机械摩擦、软管动态响应、传感器噪声、平台、次峰及自由模式功能全部留待后续阶段。

## 已固定的总体工作流

活塞振动法按照以下顺序开发：

`正式仪器模型 → 交互规则与交互动效 → 高质量预置数据驱动的 A 幕 → 预置数据驱动的完整实验闭环 → 底层物理模型替换预置数据源 → 验证、评分与产品收口`

总体原则：

1. 每一阶段必须先通过本阶段验收，再进入下一阶段。
2. 正式模型统一使用 `public/models/piston-oscillation/piston-oscillation.glb`；运行时只驱动正式节点状态。
3. 交互层、运动表现层、实验流程层和数据来源层相互分离。未来接入真实物理模型时，不重做已经验收的命中、操作、界面和数据处理流程。
4. 先用可控的高质量预置数据打通流程，再建立物理模型；不允许为了提前求解物理而阻塞模型、交互和完整流程验收。
5. 物理模型成熟后，通过与预置数据相同的输出接口向三维仪器、压力曲线和后续计算供数。
6. 绝热膨胀法 v5.3.1 继续作为稳定基线，只处理确实阻断活塞振动法开发的问题，不主动重构。
7. 全局软件教程和活塞振动法逐步解锁教程继续延期，待两个核心实验的正式功能均完成后统一制作。

## 阶段 1：正式模型资产交付（已完成）

### 目标

交付具备正式交互所需结构、比例、节点、轴心和行程的唯一模型资产，并把模型资产、交互状态和页面外壳分离。

### 工作范围

- 固化活塞侧面锁紧螺钉、正式软管两种形态和快接接口结构。
- 固化数字最高 `80 mm`、刻线最高 `85 mm` 的刻度。
- 固化官方 `32.5 mm` 活塞直径和世界 `Y` 轴运动合同。
- 建立连续 `30–80 mm` 正式高度与模型可见位置、刻度读数之间的一一映射。
- 保证活塞、活塞杆、顶部平台作为一个完整运动组件同步移动。
- 为锁紧螺钉建立正确旋转轴、少量轴向进退和锁紧/松开终点。
- 为仪器端软管建立可控制的末端、连接锚点、断开位置和必要的动态形变基础。
- 为软管接头、锁紧螺钉和活塞组件准备彼此独立的命中对象或运行时命中体。
- 修复会影响操作的穿模、悬空、遮挡、错误轴心、比例和相机可见性问题。
- 保持压力传感器、数据接口、数据线、支撑杆夹具和其他非核心部件为正确的静态状态。

### 交付物

- 软件内唯一正式仪器资产 `public/models/piston-oscillation/piston-oscillation.glb`。
- 核心节点、运行时补充部件、运动轴、轴心、行程和父子关系清单。
- `30–80 mm` 正式高度映射与刻度核对结果。
- 软管、螺钉和活塞组件的独立测试运动。
- 模型关键视角检查结果和必要的资产来源记录。
- 对应的模型合同与回归测试。

### 验收标准

- 三类核心对象可以在软件内被分别识别和独立驱动。
- 所有运动方向、轴心、限位和父子联动正确，无明显跳变或穿模。
- 六个正式目标高度都能与可见刻度正确对应。
- 锁紧螺钉和软管连接结构在默认及关键操作视角下清晰可见。
- 静态预览、相机、离线加载、桌面环境和既有实验没有回归。

## 阶段 2：交互规则与交互动效

### 目标

建立用户如何命中、启动、持续、完成、取消和恢复每个仪器动作的唯一规则，并使运动表现符合真实操作感。本阶段仍不要求真实压力或振动数据。

### 已固定边界

- 第一版正式输入设备为鼠标和常规键盘。
- 双手按压使用 `Space + 鼠标左键`；两者全部松开后释放活塞，并记录两手松开时间差。
- 当前正式交互只有 `Space` 与鼠标左键同时就位时才允许活塞下压；软管接通后的单鼠标操作不改变螺钉操作镜。单手按压的真实偏斜、摩擦响应及对应提示留待自由模式设计时统一完善。
- 软管使用聚焦状态下的拖拽、幽灵预览和双向磁吸判定。
- 调节平衡高度时，鼠标拖动表示单手提拉平台；提拉过程中按下 `Space` 表示另一只手接住平台，以便释放鼠标操作锁紧螺钉。两只手都未托住且螺钉仍处于松开状态时，平台按当前螺钉压力对应的加速度下落。
- 交互必须遵守实验规范中的首次 `80 mm` 设置顺序和跨 Run 固定顺序。

### 工作范围

- 统一单击、拖动、旋转、保持、取消和键盘辅助规则。
- 确定可见模型与透明命中体的对应关系、命中优先级和允许范围。
- 建立悬停、选中、操作中、不可操作、到达限位和顺序错误反馈。
- 解决部件操作与相机旋转、缩放、视角切换之间的冲突。
- 建立软管、锁紧螺钉、活塞平衡高度、活塞按压与振动、采集状态的组合状态机。
- 规定每个动作的前置条件、启动方式、连续运动、完成条件、提交阈值、取消方式和回退表现。
- 制作软管解锁、拔出、接回和恢复密封的运动表现。
- 制作锁紧螺钉旋转并少量轴向进退的运动表现。
- 制作托住、调节高度、保持目标高度和恢复自由运动的连续表现。
- 制作活塞向下按压时逐渐增强的压缩阻力感，以及松手后的连续衰减振动表现。
- 处理指针移出、窗口失焦、Escape、切换视角、错误顺序和动作中断。

### 交付物

- 仪器交互规则和状态转换规范。
- 每个核心对象的命中、手势、动效和反馈说明。
- 不依赖压力数据的仪器操作沙盒。
- 首次设置和跨 Run 操作的可执行演示。

### 验收标准

- 用户能够使用鼠标和键盘完成全部真实仪器操作顺序。
- 对象操作不会与相机控制争抢输入。
- 合法操作连续可控，非法操作有清晰原因，取消和中断不会留下破坏性中间状态。
- 模型运动具有一致的速度、阻力、限位和结束反馈，不依赖固定整段视频或不可中断动画。

## 阶段 3：高质量预置数据驱动的 A 幕

### 目标

先使用一套质量良好的预置数据，打通一次完整的“仪器操作—等待触发—实时曲线—停止并检查”流程。该预置数据只负责稳定演示和验证流程，不被冒充为真实物理求解结果。

### 工作范围

- 定义预置数据和未来物理模型共同遵循的输出接口。
- 使用同一实验时钟驱动活塞运动、压力采样、触发事件和曲线绘制。
- 区分活塞平衡高度、相对振动位移、气缸绝对压强和传感器输出绝对压强。
- 点击开始后进入持续监测和等待触发，而不是立即写入正式 Run。
- 压力下降穿越阈值后，正式 `P(t)` 曲线开始实时生成。
- 触发前的按压高压段不进入正式保存曲线。
- 用户停止采集后冻结曲线；三维活塞继续按预置轨迹衰减至稳定。
- 支持查看本次完整曲线，并为以后加入“接受或重采”操作预留状态。
- 预置压力数据支持正确的 `1000 Hz` 时间轴；三维渲染使用同一时间轴进行插值，不以渲染帧冒充压力样本。

### 交付物

- 一套经过检查的高质量预置活塞运动和绝对压力数据。
- 稳定的数据提供接口和统一实验时钟。
- 能够完成一次正式 Run 的 A 幕。
- 三维运动、触发状态和实时压力曲线的同步验证。

### 验收标准

- 一次完整 Run 可以从设置、开始监测、按压、触发、记录、停止一直执行到曲线保留。
- 三维仪器和压力曲线在同一事件时刻开始、触发和结束，不发生可见漂移。
- 正式保存数据不包含触发前按压高压段。
- 预置数据源可以被独立替换，而无需改动三维操作和曲线界面。

## 阶段 4：预置数据驱动的完整实验闭环

### 目标

在不依赖真实物理求解的情况下，把活塞振动法从用户所选次数的仪器操作一直打通到最终计算、结果和过程回顾；自由模式一轮最多六次。

### 工作范围

- 将阶段 3 的单次高质量预置数据方案扩展到 `80、70、60、50、40、30 mm` 六个正式高度。
- 为自由模式建立可选择的本轮测量次数，最大值固定为六次；选择控件、默认次数及少于六次时的目标高度选取规则在本阶段进入对应子任务时确认。
- 完成当前高度、Run 进度、接受、重采和进入下一高度的流程。
- 完成本轮所选次数的采集后，从 A 幕切换到 B 幕并隐藏三维仪器。
- 完成本轮各条曲线的同相位端点选择、完整周期数、`Δt`、`T` 和 `T²` 处理；一轮最多六条曲线。
- 完成本轮各组数据汇总、单位换算和 `h-T²` 线性拟合。
- 完成比热容比、相对误差和结果检查。
- 完成结果、曲线、选点、拟合和操作过程的回顾结构。
- 完成必要的实验数据保存、恢复和导出结构。
- 具体数据选取、计算窗口、误差交互和页面排版在进入对应子阶段时逐项确认，不在此前提前定稿。

### 交付物

- 使用预置数据可以完整完成的一轮实验，且可覆盖六个正式高度的上限方案。
- B 幕、独立计算窗口和过程回顾的完整功能链。
- 可以保存、关闭、恢复并继续处理的实验数据。
- 可供后续物理模型替换的数据来源边界。

### 验收标准

- 用户不依赖开发工具即可从首次设置完成到最终结果。
- 本轮 Run、曲线和周期数据一一对应，不发生串组或覆盖；各集合均不得超过六组。
- 保存恢复后仪器阶段、数据处理阶段和结果保持一致。
- 所有计算使用规范中固定的量、单位和公式。

## 阶段 5：底层物理模型接入并替换预置数据源

### 目标

在不改变已验收交互和完整流程的前提下，让实验结果由真实物理模型产生，并由物理模型生成或实时输出正式实验数据。

### 工作范围

- 建立活塞和全部随动组件的动力学模型。
- 建立密闭气体压力、活塞位移、平衡高度、活塞面积、运动质量和大气压之间的关系。
- 建立按压位移、按压速度、松手状态和阻尼对振动的影响。
- 建立软管连接、气路密封、通大气和锁紧状态对允许运动及压力的影响。
- 建立不同高度下的周期和压力曲线。
- 建立传感器采样率、量程、响应延迟、噪声、分辨率和必要滤波。
- 建立可调参数对运动、曲线、拟合和最终结果的完整传递。
- 建立错误操作和不良实验条件产生的可解释结果。
- 用物理模型输出接管阶段 3 固定的数据接口，并对预置数据与物理输出进行对照验证。

### 交付物

- 可配置、可测试、可重复的活塞振动物理模型。
- 物理状态到三维运动、传感器输出和正式曲线的数据适配层。
- 与解析关系、参考资料和预期实验范围的校准报告。
- 正常与典型错误操作测试数据。

### 验收标准

- 切换到物理数据源后，不需要重写模型命中、交互动效、A/B 幕、计算和保存流程。
- 高度、质量、压力和操作变化产生方向正确、量级合理且可解释的结果。
- 传感器曲线与真实活塞状态允许存在模型规定的延迟和噪声，但时间关系稳定、可复现。
- 本轮数据能够形成合理拟合，并给出可解释的比热容比和误差；完整上限方案可使用六组数据进行验证。

## 阶段 6：验证、评分与产品收口

### 工作范围

- 完善有效曲线判据、操作质量评价、结果评分和诊断解释。
- 完善重采旧尝试的保存规则、多实验组管理、恢复和三类导出。
- 完善过程回顾、结果比较、异常说明和报告内容。
- 检查亮色、暗色、常用分辨率、Windows 缩放、键盘行为和性能。
- 回归绝热膨胀法稳定基线和其他实验文件类型。
- 两个核心实验正式功能均完成后，再统一制作全局软件教程、活塞振动法演示/引导/自由逐步解锁和教学文案。

### 验收标准

- 活塞振动法具备与绝热膨胀法同等级的正式实验闭环。
- 操作、数据、计算、评分、回顾、保存、恢复和导出使用一致的数据来源。
- 桌面安装包、离线运行、自动更新和发布资产通过正式版本门禁。

## 已明确留待对应阶段确认的内容

以下事项的处理阶段已经确定，因此不构成当前路线图的阻塞问题：
