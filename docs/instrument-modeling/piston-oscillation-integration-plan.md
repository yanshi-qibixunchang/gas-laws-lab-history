## 1. 总体目标与不可偏离的原则

### 1.1 产品目标

活塞振动法自由模式的最终目标不是制造任意“坏曲线”，而是建立具有可信因果关系的教学模型：

1. 正确操作应得到合理、稳定、可以解释的曲线和计算结果。
2. 错误操作应通过真实物理后果影响实验进程、波形、可用周期或拟合结果。
3. 不能继续的错误应让仪器因物理状态而无法继续，而不是由软件弹窗替用户判错。
4. 仍能得到数据的错误必须产生相应偏差，不能让错误动作仍然稳定返回正确值。
5. 每一种新增影响都要有明确输入、物理机制、参数来源、输出和适用边界，不能用一个不可解释的“坏曲线系数”混合代替多种原因。

### 1.2 三种模式的关系

- **演示模式**：展示当前已确认的最佳标准流程和标准参数。
- **引导模式**：把最佳流程作为教学标准，阻止或要求重做会破坏主线教学结果的关键错误，并在适当节点解释原因。
- **自由模式**：允许用户自由操作；不弹“这一步做错了”一类即时判错提示，不强制纠正，也不为了维持流程而静默修正用户输入。错误只通过仪器状态、数据质量、计算偏差和后续过程回顾体现。
- 引导模式是自由模式评价的参考标准，但不是自由模式运行时的步骤守卫。两种模式应共用同一套底层物理机制，只在非理想因素开关、流程守卫和反馈策略上不同。

### 1.3 建模顺序

- 先建立能严格自洽的理想物理基线，再逐个增加真实机制。
- 每加入一个模型，都先验证正确操作，再验证该模型对应的错误操作。
- 参数优化不能用来补偿另一个未建模错误，也不能通过两种偏差相互抵消来“调出” `γ = 1.40`。
- 单项模型都有独立证据和回归锚点后，才允许联合校准。
- `0.434 N·s/m` 保留为按压阶段和旧存档的临时基线。当前评审预览仅在自由释放段试用 `1.1 N·s/m` 剩余线性损耗并与有限热交换联合识别，干摩擦仍为零；如后续加入摩擦，必须重新联合识别，不能把损耗直接相加。

### 1.4 代码与文档卫生

- 新方案替换旧方案时，直接删除旧运行分支、失效注释、废弃常量和只为旧交互保留的样式；不把旧方案注释掉后继续留在产品代码中。
- 兼容代码只可用于读取已有存档并迁移到最新结构，不能成为第二套长期业务逻辑。
- 候选参数扫描、临时报告和校准脚本在参数确定后按用途处理：产品运行时只保留最终参数；无长期复核价值的临时产物应删除。
- 所有删除必须限定到已核实的具体目标并可由 Git 恢复；代码修改完成后先由用户人工验证，再按用户指令保存或提交。

## 2. 已确认且必须保存的全局需求

### 2.1 正确操作的数据采集与周期处理基线

- 正确目标采样率当前为 `1000 Hz`，即每 `1 ms` 产生一个离散采样点；图上连续曲线只是这些采样点的连线。
- 正确操作走正常下降触发路径时，触发后的正式振荡段当前记录基线为 `0.500 s`，包含 `t = 0` 在内共 `501` 个样本。
- 自由模式走“开始即记录”路径时，总记录长度由“点击开始”到“点击暂停”的真实时长决定，仍按 `1000 Hz` 连续采样；后续周期处理可再从完整记录中选择有效振荡段。
- 周期框选不从触发点、释放瞬间或 `t = 0` 直接开始；先越过非周期启动段，从第一个清晰、完整的波峰或波谷开始。
- 起点和终点必须是同相位极值。
- 引导基线默认框选 `3` 个完整周期；第 `4` 个周期只有在幅度、弧线和周期宽度仍清晰时才纳入。
- 低振幅尾段、额外小峰小谷、局部缺口、明显不等宽和接近噪声的尾部需要舍弃。
- 先按波形质量确定窗口，再计算周期、拟合和 `γ`；禁止根据结果是否接近 `1.40` 反向挑选窗口。
- 自由模式允许用户只选一个或两个周期并继续处理；系统保留该选择和结果，不弹错误提示。以后是否评价由过程回顾阶段决定。

### 2.2 自由模式的非阻断原则

- 自由模式不显示步骤错误弹窗、黄色步骤警告或强制重做提示。
- 用户在软管未接好时按压，活塞应按实际状态下落或失去正常气体弹力；用户需要自行重新托起、接管和恢复实验。
- 用户可以保存质量较差但仍可处理的数据，也可以因错误状态而得不到可处理数据。
- 所有操作都应尽量忠实记录，为以后过程回顾和评分提供证据；当前阶段不因为“以后可能评分”而提前写死扣分规则。
- 评价等级的长期方向为三层：理想/合理区间、小过失区间、明显或严重错误区间。具体阈值必须等相应物理模型和过程回顾设计完成后再确定。

### 2.3 实验计划、目标高度与实际高度必须分离

- 一轮自由实验选择 `3–6` 个目标高度。
- 系统正式候选为 `80、70、60、50、40、30 mm`。
- 用户还可以添加 `10–80 mm` 范围内的整数自定义候选高度；不接受小数。`30–80 mm` 是推荐区间，`10–29 mm` 允许使用但必须标记为非推荐区间，不能把它冒充成标准实验条件。
- `0 mm` 是活塞接触刚性下限的位置：只能向上提，不能继续向下压缩气体，因此不能制造可触发并保存的振荡 Run，也不能进入后续计算；正式计划通过 `10 mm` 下限排除该边界。
- 自定义候选数量不设产品级固定上限，选择区内容过多时必须可以滚动。
- 一轮实际选中的目标仍只能有 `3–6` 个。
- 目标执行顺序不按点击顺序，而是统一按高度从高到低排列。
- 进度按“已保存的目标 Run 数量 / 本轮总数”推进。例如五个目标中保存当前目标后显示 `1 / 5`，下一目标保存后显示 `2 / 5`。
- 用户应按系统给出的当前目标高度完成实验，不在运行中自由跳选目标顺序。
- 必须分别保存 `targetHeightMm` 与 `actualHeightMm/confirmedHeightMm`。例如目标是 `65 mm`、用户实际在 `40 mm` 操作：底层物理数据按真实 `40 mm` 产生，自动教学计算仍按计划目标 `65 mm` 使用，从而让错误高度形成真实系统性偏差；软件不即时提醒。
- 最终拟合数据按目标高度排序，不按采集时间或用户最初点击顺序排序。

### 2.4 Run 生命周期

- 当前 Run 必须经历：等待采集、触发/记录、暂停并冻结候选、保存正式 Run。
- 用户点击保存后，该目标才算完成并使进度加一。
- 若还有目标，保存后自动进入下一目标的准备阶段；不增加一个多余的“进入下一组”确认按钮。
- 最后一个目标保存后自动进入数据处理，不要求用户再点击“进入数据处理”。
- “重做当前候选”“删除已保存 Run 后重采”“退出并保留会话”“重置整个自由模式”是不同动作，不能用一个含义不清的按钮代替。
- 退出自由模式不是重置：计划、自定义候选、当前进度、候选曲线、正式 Run、采集设置、数据处理状态、操作记录和自由模式仪器状态都必须持久化；重新点击自由模式时直接恢复旧内容。
- 整轮计划不能在恢复入口中静默修改。用户只有通过默认视角按钮下方进度组件的三点菜单执行“重置”后，才能清空当前自由模式并重新建立计划。
- “重置自由模式”清空当前自由模式所属状态，但不影响演示模式、引导模式或软件全局设置；执行前二次确认，并允许从“编辑”菜单撤销。
- 被重做或删除的尝试不得参与正式拟合，但在未执行整轮重置前，其操作事件、采集设置、物理快照和必要的原始观测应作为排除记录保留，以支持恢复和未来过程评价。

### 2.5 采集参数与监测点

- 只保留当前这一种阈值监测/下降触发采集方式，不增加四种触发方法供用户选择。
- 自由模式允许用户自己输入触发阈值，不把引导模式的预设值强行覆盖回来。
- 采样率和触发阈值都必须支持真实键盘输入，而不是只能通过虚拟键盘或预设按钮产生 `1000`、`120` 等固定数字。
- 用户点击开始记录时，系统先比较用户阈值与当时传感器对应的真实平衡压强：
  - 若当时压强尚未达到阈值，则保持当前下降触发逻辑，等待释放后压强首次向下穿越阈值再进入正式记录；
  - 若当时压强已经高于用户阈值，则立即进入正式记录，不再等待一次人为制造的下降穿越。
- 立即记录后必须按真实时间连续保存离散采样点：开始后的平直基线、下压造成的上升段、用户停留造成的平台段、松手后的振荡段都不能被裁掉、重排或替换成预制函数。图上看似连续的“函数”本质上仍是采样点序列。
- 立即记录路径使用用户设置的采样率；正确基线为 `1000 Hz`。采样点数量由实际记录时长计算。
- 每个 Run 保存开始采集时的采样率、触发阈值和其他采集设置快照；后续改设置不能改写已经保存的 Run。
- 用户设置不理想但仍在仪器能力范围内的值时，软件不弹步骤错误提示，观测模型应忠实产生相应分辨率和触发结果。
- 当前 `120–130 kPa` 不是科学标准，只是早期实现值。教师真实演示曾使用约 `115 kPa` 和 `120 kPa`，可作为后续候选证据，但不能直接升级为最终参数。
- 最佳触发/释放压强、红色上限和对应下压距离必须在热交换、正常耗散和传感器基线建立后统一确定。

### 2.6 学生计算、底层真实量与模型自检要分层

- 学生计算继续使用教学近似大气压 `1.01 × 10^5 Pa`。
- 底层物理模型使用精确的标准大气压和活塞重量引起的平衡压强增量，不用 `1.01 × 10^5 Pa` 代替真实状态。
- 松开锁紧螺钉后，活塞重量会使气体达到新的真实平衡压强、体积和高度；即使位移只有 `0.01 mm`，状态和三维动画也必须真实更新。
- 理想模型自检使用松开后真实的 `P、V、h`，应还原 `γ = 1.40`，不能让教学近似或名义高度污染底层参数识别。
- 用户实际实验和教学计算仍可使用名义/目标高度与 `1.01 × 10^5 Pa`，这些近似与真实状态之差形成可解释的系统误差。

### 2.7 气体弹性与当前损耗口径

- 空气弹性来自气体状态方程和能量关系，不把空气永久简化成一个人为指定刚度的线性弹簧。
- 理想自由振动采用非线性气体关系；局部的 `k = γA²P/V` 只用于解释平衡点附近的小振幅线性近似。
- 理想绝热关系为 `P = P_eq (V_eq / V)^γ`，温度关系为 `T = T_amb (V_eq / V)^(γ-1)`。
- 活塞动力学至少满足 `m x¨ = A(P - P_atm) - mg - F_loss`。
- 零热交换、零耗散的后台不变量测试不是第二套产品模型，而是验证几何、质量、平衡状态和 `γ` 的科学门禁。

### 2.8 下压动作、热过程与待记录数据

- 下压速度、下压时长、最低点停留时间和松手速度会影响温度、压强和第一段曲线；现有自动演示约 `1.1 s` 的下压只代表视觉节奏，不是真实压缩时间。
- 用户在仍向下运动时松手，底层模型必须保留真实的非零释放速度，不能一律把初速度重置为 `0`。
- 后续至少记录：完整下压位移—时间轨迹、下压起止时间、平均与峰值下压速度、最低点停留时间、释放速度、左右手释放时刻与顺序、释放时间差，以及释放时的真实 `P、V、T、h`。
- 上述数据当前只记录，不评分、不弹警告，也不要求现在就显示在过程回顾中；后续过程回顾设计可以使用这些证据。
- 目前定性标准是“平稳、短促、连续地下压，达到目标后不故意停留并尽量同时松手”，不是“越快越好”。过猛动作会增加释放速度、倾斜和大振幅非线性。
- 精确推荐时长和最终下压幅度需要热模型与参数扫描后才能确定。

### 2.9 引导模式的下压实验说明

- 每次进入一次新的引导实验会话，只弹出一次下压实验说明。
- 触发位置固定为：第一次有效完成“下压—松手—生成振荡曲线”后，用户点击暂停，记录已经冻结，再立即弹出；关闭说明后用户才点击保存。
- 第二次、第三次以及同一会话的后续 Run 都不再弹。
- 若没有完成有效下压、松手和曲线记录，只是开始后误点暂停，不弹。
- 自由模式不弹该说明。
- 说明内容最终解释快速小振幅振动为何近似绝热、为什么不应故意停留、动作过猛的影响和推荐操作时长；必须等热模型和标准参数确定后再定稿。
- 最终采用的权威资料按 `piston-oscillation-modeling-references-gb.md` 的现有格式补入；不把未采用的候选解释当成最终口径长期保留。

### 2.10 双手释放时间差的长期要求

- 正确操作为左右手尽量同时释放，理想时间差为 `0`。
- 左右手释放顺序和带符号时间差必须原样保存，不能只保存绝对值后丢失方向。
- 后续第一版错误模型优先研究释放不同步引起的初始倾斜、额外摩擦及其波形后果；如果资料支持其他机制，再逐个加入。
- 用户描述的真实坏曲线特征包括：周期前后宽度不一致、局部弧线或斜率异常、不光滑、有效周期由五六个减少到一两个，甚至无法正常框选。
- 引导模式中，超过最终阈值的不同步释放应产生相应不良曲线，随后给黄色警告、要求重做并解释同时松手的原因；自由模式不弹警告，允许继续使用坏数据。
- 理想、轻微过失和严重错误的毫秒阈值必须等资料、模型和验证结果确定，当前不凭感觉写死。

### 2.11 已验收交互不得回退

- 侧面锁紧螺钉的视觉轴向进退幅度已经加大，用于让旋紧/旋松更明显；鼠标旋转灵敏度和完成相同圈数所需的鼠标运动不能随轴向视觉距离一起加倍。实现应表现为螺纹导程/轴向视觉映射改变，而不是旋转角速度翻倍。
- 自由模式活动按钮的功能是“退出自由模式”，图标和辅助文本必须表达退出，不能继续使用表示“终止”的方形停止图标。
- 实验次数控件中的“次”与右侧下拉按钮之间必须保留已验收留白；后续样式调整只维护最新布局，不恢复旧间距方案。

## 5. 第一阶段：自由模式独立小闭环修复

### 5.1 目标

只修复不依赖新物理模型的现有问题，让当前正式高度计划至少能够完整做完一轮。该阶段完成后，用户即使暂时不使用自定义高度，也能从进入自由模式一路保存到自动进入数据处理。

### 5.2 实施内容

#### A. 退出按钮语义

- 自由模式活动后出现的附加按钮继续执行“退出并暂停当前自由会话”。
- 图标改为与退出语义一致的 `LogOut` 类图标，不使用表示终止/停止的 `Square`。
- 文案、辅助标签和提示统一为“退出自由模式”。
- 退出不会静默删除当前计划、已保存 Run、候选记录或审计事件。
- 若退出时正在正式记录，退出动作先在同一时刻自动暂停并冻结已经产生的采样点，再保存会话；离开界面后不在后台继续采样。

#### B. 参数键盘输入

- 采样率和下降触发阈值都使用可直接获得焦点的真实输入框。
- 支持数字键、退格、删除、方向键、全选和粘贴；不能由工作区快捷键或虚拟键盘拦截正常输入。
- 输入过程允许暂时为空或处于未完成草稿状态，提交时再校验；不能每输入一个字符就立即回写默认值。
- `Enter` 或失焦提交合法值，`Escape` 恢复上一次已提交值；与其他内联输入交互保持一致。
- 采样率接受仪器能力内的整数；触发阈值接受后续模型支持的有限数值。合法但不理想的自由模式参数不自动改正。
- 保存 Run 时固化本 Run 的参数快照。

#### C. 保存后的自动推进

- 暂停后曲线冻结，用户检查并点击“保存本次”。
- 保存成功后立即更新进度；若还有下一目标，当前目标切换为计划中的下一个高度并进入准备状态。
- 不增加“进入下一组”按钮。
- 最后一个目标保存成功后，自动切换到数据处理入口/界面，不再停留在已经完成的 Run 1 或最后一条曲线上。
- 自动切换只在保存真正成功后发生；无有效候选或持久化失败时不能假装已经完成。

#### D. 最小进度组件

- 在三维默认视角附近采用与另一个实验“第几次实验”组件一致的视觉语言，但本阶段只承担活塞振动法所需信息。
- 至少显示：`已完成数量 / 总数量`、当前目标高度、当前目标状态。
- 进度按保存成功次数增加，不按点击开始、触发或暂停增加。
- 第一条未保存时显示 `0 / N` 与第一个目标；第一条保存后显示 `1 / N` 并转到第二目标。
- 本阶段先支持现有正式高度计划；第二阶段再扩展自定义高度和逐项管理能力。

### 5.3 状态与数据要求

- 第一阶段不得另建一套临时 Run 计数；进度必须从自由会话的正式计划和已保存 Run 推导。
- 当前 Run 的候选数据、已保存数据和显示进度必须拥有同一 `measurementIndex`/目标标识，避免 UI 显示进入第二条但保存仍覆盖第一条。
- 最后保存后的自动数据处理切换属于可恢复会话状态，刷新或重新打开文件后不能退回错误阶段。

### 5.4 验收场景

1. 选择 `3` 个正式高度，依次完成三次，进度为 `0/3 → 1/3 → 2/3 → 3/3`，最后自动进入数据处理。
2. 分别选择 `4、5、6` 个正式高度，保存次数和目标推进完全一致。
3. 参数框可用实体键盘输入 `1000`、自定义阈值以及退格重输。
4. 第一次暂停但未保存时退出，再进入后候选与进度不被误判为已完成。
5. 退出按钮显示退出图标，功能仍是退出/暂停，不清空会话。
6. 类型检查、现有自动测试、自由会话保存恢复测试通过；固定端口 `http://127.0.0.1:5174/` 完成人工预览。

### 5.5 第一阶段明确不包含

- 不加入自定义高度创建器。
- 不改变当前气体轨迹、阻尼、平衡高度或触发物理。
- 不加入下压实验说明。
- 不评价用户输入、手速、停留时间和双手释放差。
- 不改最终压强范围。

## 6. 第二阶段：自由模式计划、持久化与多 Run 生命周期闭环

> 实施状态（2026-08-28）：第二阶段交互和恢复闭环已经进入软件并由用户确认进入下一阶段；仍须随第三阶段一起保留全量回归和固定端口人工复核，发现的第二阶段回归问题继续按原口径收口，不重新引入旧交互方案。

### 6.1 目标

把自由模式从“能进入的骨架”扩展为可长期保存和精确恢复的一轮实验：用户首次建立计划后按高到低执行，能够保存/重做/删除 Run；退出或重新打开文件后继续同一会话；只有从进度组件明确执行整轮重置后才能建立新计划；完成后自动进入统一数据处理。

### 6.2 计划设置弹窗

#### A. 实验次数

- 用户可直接输入，也可使用与语言选择类似的下拉菜单选择 `3、4、5、6` 次。
- 第一次打开计划窗口时不预选次数，输入框为空；用户必须主动输入或从菜单选择。
- 输入次数与最终选中目标数必须相同，未匹配时不能确认计划。
- 已验收的“次”字留白和组合输入样式作为最新 UI 基线继续使用。
- 次数输入与空气比热容比实验共用同一个次数选择组件，只通过选项范围和文案配置区分；不得再维护两套外观相似但交互不同的实现。空气比热容比实验范围仍为 `3–7`，活塞振动法仍为 `3–6`。

#### B. 系统正式高度

- 第一行固定显示 `80、70、60、50、40、30 mm` 六个系统候选按钮。
- 选中后使用边框/框选状态表达，不通过禁用后褪色制造“已选但不可理解”的状态。
- 达到本轮选择上限后，未选候选不能继续加入，但已选项仍可取消。

#### C. 自定义高度

- 提供单独的“自定义”入口；用户输入例如 `65` 并确认后，新增 `65 mm` 候选按钮。
- 只接受 `10–80 mm` 的整数；输入小数、低于 `10`、超过 `80`、空值或非数字时不能创建候选。
- `30–80 mm` 使用普通候选样式；`10–29 mm` 可以创建和选择，但要以不阻断的“非推荐”文案或视觉标识说明其不属于标准推荐区间，不能弹步骤错误提示。
- 自定义候选显示在系统高度行下方，按网格继续换行。
- 候选总数不设固定上限；内容超过窗口可用高度后，弹窗内容区滚动，标题、必要说明和底部操作保持可用。
- 同一数值只保留一个候选；与系统正式高度相同的值不重复创建第二个按钮。
- 计划保存时统一按数值从高到低排序，不保留用户点击顺序。

### 6.3 运行顺序与进度组件

- 系统每次给出明确的“当前目标高度”，用户按目标从高到低推进。
- 活塞振动法进度主行固定采用紧凑单行：`第 1 / 3 次 · 目标 80 mm`；详细计划、已保存/当前/待完成状态和删除入口放入三点菜单。
- 组件位于三维默认视角按钮下方，带三点菜单；三点菜单是整轮“重置自由模式”的唯一入口，不能在重新点击自由模式时另开一条改计划入口。
- 两个实验共用同一个进度/管理组件。菜单通过页面顶层浮层显示，并根据视口空间自动放在按钮上方或下方、限制横向位置和最大高度；不能再被三维视口或父容器裁掉。点击菜单外、按 `Escape`、滚动或切换状态时按统一规则关闭；关闭时同时清除尚未确认的删除状态。
- 用户实际设置成其他高度时不报错；物理状态按实际高度产生，目标字段保持不变。
- 保存后自动进入下一目标；最后一次保存后自动进入数据处理。
- 数据处理列表和最终拟合按目标高度从高到低排序。

### 6.4 单一监测点与两条进入记录路径

- UI 仍只有一个用户可设置的触发阈值和一套监测点，不增加触发方式选择器。
- 新建计划或整轮重置后，采样率和触发阈值均为空，不暗中回填旧默认值。采样率接受 `1–1000 Hz` 整数，正确操作基线为 `1000 Hz`；触发阈值接受 `96.0–130.0 kPa`、步长 `0.1 kPa`。
- 输入越界、格式无效或不符合步长时，提交后恢复上一次有效值；若从未保存过有效值则恢复为空，并显示约 `2.5 s` 的黄色仪器参数提示。这属于仪器能力约束，不属于自由模式步骤判错。
- 在采样率输入框键入有效值后按 `Enter`，保存并把焦点移到触发阈值输入框；触发阈值按 `Enter` 只沿用现有的保存并退出输入框行为，不自动开始记录，也不把焦点移到开始按钮。
- 两项都保存为有效值后才显示监测线和监测点。开始记录按钮保持可点击；若任一项缺失或当前草稿无效，点击后不开始记录，给出仪器参数提示并聚焦第一个需要处理的输入框。若开始点击首先触发了无效草稿失焦，本次点击只完成拒绝与提示，不同时开始记录。
- 点击“开始记录”后读取同一传感器观测链的当前绝对压强：
  - 当前压强未高于阈值时进入“等待下降触发”；用户下压后监测点进入已越过阈值的激活状态，松手后首次向下穿越阈值才把正式振荡记录的时间原点固定下来；
  - 当前压强已经高于阈值时直接进入“正在记录”；记录时间原点就是点击开始的时刻。
- 立即记录路径必须保存开始后的平直基线、完整下压上升段、可选停留平台和释放振荡段；这些部分共用一个单调递增的采样时间轴和同一 Run 设置快照。
- 正确基线按 `1000 Hz`、每 `1 ms` 一个离散点采样。立即记录路径的总点数由开始至暂停的实际时长决定；正常下降触发路径的触发后振荡段继续以 `0.500 s / 501` 点作为当前正确操作基线。
- 监测点颜色表达当前实测压强与用户阈值的关系，而不是继续把引导模式的 `120 kPa` 写死为自由模式激活边界；红色过压上限的最终数值留到第五阶段统一校准。
- 自由模式纵轴根据用户阈值、真实平衡压强、当前实测压强和已显示样本共同计算。阈值线必须位于图高的 `25%–75%` 范围，且上下至少各保留一个主刻度间隔；优先使用整洁整数主刻度。阈值为 `120 kPa` 且数据仍在正常基线附近时，固定显示 `96、102、108、114、120、126、132 kPa`。
- 正在记录时纵轴只允许向外扩展，不随瞬时数据缩回；暂停或保存后冻结本 Run 的纵轴，新 Run 开始时重新计算。监测点低于阈值为暗淡色，达到阈值后为激活色，超过当前 `130 kPa` 上限为红色。
- 无论走哪条路径，图表、保存和后续处理都读取正式离散样本，不能让图上动画和保存数据来自两套曲线。

### 6.5 退出、继续与整轮重置

- “退出自由模式”只离开当前界面并保留当前会话，不弹计划设置，不清空数据。
- 若退出时正在记录，先自动暂停并冻结当前采样；退出后不在后台继续产生数据。重新进入后恢复被冻结曲线，由用户决定保存、重做或继续后续流程。
- 立即记录路径若在真正松手前就暂停或退出，也要按“尚未发生松手”的不完整曲线冻结和恢复，不能伪造后续振荡；该曲线可被用户重做，也可作为无法正常处理的错误 Run 保留。
- 重新点击自由模式时直接恢复退出前的旧内容；若已经进入数据处理，也恢复到同一数据处理阶段。重新进入不是编辑计划入口。
- 计划一经确认，在当前自由会话内保持冻结。用户想把四组改成五组，必须先从默认视角按钮下方的进度组件打开三点菜单，再执行“重置自由模式”。重置确认后仍停留在自由模式，不自动弹窗；原进度位置显示“设置新实验计划”，由用户主动点击后再打开空白计划窗口。第一次从未进入过自由模式时，点击“自由”仍直接打开计划窗口。
- 重置前不得把旧计划中的 Run 静默映射到新计划，也不得把新高度插入一轮已开始的活动计划。
- 删除单条已保存 Run 后，该目标重新变为未完成，进度回退并允许重采；删除不能改变其他 Run 的目标身份。

### 6.6 Run 与整轮操作语义

- **重做当前候选**：当前尚未保存的曲线被排除，目标和进度不变，重新采集同一目标。
- **保存当前候选**：成为该目标唯一正式 Run，进度增加。
- **删除已保存 Run**：正式 Run 转为排除记录，该目标恢复未完成；自动计算结果失效并等待重采。
- **退出会话**：离开自由模式，旧会话全部保持；重新进入时继续。
- **重置整个自由模式**：只从进度组件三点菜单触发；当前自由模式所属的计划、自定义候选、当前候选、正式 Run、排除尝试、计算状态、采集设置、操作记录和仪器状态全部清空，然后在原位置显示“设置新实验计划”，不自动弹出窗口。重置不影响演示模式、引导模式和软件全局设置；执行前二次确认，并生成可从“编辑”菜单撤销的恢复快照。

### 6.7 数据结构与恢复

计划至少保存：

- 计划结构版本；
- 目标高度列表和排序结果；
- 系统/自定义候选来源；
- 当前目标标识；
- 已保存 Run、当前候选和排除尝试；
- 每个 Run 的目标高度、实际高度、采集设置快照、原始观测、物理模型版本和操作审计；
- 当前候选曲线及其采样进度；
- 当前是否位于仪器操作或数据处理阶段；
- 自由模式仪器物理状态，以及恢复同一交互阶段所需的 UI 状态。
- 周期核验和最终计算的每次作答尝试：原始输入字符串、尝试时间、尝试序号、解析值和结果；答案结局区分首次正确、重试后正确、有效尝试后查看答案、没有有效数值尝试便查看答案和尚未解决。旧存档只有尝试次数而没有原始输入时，迁移结果明确记为“未知”，不得伪造历史答案或时间。
- 高频 `1000 Hz` 传感器点和连续运动轨迹继续保存在 Run 快照中，不把每一个采样点膨胀成独立操作审计事件；后续评分指标在现有版本化尝试/操作结构上扩展。

恢复时不得只凭数组位置猜测 Run 身份；自定义候选、目标、实际数据和审计事件必须通过稳定标识关联。退出自由模式、刷新、关闭文件或重新打开软件后，只要未执行整轮重置，都恢复同一活动会话，不能重新弹计划设置或重新生成默认值覆盖用户内容。

### 6.8 第二阶段验收矩阵

1. 系统高度分别完成 `3、4、5、6` 次计划。
2. 系统高度与自定义高度混合，例如 `80、65、50、35、30 mm`，实际按从高到低推进。
3. `10、29、30、65、80 mm` 的整数边界按规则创建；`0、9`、小数、负数和 `81 mm` 被输入校验拒绝；`10–29 mm` 只提示非推荐，不阻断。
4. 创建大量自定义候选后，弹窗可滚动且次数控件、确认和取消仍可使用。
5. 选择四组并完成一部分后退出；重新点击自由模式、刷新和重新打开文件都直接恢复原四组、原进度、原数据和原仪器状态，不出现改成五组的入口。
6. 正在记录时退出会自动暂停并冻结已有样本；退出期间点数不增加，重新进入后曲线和状态一致恢复。
7. 只有从进度组件三点菜单二次确认整轮重置后，旧活动会话才被清空；重置后仍在自由模式并显示“设置新实验计划”，点击后才打开空白计划窗口。执行撤销后能够恢复重置前完整自由会话，其他模式和全局设置始终不变。
8. 触发阈值高于初始平衡压强时按下降穿越开始振荡记录；阈值低于初始平衡压强时点击开始即记录，并以 `1000 Hz` 保存基线、下压、停留与松手振荡全过程；点数与实际记录时长一致。
9. 用户目标 `65 mm`、实际 `40 mm`：物理数据保存真实高度，教学计算使用目标高度，不即时提示。
10. 当前候选重做、已保存 Run 删除和删除后重采均保持数据身份正确。
11. 最后一条保存后自动进入数据处理；删除其中一条后计算状态失效并回到待补 Run。
12. 保存、刷新、关闭文件和重新打开后，计划、进度、正式 Run、排除记录、设置快照和阶段一致恢复。
13. 自由模式全程不出现步骤错误弹窗。
14. `120 kPa` 阈值在正常数据下显示于 `96–132 kPa` 纵轴内部；测试 `96.0、100.0、120.0、130.0 kPa` 以及超出当前视域的数据时，阈值线、实时点和曲线均不被裁掉，记录中纵轴不缩回。
15. 采样率输入 `1000` 后按 `Enter` 自动进入阈值框；阈值按 `Enter` 只保存并退出输入。两项为空、越界或格式无效时开始记录被仪器约束阻止；有效后可正常进入实操。
16. 最后一条 Run 的周期答案核验完成或查看答案后，立即自动打开计算窗口；自由模式不显示“进入计算”按钮，也不显示固定的“三组周期数据已记录”提示。
17. 首次正确、重试正确、两类查看答案和旧存档未知输入都能从保存结构中明确区分并恢复。
18. 自由模式完成计算并退出二级计算窗口后，左侧栏自动重新展开，主工作区恢复为三维仪器与实时数据左右布局；已完成的数据处理界面不继续占据主工作区，只能由左侧“数据处理”条目双击重新打开，关闭回顾后再次返回仪器布局。
19. 第二阶段人工验收收口前，对活塞振动法新增界面完成一次整体配色核验：按钮、选中态、提示色和状态色优先复用工作台与绝热膨胀法已经使用的全局色彩，不再增加实验私有的按钮蓝；绘图曲线、框选区域等数据可视化颜色与操作控件颜色分开审查。数据处理回顾以“曲线编号使用普通正文色、选中卡片使用工作台选中色、主要操作使用全局主操作色”为当前基线。
20. 两个实验的左侧“实验资料与结果”必须跟随当前模式变化：演示模式和未选择任何模式时整组隐藏；引导模式只显示当前真正可用的教学内容；自由模式显示该实验已实现的完整内容。隐藏只改变导航呈现，不清除已保存数据或模式会话。
21. 活塞振动法在实验指引、数据与结果和过程回顾尚未完成前，不显示“开发中”占位；当前只在引导或自由模式已经产生数据处理会话后显示可双击打开的“数据处理”。退出对应模式后该组隐藏，重新进入时仍读取原模式保存的数据。

### 6.9 第二阶段已经确认的颗粒度结论

1. **整轮重置**：使用二次确认；清空当前自由模式所属全部活动状态，不影响其他模式和软件全局设置；生成可从“编辑”菜单撤销的恢复快照。
2. **记录中退出**：退出瞬间自动暂停并冻结已有采样，完整保存会话；离开界面后不在后台继续采样。
3. **采样点口径**：使用 `1000 Hz` 采样，采样间隔为 `1 ms`；立即记录路径从点击开始连续采样到点击暂停，点数随实际时长变化；正常下降触发路径的触发后振荡段仍保留当前 `0.500 s / 501` 点基线。
4. **统一交互组件**：次数选择和紧凑进度管理分别只有一套共享实现；旧的两个实验专用进度组件及其专用样式、旧测试入口在新结构通过检查后直接删除，不留注释版或并行分支。
5. **数据处理衔接**：中间 Run 核验后仍保留“下一步”；最后 Run 核验完成后自动打开计算窗口。核验本身继续存在，并把每次输入与纠正过程写入可扩展记录结构；当前不据此评分。
6. **计算后的工作区恢复**：自由模式完成二级计算后立即关闭计算窗口、展开左侧栏并恢复三维仪器与实时数据；后续查看周期核验、拟合和计算历史必须从左侧“数据处理”双击进入，不把已完成的数据处理永久留在主工作区。
7. **配色来源**：新增实验界面的操作色从现有工作台全局色彩继承，不能用绘图曲线蓝临时充当按钮蓝；整体配色核验作为第二阶段人工验收前的独立收口任务。

### 6.10 左侧导航与活塞振动法实验指引准备

- 左侧导航采用同一套“当前模式 + 当前已实现能力”判断，不再为两个实验分别维护外观相似但规则冲突的固定列表。
- 绝热膨胀法：引导模式显示“实验指引、数据与结果”，自由模式再增加“过程回顾”；演示模式和普通未选模式不显示整组。
- 活塞振动法：本阶段只接入已经能正常打开和回到仪器界面的“数据处理”；没有数据处理会话时整组隐藏。后续“实验指引、数据与结果、过程回顾”分别完成后再加入相应模式，不提前放置不可用条目。
- 活塞振动法“实验指引”后续沿用绝热膨胀法的折叠问答交互，但先与用户逐题确认文案和展示节点。当前候选问题为：为什么不从触发点直接框选、为什么端点要同相位、为什么舍弃低振幅尾段、采样率与触发阈值分别控制什么、为什么需要多个高度拟合、为什么两手应尽量同时松开、下压速度和停留如何影响曲线。
- 前五项可在现有采集与计算规则基础上先拟稿；“双手释放”和“下压/停留”两项必须等对应摩擦、热交换模型及文献口径确定后再给最终答案，不能把当前定性猜测写成权威教学结论。

## 7. 第三阶段：精确静态平衡与理想非线性基线

### 7.1 松开螺钉后的真实平衡

设锁紧并密封时气体为环境温度、压强 `P_atm`、体积 `V_locked`。松开后先按准静态等温平衡处理：

- `P_eq = P_atm + mg/A`；
- `P_atm V_locked = P_eq V_eq`；
- `h_eq = (V_eq - V_dead)/A`。

三维活塞从名义设置高度移动到 `h_eq`；物理状态保存真实 `P_eq、V_eq、h_eq`。用户肉眼是否看得出不影响数值必须真实变化。

- 这段下沉使用统一的 `0.2 s` 物理时间，不是只供观看的动画延迟；位移采用平滑、单向、无超调、无振荡的变化。
- 若采集在松开前已经进入正式记录，这 `0.2 s` 内的真实压强变化必须按当前采样率写入同一条曲线，不能跳过、裁掉或只改变三维画面。
- 名义高度和真实高度必须并存：仪器操作提示、目标计划和学生计算继续显示/使用名义高度；真实高度只在后台物理状态、Run 快照和模型自检中使用，不主动向学生显示精确数值。
- 重复锁紧和松开不能重复套用重量修正或造成累积下沉；在没有其他操作时，同一名义高度每次都回到同一个真实平衡状态。
- 软管保持连接且螺钉松开时，用户仍可按压平台；按压会从当时真实状态继续改变体积、压强、温度和内能，不能在松开状态下把气体状态冻结。
- 固定死体积继续采用现有真实实验数据约束后的值，在本阶段和后续基础参数拟合中保持固定，不允许与损耗、热参数或其他参数相互补偿。
- 第三阶段当时只建立了气体物质的量、温度、内能和热模型版本字段，热交换门禁保持关闭；第四阶段已经用显式版本升级启用候选热过程，因此不得把第三阶段的禁用状态误读成当前运行状态。

### 7.2 理想释放模型

- 从真实平衡状态按非线性绝热关系生成压力、温度和活塞运动。
- 理想自检关闭热交换、摩擦、噪声、泄漏和用户误差。
- 使用真实平衡量拟合时必须在数值容差内得到 `γ = 1.40`。
- 教学计算另行使用 `1.01 × 10^5 Pa` 和目标/名义高度，不能与底层自检混为一条公式。

### 7.3 与临时损耗的关系

- 本阶段先用零损耗证明模型正确。
- `0.434 N·s/m` 继续支撑已验收按压手感和旧存档兼容，但不能参与理想参数识别，也不能被重命名为真实摩擦。
- 四组实测的联合比较支持在自由释放段临时试用 `1.1 N·s/m` 剩余线性损耗、`50 ms` 参考热弛豫和一次体积缩放；当前只用于人工验收。机械摩擦保持为零并后移，用户确认曲线前不把该候选转为正式参数。

### 7.4 三种模式与持久化

- 演示、引导和自由模式共用同一套名义锁定状态、松开下沉状态、真实加载平衡状态、候选热过程和释放运动状态，不为不同模式各保留一套平衡或造波公式。
- 模式只负责各自的时间安排、流程守卫和反馈；底层 `P、V、T、h` 的计算口径保持一致。
- 自由模式保存并恢复完整热力学状态和下沉阶段；刷新或退出后不能只凭画面高度重新猜测状态，也不能重复触发一次额外下沉。
- Run 快照同时固化名义目标/名义仪器高度与后台真实平衡量，使学生近似计算、真实数据生成和理想模型自检各自使用正确的一层数据。

### 7.5 第三阶段验收门禁

1. `80、70、60 mm` 等名义高度松开后均在 `0.2 s` 内平滑单向到达唯一真实平衡高度，无振荡和累积下沉。
2. 记录已经激活时，曲线以真实物理时间包含下沉段；未激活时只更新仪器状态，不伪造历史采样。
3. 软管连接、螺钉松开后继续按压，会从当前真实状态连续改变 `P、V、T、h`；释放后从同一状态连续进入振动。
4. 三种模式在相同名义高度下得到相同真实加载平衡；引导提示和学生计算仍只看到名义高度。
5. 自由模式退出、刷新、重新进入后精确恢复名义高度、真实状态和当前物理阶段；重复松开不会再次下沉。
6. 固定死体积不能被运行时参数覆盖；零热交换、零耗散的后台拟合使用真实平衡量并在数值容差内还原 `γ = 1.40`。
7. 理想科学门禁继续明确关闭全部损耗；产品人工验收预览在自由释放段使用版本化 `1.1 N·s/m` 联合损耗候选，按压阶段及旧存档仍保留 `0.434 N·s/m`，两者不得混作一套参数识别。
8. 自定义高度只接受 `10–80 mm` 整数；低于 `10 mm` 的刚性底部边界不进入正式计划、采集和计算流程。

## 8. 第四阶段（已完成检查点）：完整下压历史与第一版热交换模型

### 8.1 最小热模型

第一版使用单一平均气体温度，不立即建立复杂空间温度场：

- `P = nRT/V`；
- `nC_v T˙ = -P V˙ + G_th(T_amb - T)`；
- 手部按压期间由真实鼠标轨迹驱动虚拟柔顺手目标，手部作用力再进入活塞动力学；`V(t)` 是受力积分结果，不由鼠标直接指定；
- 最低点停留期间 `V` 固定、温度和压强继续松弛；
- 松手时 `x、v、T、P` 连续进入自由运动。

只有该模型不能解释正确基线、不同速度和衰减数据时，才升级为核心区/边界层等更复杂模型。

### 8.2 记录但暂不评价

- 下压时长、平均/峰值速度、停留时长、释放速度和左右手释放差都进入版本化事件与 Run 快照。
- 当前不产生分数、错误标签或过程回顾结论。
- 引导模式只在最终标准确定后给“推荐动作”，不按精确秒数判错。

### 8.3 文献与参数

- 使用 PASCO 官方实验、Torzo 等人的实测、Shearwood 与 Sloan 的分析以及气体弹簧热损失资料约束模型。
- 资料不能给出本仪器具体参数时，明确区分文献先验、仪器几何推算和需要校准的参数。
- 热模型接入后已明确重新审查临时线性损耗的必要性；当前因缺少可辨识实测数据而保持数值不动，后续取得数据时再重估，防止把热耗散重复算成机械阻尼。

## 9. 第五阶段（交互锚点已完成，科学标准后移）：确定正确操作的标准激励参数

### 9.1 要确定的不是单个压强值

最终标准至少包括：

- 相对真实平衡压强增量 `ΔP = P_release - P_eq`；
- 合理释放压强带和过压红色区间；
- 每个目标高度对应的参考下压距离；
- 推荐下压时长范围；
- 最低点不故意停留；
- 合理人体波动范围和释放速度范围。

优先以相对平衡压强增量或等效压缩比例作为跨高度标准。固定同一个绝对下压毫米数会让不同初始体积具有不同压缩比例，不宜直接作为所有高度的统一规则。

### 9.2 参数扫描

- 在所有目标高度上扫描不同下压幅度、释放压强、下压时长和短暂停留。
- 至少比较当前历史区间附近的多个候选，不预先认定 `120–130 kPa` 正确。
- 同时评价：理想模型偏差、真实正确操作的 `γ` 偏差、重复性、可用周期数、曲线平滑度、传感器信噪比、达到目标的操作难度、对正常手速波动的敏感性和机械行程裕量。
- 不能只选“算出来最接近 `1.40`”的点；若接近来自两种误差抵消，该候选应淘汰。

### 9.3 落地范围

- 最终参数统一进入演示模式和引导模式。
- 演示动画的下压时长、位移和停留重新按最终标准制作。
- 引导清单说明大概需要多快、约多久，但不要求用户命中精确秒数，也不按秒数评分。
- 完成第一次有效曲线并点击暂停后，按第 2.9 节规则弹出一次实验说明。
- 更新权威参考文献 MD；删除产品代码和正式文案中的旧压强标准及废弃候选。

## 10. 第六阶段（已完成检查点）：主体自由模式闭环与传感器观测校准

### 10.1 主体闭环门禁

- 用 `3–6` 组、系统高度与自定义高度覆盖从计划建立、按压、连续显示、暂停、保存、数据处理、计算、拟合、退出、恢复和主动重置的完整流程。
- 在 `80 mm / 120 kPa` 手感锚点上分别人工验证慢压、快压、压住短暂停留以及回稳后再次按压；记录必须按真实 `1000 Hz` 样本连续增长，界面允许以较低刷新率批量绘制，但不能丢样本或整段跳显。
- 释放运动锁结束后恢复 Space 和鼠标；同一记录中后续按压和释放形成新的真实片段，不覆盖或伪造前一段。
- 本阶段发现的主体阻断问题可以修复；不借验收之名加入新的物理因素。

### 10.2 传感器候选层

- 分开比较真实气体状态、传感器内部响应和图表刷新，不能把 UI 绘图延迟当成传感器滞后。
- 当前候选层包含一阶响应、缓慢线性漂移、长周期游走、约 `2 ms` 的快速连续相关分量、约 `18 ms` 的慢速连续相关分量、极少量独立噪声和 `0.01 kPa` 量化；每项保持独立参数、状态、随机种子和版本快照。相关微波动只改变观测压力，不反馈到底层气体或活塞运动。
- 新传感器会话使用新种子，同一会话内按样本序号连续推进；正式 Run 保存量化样本与观测配置、首尾状态，恢复后不得重新抽取随机数。旧 `lag-drift-v2` 记录保持原样可读，不迁移成新的波动结果。
- 人工验收至少比较快压、慢压、快压后停留三种操作，确认监测读数和记录曲线的差异可见但不过度拖尾。
- 没有实物阶跃响应和长时间零点记录时，只能做教学候选手感调整；不能把参数写成 PASCO PS-2181 的实测规格。

### 10.3 本阶段明确不做

- 不加入显式摩擦、倾斜、泄漏和环境随机扰动。
- 不给下压速度、停留或松手时间差评分。
- 不修改学生计算公式、评分区间和已有存档语义。

## 11. 第七阶段（已完成检查点）：活塞振动法仪器声音

- 复用现有全局音频总线、音量设置、并发策略和静音降级，不另建第二套声音系统。
- 先确定需要声音的真实事件及素材来源，再分别接入螺钉、软管、平台接触、下压/释放和振动等事件；没有可信声音的事件可以保持无声。
- 声音订阅物理与交互事件，不反向决定动画、采集或状态机完成时刻。
- 自动测试覆盖重复触发、快速操作并发、模式切换、静音、资源缺失和刷新恢复；人工验收关注响度、节奏、空间感和是否令人疲劳。

## 12. 第八阶段（当前 8A 范围）：错误操作因果矩阵与证据闭环

### 12.1 先使用已有机制形成错误后果

- 优先覆盖错误目标高度、软管状态错误、采样率或阈值不合适、过早暂停、周期框选不当、重复按压以及错误计算输入。
- 分别测试 `0、1、2、3` 个错误 Run；一个错误点覆盖高、中、低位置，多个错误点覆盖相邻点、首尾点和同方向一致偏差。
- 每个场景记录是否能继续、是否能形成正式曲线、可用周期数、周期稳定性、能否拟合，以及斜率、截距、`R²` 和 `γ` 的偏移。
- 结果归入“无法继续”“可继续但数据质量差”“可完成但结果偏差”；不能为了显示错误而额外添加没有因果依据的随机坏曲线。
- 当前 8A 只验证并保存已有模型的真实后果；若诊断结果不符合预期，先形成报告并与用户讨论，不直接修改物理模型。
- 自由模式允许任意框选，只要求选区存在 `0.5` 个主周期。整条记录明确不足半个主周期时，处理界面显示 `1 s` 后返回采集并只重做当前 Run；局部框选过窄时只重选，不退回实验。
- 自动重做保留采样率、触发阈值、电源和其他 Run，重置为软管断开、活塞 `0 mm`、螺钉完全松开；替代记录完成后返回原处理 Run，连续不可用时按同一规则重复。
- 自由模式的 `t₁、t₂、T` 和最终 `A、γ、相对误差` 分别统一校验；字段按顺序显示但在统一校验前可回改，无法解析的草稿不计正式错误尝试。引导模式继续逐步校验。

### 12.2 过程回顾边界

- 本阶段先建立稳定评价事件和证据接口；过程回顾 UI、评分权重和扣分文案另行确认。
- 下压速度、停留、释放速度和带符号松手时间差可以作为信息项，在用户另行确认前不扣分。
- 自由模式运行过程中继续不弹步骤错误提示；评价集中在实验完成后的回顾阶段。
- 当前 8A 不制作过程回顾页面、不设置三档评价或数值评分；只建立可持久化的 Run、排除原因、操作、判定报告和计算尝试证据。

### 12.3 有余量时再加入的真实机制

- 释放不同步引起的倾斜、侧向接触和额外摩擦必须先有直接资料、实物观察或可复核模型；摩擦不再作为传感器之前的必做阶段。
- 正常机械摩擦、静摩擦/库仑摩擦、环境扰动、泄漏和其他观测偏差每次只新增一个机制，并分别完成正确/错误小闭环和灵敏度分析。
- 只有各机制能够单独辨识后才联合校准；不允许多个自由参数互相补偿。

## 13. 每增加一个模型的固定小闭环

1. 收集直接证据，写清因果链、适用范围和未知项。
2. 定义输入、内部状态、输出、参数、单位、默认值、范围、随机种子和模型版本。
3. 运行零损耗/理想不变量，确认基础方程没有被新模型破坏。
4. 运行正确操作基线，确认周期、衰减、拟合和 `γ` 仍合理。
5. 运行该机制的错误场景，区分无法继续、坏数据可继续和错误结果三类。
6. 检查一个、两个、三个错误点及其在拟合区间不同位置的影响。
7. 保存参数来源、操作事件、物理快照、观测样本、结果和评价证据。
8. 补齐确定性测试、持久化恢复和版本迁移。
9. 通过人工验收后再进入下一个机制。
