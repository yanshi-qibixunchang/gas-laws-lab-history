# 顶部玻璃旋塞 / 玻璃活塞阀说明

## 一、位置

玻璃旋塞位于左侧玻璃气瓶的最顶部。

空间关系为：

方形透明玻璃气瓶
→ 顶部瓶颈
→ 米黄色橡皮塞
→ 透明玻璃旋塞 / 玻璃活塞阀
→ 外界空气通道

它安装在橡皮塞上方，是控制瓶内空气是否与外界连通的关键部件。

## 二、外观结构

简化建模时可以把它理解为：

### 1. 一个横向透明玻璃管
- 位于瓶口正上方。
- 横向展开，像一个小的玻璃圆筒。

### 2. 一个竖向玻璃接口
- 从横向玻璃管向下连接到瓶口。
- 通过橡皮塞与瓶内空间相通。

### 3. 一个可旋转的玻璃阀芯 / 把手
- 位于横向玻璃管中部或侧面。
- 外观看起来像一个短的竖直小玻璃把手。
- 通过旋转改变内部通道方向。

## 三、控制通气和断气的原理

玻璃旋塞内部有一个小孔道。

当旋塞内部孔道与玻璃管方向对齐时：

- 瓶内空气通道打开。
- 瓶内空气可以和外界相通。
- 可以进气、放气或快速释放瓶内压力。
- 这时称为“通气状态”。

当旋塞内部孔道旋转到与玻璃管方向垂直时：

- 通道被堵住。
- 瓶内空气不能再与外界交换。
- 玻璃瓶变成近似封闭容器。
- 这时称为“断气 / 关闭状态”。

简单理解：

- 旋塞打开 = 瓶内和外界连通
- 旋塞关闭 = 瓶内和外界隔绝

## 四、在实验中的控制效果

### 1. 打气阶段
- 通过打气控制向瓶内输入空气。
- 顶部旋塞或相关气路处于允许进气的状态。
- 瓶内压强升高。
- 压力表和压力显示区读数上升。

### 2. 封闭阶段
- 旋转玻璃旋塞，使通道关闭。
- 瓶内空气被封闭。
- 此时可以观察瓶内气体状态变化。

### 3. 快速放气阶段
- 重新打开玻璃旋塞。
- 瓶内高压空气迅速与外界连通。
- 空气向外释放，瓶内压力下降。
- 气体膨胀过程中温度也会发生变化。
- 瓶内杆状温度传感器用于感知这种温度变化。

## 五、建模时如何表现

建议建模为一个简化的“三通玻璃阀”结构：

### 1. 横向透明圆柱玻璃管
- 表示主气路。

### 2. 下方短竖管
- 连接橡皮塞和瓶内空间。

### 3. 侧边或中间小竖直把手
- 表示可旋转阀芯。
- 这个把手不需要复杂机械结构，只要让人看出它是控制开关即可。

### 4. 可加一个小标注
- 玻璃旋塞
- 通气 / 关闭
- 控制瓶内空气与外界连通

## 六、给图像模型的提示词补充

顶部不要只画成普通玻璃管，要明确画成一个可旋转的玻璃旋塞 / 玻璃活塞阀。
它由横向透明玻璃管、向下连接瓶口的竖向接口、以及一个可旋转的小玻璃把手组成。
该部件用于控制瓶内空气与外界的连通状态：

- 旋塞打开时，瓶内与外界通气，可以进气或放气；
- 旋塞关闭时，瓶内空气被封闭，用于维持实验中的压缩空气状态。

建模时不需要画复杂内部孔道，但要保留“阀门 / 旋塞”特征，而不是画成普通装饰玻璃管。

## 七、关键修正一句话

顶部所谓“活塞”应理解为**玻璃旋塞 / 玻璃活塞阀（glass stopcock）**，它通过旋转内部孔道来控制瓶内空气与外界的通气或断气，不是上下推动式活塞。
