## 使用边界

- 真实数据用于约束周期量级、周期随高度变化、衰减持续时间和压力水平。
- 真实四组记录不足以唯一确定摩擦、阻尼、死体积、传感器延迟和噪声等全部参数，不应进行过拟合。
- 工作流测试应使用独立、固定的测试记录；绑定物理模型版本的科学结果测试可以引用本数据作为外部量级参考。
