# 空气比热容比 Free Mode 六类基线测试结果

生成日期：2026-07-13

本页数值校准仅适用于空气 `gammaTrue = 1.4`，不把空气数值区间套用于其他气体。

## 1. 当前默认真实参数结论

本轮把放气时序统一到三模式共用状态机，并按新的真实主放气区间重标定流动强度：

- 标准打气：18 次，第 1 次在 `0s` 开始、第 18 次在 `8s` 开始，末次 `0.08s` 行程于 `8.08s` 完成。
- 进气量：`pumpAmountGainRatio = 0.00334`，在 `2 L` 容器中等效每次进气 `6.68 mL`。
- 压缩功保留：`pumpWorkRetention = 0.30`；仅控制泵入能量中保留在瓶内气体的比例，不改变进气量。
- 统一温度标定：环境基线 `1498.7 mV`，灵敏度 `5.0 mV/K`。
- 空气标准组的温度电压峰值验收只要求 `> 1500 mV`；当前固定无噪声场景观测值约为 `1505.05 mV`，该观测值不构成额外的上下限区间。
- 开启动画 `420ms`、关闭动画 `420ms`；动画期间背景物理继续，但只有开启动画完成后才进入主放气。
- 放气阀有效开度：`aperture(releaseElapsedS) = smoothstep(releaseElapsedS / 0.1s)`，放气流量使用时间段内的积分开度。
- 放气流动强度：`stopcockFlowRate = 0.79`。该值让 `0.375s` 标准主放气接近理论结果，同时保留过短/过长的真实偏差趋势。
- 最佳时序窗口为 `[0.30s, 0.50s]`（含边界）；自动演示固定 `0.375s`。
- 开启动画完成前关闭为快速开关：不形成主放气、不产生失败条，可在关闭完成后重试。
- 低压传感器不敏感模型：默认开启，`kneeMv = 15`、`minGain = 0.65`、`exponent = 1.4`。
- 打气阀打开期间气体交换模型：默认开启，`gasExchangeRatePerS = 0.005`、`thermalConductanceWPerK = 0.004`、`openingDelayS = 0.42`。
- 独立环境扰动模型：默认开启，强度较弱，`pressureAmplitudeKPa = 0.002`、`temperatureAmplitudeK = 0.015`。

## 8. 保留问题

- U1 等待过久对 gamma 本来不应非常敏感，后续仍建议在诊断层解释为流程/读数风险，而不是强制让物理结果崩坏。
- `0.03s/0.05s` 已经能在物理层产生极大偏离，不需要再向 gamma 写入人工时长惩罚。
- 时序分以 `[0.30s, 0.50s]` 为满分窗口，窗外按距最近边界的绝对秒数指数递减，并以五成双量化到 `0.5` 分；严重偏差使用统一低分档。
- 快速开关（开启动画完成前关闭）与极短真实放气不同：前者根本不形成 release，时长为 0，并允许重试。
