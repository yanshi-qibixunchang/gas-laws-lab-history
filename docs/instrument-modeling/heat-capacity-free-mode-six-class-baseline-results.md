# 空气比热容比 Free Mode 六类基线测试结果

生成日期：2026-06-19

## 1. 当前默认真实参数结论

本轮继续保留三个新增真实模型，并只微调低压传感器不敏感参数：

- 低压传感器不敏感模型：默认开启，当前真实参数为 `kneeMv = 15`、`minGain = 0.55`、`exponent = 1.4`。作用是让低 U1/U2 信号的统计误差更大，并让慢打气导致的低信号更明显地反映到 gamma。
- 打气阀打开期间的气体交换模型：默认开启，`gasExchangeRatePerS = 0.005`、`thermalConductanceWPerK = 0.004`、`openingDelayS = 0.42`。这部分没有继续增强，以避免破坏每次打气约 7 mV 和标准 5 min 后约 114 mV 的真实参考。
- 独立环境扰动模型：默认开启，强度较弱，`pressureAmplitudeKPa = 0.002`、`temperatureAmplitudeK = 0.015`。

本轮调参后的核心变化：50s 慢打气的 30 次均值从约 `1.376` 降到约 `1.365`，同时 12s 正常操作仍通过最佳操作验收区间。

## 8. 保留问题

- 极短放气 `0.03-0.05s` 当前不会自然造成 gamma 崩坏；是否要判错，应放到 UI 交互有效性和诊断报告阶段重新定义。
- U1 等待过久对 gamma 本来不应非常敏感，后续仍建议在诊断层解释为流程/读数风险，而不是强制让物理结果崩坏。
