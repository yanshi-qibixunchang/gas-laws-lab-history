# 活塞振动法正确操作基线（当前版）

确认状态：已由用户于 `2026-08-27` 确认为后续自由模式和真实模型共同使用的正确操作基线。

## 文档用途

- 本文固定下一阶段所有真实模型共同使用的“正确操作”参照。新增摩擦、环境、传感器或其他机制时，必须先证明正确操作仍能得到合理曲线和结果，再验证错误操作的后果。
- 本文只保留当前建议，不并列保存旧选区方案。来源数据和原始选择保存在 `reference/piston-oscillation-real-data/`，历史变化由 Git 追溯。
- 当前基线分为“已固定规则”和“待模型验证的暂定参考”。暂定参考不得在没有证据时被解释成真实仪器常数。

## 证据边界与数据质量

当前真实参考 CSV 包含 `50、40、30、20 mm` 四组并列记录；每组均为 `0.000–0.500 s`、`501` 个样本、`1000 Hz`，没有缺失值、重复时间或时间倒序。第 2 组首个时间值约为 `10⁻¹⁰ s`，是原始导出的近零浮点痕迹；第 4 组表头虽然写作 `60 mm`，但已由用户确认应解释为 `20 mm`。

这四组数据足以约束周期量级、衰减区间、尾部形态和人工框选习惯，但不足以唯一识别摩擦、热交换、死体积、传感器动态及噪声，也不能作为最终 `γ` 的单一真值来源。

## 正确操作的当前时序

| 阶段 | 当前基线 | 性质 |
| --- | --- | --- |
| 仪器准备与高度调整 | 按实验规范的状态顺序完成，不用固定秒数代替“接管、锁紧、调高、旋松”等真实完成条件 | 已固定为状态驱动 |
| 开始采集前稳定 | 进入后台稳定检查至少 `1.2 s` 后，放行时必须同时满足软管已接、螺钉已完全旋松、双手已释放、活塞静止、目标高度误差不超过 `0.25 mm` | 当前软件门禁 |
| 向下按压 | 平稳按至绝对压强 `120–130 kPa`；自动演示当前约用 `1.1 s` 完成按压 | 压强范围已固定；`1.1 s` 只是可重复的演示参考，不是物理常数或评分阈值 |
| 底部停留 | 达到目标压强后不要求故意停留，应直接准备释放；自动演示中约 `0.4 s` 的平台停留只用于让操作可看清 | 不进入当前物理模型和评分；加入热过程模型时重审 |
| 双手释放 | 正确操作的理想时间差为 `0`，即尽量同时释放 | 因果方向已固定；可接受、小过失和严重错误的毫秒阈值留给第一版释放扰动模型 |
| 正式触发 | 绝对压强由高向低穿过 `120 kPa` 时开始正式记录，不保存按压高压段 | 已固定 |
| 正式记录 | 固定记录 `0.500 s`，即包含 `t=0` 在内的 `501` 个 `1000 Hz` 样本 | 已固定 |

因此，不计高度设置和接管等状态操作，从进入稳定检查到一条 Run 冻结的当前最短参考约为 `3.2 s`；从开始按压到 Run 冻结约为 `2.0 s`。这两个总时长仅用于流程节奏估计，不能取代各阶段的状态和压力条件。

## 周期框选的唯一当前规则

1. 不从 `t=0`、触发穿越点或释放瞬间开始框选；先越过触发后的非周期启动段。
2. 起点取启动段之后第一个清晰、完整的波峰或波谷，终点必须是同相位极值。这里跳过的是触发点到首个可用极值之间的短距离，不默认舍弃整整一个周期。
3. 如果第一整个周期已经明显畸变，并且后面仍能保留至少三个完整周期，可以把起点顺延到下一个同相位极值；不能为了改善最终 `γ` 而顺延。
4. 正确操作基线默认框选 `3` 个完整周期。第 `4` 个周期只有在振幅、弧线和周期宽度仍清晰时才可纳入；当前不建议用超过 `4` 个周期作为统一教学选区。
5. 末端应停在明显低振幅尾段之前；出现额外小峰、小谷、局部缺口、明显不等宽或接近噪声的波动时，舍弃这些尾部周期。
6. 选区先按波形质量确定，再计算 `T`、拟合和 `γ`；严禁根据结果是否接近 `1.40` 反向挑选窗口。

自由模式可以允许用户框选少于三个周期并继续处理，但系统必须保留该选择及其后果用于过程评价；这不改变上面的正确操作标准。

## 真实四组数据对统一三周期规则的支持

以下窗口都从首个清晰同相极值开始，只取前三个完整周期。它们不覆盖用户原始确认的 `6、4、4、3` 周期选区，而是用于检验能否建立所有高度一致遵循的教学规则。

| 高度 | 起止相位 | 三周期窗口 | 平均周期 | 三个周期的变异系数 | 末端相对稳定压强振幅 |
| ---: | --- | --- | ---: | ---: | ---: |
| `50 mm` | 谷到谷 | `0.010–0.100 s` | `30.00 ms` | `0.00%` | `3.54 kPa` |
| `40 mm` | 谷到谷 | `0.009–0.095 s` | `28.67 ms` | `1.64%` | `4.76 kPa` |
| `30 mm` | 峰到峰 | `0.021–0.100 s` | `26.33 ms` | `1.79%` | `3.43 kPa` |
| `20 mm` | 谷到谷 | `0.007–0.073 s` | `22.00 ms` | `3.71%` | `3.77 kPa` |

四组都能支持从首个清晰极值开始的三个完整周期，且不需要统一强制跳过第一个完整周期。只有部分高度能稳定支持第四个周期，因此“默认三周期、清晰时选四周期”比统一选四个以上更可靠。

如果改为专取每组最后三个可见周期，拟合得到的 `γ` 会偶然更接近 `1.40`；但 `50 mm` 选区末端的振幅已降至约 `0.94 kPa`，三周期宽度变异系数约为 `5.27%`，明显比早期稳定段差。该方案属于结果驱动选择，不能作为正确基线。

用户原先确认的 `6、4、4、3` 周期窗口按同一套仪器常数计算时，约得到 `γ=1.489`、`R²=0.963`。这进一步说明真实四组数据应作为曲线形态和量级证据，而不应强迫当前软件逐点拟合成该结果。

## 当前软件的结果回归锚点

当前引导模式使用 `80、70、60 mm` 三个高度和最早合法三周期选区；在现有物理模型版本下，回归结果约为：

- `60 mm`：`T≈33.00 ms`；
- `70 mm`：`T≈35.67 ms`；
- `80 mm`：`T≈37.67 ms`；
- `h-T²` 拟合斜率 `≈60.3524 m/s²`，截距 `≈-0.006052 m`，`R²≈0.99590`；
- 使用当前教学计算常数得到 `γ≈1.37917`，相对 `1.40` 的偏差约 `1.49%`。

这些数值是新增真实机制之前的版本绑定回归锚点，不是永久不变的自然常数。新增模型后，正确操作首先应保持：三个高度均有至少三个清晰可处理周期、周期随高度变化方向正确、`R²` 不因新增错误机制在正确操作中无故恶化、`γ` 仍落在合理教学范围。

第一轮联合验收可暂用 `R²≥0.99` 且 `γ` 相对 `1.40` 的误差不超过 `3%` 作为候选门槛。正确操作流程和选区规则已经确认；这里的数值门槛仍只是下一模型阶段的测试建议，需要结合更多实物或文献证据后才能升级为正式评分阈值。

## 第一版释放扰动模型需要验证的基线矩阵

1. 三个高度全部正确释放：重跑本文件的正确结果锚点。
2. 仅低、中、高高度之一出现释放时间差：分别观察单点偏移、斜率、截距、`R²` 和 `γ`。
3. 两个高度出现同级错误：覆盖相邻两点与首尾两点组合。
4. 三个高度均出现同方向、同等级错误：确认系统能够得到一致但错误的拟合，而不是仍返回正确值。
5. 对每种位置分别测试小过失和严重错误，并测试左手先松、右手先松；如果当前摩擦模型只取时间差绝对值，必须明确记录“方向效应尚未建模”，不能静默丢弃原始顺序。
6. 每个场景同时记录曲线可用周期数、周期稳定性、是否能够完成计算，以及最终评价事件；正确基线与错误基线共用同一数据链和选区算法。
