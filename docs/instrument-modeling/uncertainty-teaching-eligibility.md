# 两个热容实验的不确定度教学适用条件

2026-09-24：两个实验的计算入口和统一记录标准如下；活塞法与绝热法均已接入 A 类、B 类、合成标准不确定度及报告教学。不调整原有物理模型和已批准的不确定度来源。

## 判定依据

- 使用本组采集时冻结的参数，不使用当前侧栏参数，也不信任存档中缓存的“可计算”标记。
- 真实模拟模式，空气和氦气分别匹配自身的标准真实参数。关闭仪器噪声、改动阻尼/传热/泄漏/传感器等模型参数时，只保留基本数据计算。
- 环境温度允许 10～35 ℃（283.15～308.15 K），大气压允许 80～110 kPa，均包含端点。这是本课程预算的适用范围，不是仪器实际工作范围或输入控件的总范围。
- 温度和气压沿用现有环境、传感器与数据处理函数；压力传播使用本组公开压力。仪器教学给定值不凭空随环境参数缩放。
- 活塞采样率允许 1～1000 Hz，使用记录中的实际采样率和选取周期数，保留现有端点计时传播函数。触发阈值沿用随环境压力缩放后的合法范围。采样不足、不可辨识周期、退化拟合等仍由原有数据检查处理；不把这些情况称为理想模式。
- 高度、测量次数、选点、自然操作过程与纯显示开关不要求锁为一个固定值。模型参数和实验操作参数分别处理。

## 绝热膨胀法的统一记录标准

从高级参数中移除以下 8 项编辑入口；新实验冻结前统一应用原有默认值：

| 内部参数 | 默认值 | 保持的用途 |
|---|---:|---|
| 零点容差 | 0.12 mV | 原有零点判定 |
| 压强稳定斜率阈值 | 0.25 mV/s | 原有稳定性判定 |
| 温度稳定斜率阈值 | 0.3 mV/s | 原有稳定性判定 |
| 环境温度接近容差 | 0.875 mV | 兼容旧参数；本次不新增使用它的拦截条件 |
| 最小有效 U₁′ | 90 mV | 原有操作质量评价，不新增硬性记录拦截 |
| 最小 U₂′ | 0.2 mV | 原有过度放气判定 |
| 压力预警值 | 120 mV | 原有预警 |
| 压力危险值 | 140 mV | 原有安全判定 |

历史冻结参数和原始记录不改写。旧自定义阈值的实验保留基本计算，提示按统一标准重新实验才能进入不确定度教学。新实验不能从旧草稿继承可变阈值。

## 计算、保存与导出

- 活塞法符合条件时使用现有不确定度课程；不符合时保留周期、拟合、γ、相对误差及现有统一精度规则。
- 绝热法的标准差、A 类、B 类、合成及报告按同一条件显示；理想/非标准实验仅保留逐次计算、平均值和相对误差。
- 不更改表格结构、二级弹窗尺寸和公式样式。跳过时给出简短原因。
- 恢复时重算适用性，重放仍适用的答案；不以缓存标记绕过采集参数。导出的不确定度及图中 A 类误差范围遵循同一条件。历史仪器配置与记录证据继续保留。
- 详细仪器预算假设、给定值包含范围和防止重复计入等，仍留作教学附录待办。
