# 绝热膨胀法引导模式：初始步骤强提醒后续项

日期：2026-08-23  
状态：已记录，待活塞振动法本轮验收后处理

## 现象

进入绝热膨胀法引导模式后，在第一个“打开电源开关”步骤连续进行两次错误操作，普通错误反馈可能出现，但不会按既定节奏升级为强提醒。

## 预期

- 引导模式从第一个可操作步骤开始即启用误操作计数。
- 在“打开电源开关”步骤连续两次执行当前步骤之外的操作时，应沿用正式动作守卫的普通提示、控件回弹和强提醒触发节奏。
- 修复不得把尚未进入引导模式的普通浏览行为计入误操作，也不得改变其他已经验收的绝热膨胀法引导步骤。

## 本轮边界

本文件仅记录复现条件和期望行为。活塞振动法的双手语义、动作守卫、平台失去托举恢复和强提醒布局完成并验收前，不修改绝热膨胀法实现。
