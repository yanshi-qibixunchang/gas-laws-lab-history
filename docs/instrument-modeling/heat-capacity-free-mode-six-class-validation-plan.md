# 空气比热容比 Free Mode 六类测试方案

更新日期：2026-06-19

## 0. 统一规则

- U1 等待从打气阀关闭后开始计时。测试中默认最后一次打气后 0.5s 关闭打气阀。
- 放气时间指物理开阀时间，不包含点击 0.05s、阀门转动动效或 UI 动画时间。
- U2 等待从旋塞关闭后开始计时。
- 理想类关闭漏气、泵阀交换、环境扰动、传感器噪声、低压非线性和额外读数扰动。
- 真实类开启热交换、弱漏气、泵阀交换、传感器滞后、量化、噪声、低压非线性和弱环境扰动。
- 所有随机/扰动都必须由固定 seed 产生，禁止在物理或传感器链路中使用 `Math.random()`。
- 本轮不把所有错误都压成 gamma 硬阈值。若真实物理只造成 U1 降低、可靠度降低或趋势变差，应记录为后续诊断层处理，而不是加入不真实的惩罚项。

## 1. 放气阀有效开度规则

本轮放气模型采用：

```text
放气流量 = 理论压缩气体放气流量 * aperture(openElapsedS)
x = clamp(openElapsedS / 0.1, 0, 1)
aperture = x * x * (3 - 2 * x)
```

验收约束：

- 每个物理时间段必须使用积分开度或区间平均开度，不能只取步末开度。
- `0.03s` 必须按真实 `0.03s` 物理开阀计算，不能被 `0.05s` 点击或最小步长吞并。
- `0.03s` 相比 `0.35s` 的无噪声 gamma 差距必须大于 `0.05`。
- `<0.1s` 和 `>2.5s` 的 UI 诊断判定留到诊断/UI 阶段；物理层只保证数值真实演化和偏离可观测。

| 单项 | 扫描值 | 验证目的 |
| --- | --- | --- |
| 打气次数 | 4, 8, 12, 16, 18 | 验证低压 MAE 随次数接近 18 非线性下降 |
| 打气总时长 | 12s, 50s, 120s | 验证慢打气通过泵阀交换降低 U1，并由低压传感器不敏感放大低信号误差；50s 四舍五入进入 1.36 段，120s 进一步变差 |

## 7. 单项错误操作

当前必须通过的错误检验：

| 错误项 | 定义 | 当前要求 |
| --- | --- | --- |
| U1 过早记录 | U1 等待 0s | gamma 超出 1.3-1.5 |
| U2 过早记录 | U2 等待 0s | gamma 超出 1.3-1.5 |
| 极短放气 | 0.03s / 0.05s | 相比 0.35s 产生明显偏离；0.03s 与 0.35s 的 gamma 差距大于 0.05 |
| 放气过长 | 2.5s | gamma 超出 1.34-1.46 |
| 放气极长 | 10s | gamma 超出 1.3-1.5 |
| U2 等待过久 | 600s | gamma 超出 1.37-1.43 |
| U2 等待很久 | 1200s | gamma 超出 1.34-1.46 |
| 打气过少 | 4/8/12/16/18 统计 | MAE 随次数接近 18 下降，且改善放缓 |
| 打气太慢 | 50s/120s | 50s gamma 四舍五入进入 1.36 段，120s 进一步变差，U1 随总时长降低 |

暂不硬性要求但要记录：

- 50s 慢打气不要求自然超出 1.3-1.5；当前要求是相对标准操作明显变差，后续诊断层仍应按慢打气扣分。
- `<0.1s` 和 `>2.5s` 的具体 UI 告警阈值留到诊断/UI 阶段确定。
- U1 等待过久不强制让 gamma 崩坏；真实物理上它通常不应强烈影响 gamma。
