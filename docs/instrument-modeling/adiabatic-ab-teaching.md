# 绝热膨胀法自由模式：A＋B 标准不确定度教学

更新：2026-09-24。本说明集中记录当前计算流程、精度及虚拟仪器教学预算，不保留并行的旧版教学方案。仿真物理模型、原始显示规则和真实／理想模式的适用条件保持不变。

## 仪器给定量与依据

- u仪器(U)=0.1 mV 为直接给定的标准不确定度。这是虚拟仪器教学设定，不是厂家规格，不再除以 √3。
- 仪器原始读数仍按 0.1 mV 显示步长向零截断。显示步长与标准不确定度是不同概念，给定预算包含显示影响，不再叠加显示项。
- P₀、环境温度、S=20.00 mV/kPa 作为已知条件，不另设不确定度。
- 敏感系数传播与平方和合成依据：[NIST Combining](https://physics.nist.gov/cuu/Uncertainty/combination.html)。该资料支持通用方法，不规定本软件的给定数值和相关性假设。

## 传播假设与系统计算（附录内容）

三个测量位置 U₀、U₁、U₂ 的仪器影响 δ₀、δ₁、δ₂ 按不相关处理；每个位置的仪器影响在三次同条件实验中共用。给定 0.1 mV 约定为本组重复实验离散未充分反映的仪器残余影响，包含显示影响；不再另加已通过重复结果进入 A 类的采样噪声。实验间离散由 A 类评定，A 与 B 按不相关处理。这是用户确认的简化教学预算，不声明已从记录证明无重叠、实际仪器满足这些条件或所有实际影响均已覆盖。

手动 U₀ 优先，否则使用有效自动 U₀。缺失记录不当作零。同次两次电压修正使用同一公开零点，采集判定、计算及保存恢复统一使用该记录；仪器给定值不因三次重复或重新记录零点而机械缩小。

对第 i 次实验，Lᵢ=ln(P₁ᵢ/P₂ᵢ)，使用已公开、按课程位数修约的 P₀、P₁ᵢ、P₂ᵢ、S，在现有未修约的测量方程上求敏感系数（不对修约操作本身求导，也不另算一套学生 γ）：

```
c₁ᵢ = ln(P₀/P₂ᵢ) / (S P₁ᵢ Lᵢ²)
c₂ᵢ = ln(P₁ᵢ/P₀) / (S P₂ᵢ Lᵢ²)
c₀ᵢ = −c₁ᵢ − c₂ᵢ
cⱼ = (cⱼ₁ + cⱼ₂ + cⱼ₃) / 3
C = √(c₀² + c₁² + c₂²)   [mV⁻¹]
```

同一 U₀ 同时用于两次电压修正，先合并它的系数，不能将它当成两个独立零点。先平均每个位置的敏感系数，再平方和开根号；不机械地把仪器项除以 √3。三次完全相同的实验不会使 C 缩小。C 随本组公开数据计算，公开四位有效数字后，后续直接使用这个值。

## 学生流程与精度

原始三次读数 → 修正电压 → 压强 → 各次 γ → 平均 γ → 标准差 → A 类 → 平均 γ 的 B 类 → 合成标准不确定度 → 相对误差 → 最终报告。

| 内容 | 教学计算 |
| --- | --- |
| U₀、U₁、U₂ | 沿用仪器向零截断至 0.1 mV 的原始记录；不补位制造测量精度 |
| 修正电压 | U′₁=U₁−U₀，U′₂=U₂−U₀，1 位小数，mV |
| 压强 | P₁=P₀+U′₁/S，P₂=P₀+U′₂/S，3 位小数，kPa；P₀ 全程使用系统公开给定精度 |
| 各次 γ | γ=ln(P₁/P₀)/ln(P₁/P₂)，4 位有效数字 |
| 平均 γ | 三次已核验 γ 的平均值，4 位有效数字 |
| 系统统计量 Q | 根据已核验 γ 和平均值计算 Σ(γᵢ−γ̄)²，公开 4 位有效数字；显示值即后续操作数 |
| 标准差 s | √[Q/(3−1)]，3 位有效数字 |
| 平均值 A 类 | uA(γ̄)=s/√3，3 位有效数字 |
| 电压仪器标准不确定度 | 表格直接给 u仪器(U)=0.1 mV，无换算题 |
| 系统已知量 C | 表格公开 4 位有效数字，单位 mV⁻¹ |
| 平均值 B 类 | 学生算 uB(γ̄)=C·u仪器(U)，3 位有效数字 |
| 合成标准不确定度 | 学生算 uc(γ̄)=√[uA²(γ̄)+uB²(γ̄)]，3 位有效数字 |
| 相对误差 | 同一份已核验、报告修约前的平均 γ；3 位有效数字 |
| 最终报告 | uc 保留 2 位有效数字，平均 γ 末位对齐；明确是标准不确定度，不追加置信概率或扩展倍数 |

计算修约沿用五成双。各题严格核验数值和书写位数；通过的值直接作为下一步操作数。A=0 仍接受，不自动增位、不提示异常，仪器 B 类继续保留。

上方表格只放变量、数值、单位，不预填未完成题目的答案。主流程简短说明给定标准不确定度乘 C；C 的三个来源放折叠解释，敏感系数推导和上述假设保留在本附录。不增加 √12、仪器内部来源或相关性计算题。保留 A 类的 s/√3 统计题。

最终报告为平均 γ ± 合成标准不确定度，不增加 k、扩展不确定度或置信概率。

## 数值验证依据

高精度参照仅由同一组公开 U₀、U₁、U₂、P₀、S 计算，不读取仿真真值。已有自动测试核对 2,503 组电压数据的逐步修约，包含典型、低离散、相同结果及最终两位修约边界；另核对 7,803 组 γ 组合的 Q 与标准差。参照用于核验实现，不据最终末位差异自动增位或采用额外 1%／2% 门槛。

三个 γ 修约后相同时，正常接受 Q=s=uA=0；继续评定仪器 B 类和合成标准不确定度。B 类测试核对对数公式的敏感系数、同位置共用影响、C 的公开精度、逐步保存恢复和旧预算迁移。

典型公开读数：(0.3,82.6,22.6)、(0.3,84.1,23.7)、(0.3,84.3,23.6) mV；P₀=101.3 kPa，S=20.00 mV/kPa。γ=1.379、1.395、1.392，平均=1.389，uA=0.00491；C=0.02956 mV⁻¹，u仪器(U)=0.1 mV，uB(γ̄)=0.00296，uc=0.00573；报告 1.3890 ± 0.0057（合成标准不确定度）。
