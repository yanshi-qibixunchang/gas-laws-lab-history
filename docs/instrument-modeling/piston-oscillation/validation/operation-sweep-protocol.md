# 活塞操作参数扫描口径（PO-CAL-001）

> 状态：模型敏感性验证合同；不属于实物标定标准
> 适用版本：6.4.0 未发布开发分支
> 最后核验：2026-09-14
> 来源：本项目原创；复用当前生产领域模型、观测层与精确计算链

本批完成 PO-CAL-001 的指标定义、可复现模型扫描及证据报告。目标是查明相同动作在不同高度下的结果差异，为实物采样和后续 PO-CAL-004 提供输入。引导阈值、演示动作、评分、物理参数与保存格式保持当前值。科学操作标准仍须结合新的可追溯实测，不以接近理论 γ 作为调参目标。

## 预先固定的扫描范围

扫描前固定以下网格及选区规则，运行后不按结果优劣删行或反向改变选点：

| 项目 | 扫描值或固定值 |
| --- | --- |
| 实验条件 | 当前 Real 空气默认参数档案；空气 γ、等效损耗、热交换、传感器和尾部候选模型均从源码读取 |
| 名义高度 | 80、70、60、50、40、30 mm |
| 虚拟手行程 | 120、160、200、240、300、350 参考像素（438 px 场景高度口径） |
| 下压时间 | 0.1、0.4、1.1、2.0 s |
| 下压结束后手部目标停留 | 0、0.1、0.4 s；柔顺手允许活塞回顶，不强行锁死最低位置 |
| 动作曲线 | 当前 Demo 使用的 smoothstep；按 1 ms 推进虚拟手受力求解器，沿用下压防反向约束 |
| 放手 | 双手同时释放，保留实际释放速度及完整热力学状态 |
| 观测 | 1000 Hz、120 kPa 下降触发、0.500 s/501 点；下压和释放连续共享传感器状态，正式观测保持 0.01 kPa 粒度 |
| 重复种子 | 11、29、47、71、101；同操作及高度间配对使用，尾部扰动使用产品原有派生种子 |
| 选区 | 最早被现行局部识别接受的两个完整主周期；端点来自正式观测样本，不依赖理论周期或拟合 γ 选择窗口 |
| 拟合集合 | 分别报告 80/70/60 三高度与全部六高度；任一点失败则整套记为失败，不删除失败点后拟合 |

共 72 个动作组合、432 个物理轨迹、2,160 个传感器观测实例。释放压强和实际下压幅度是受力与热模型算出的结果，不能与鼠标行程一起作为互相独立的任意输入。按压行程不是实物位移或仪器规格。此次只评估上述网格，未覆盖氦气、Ideal、自由自定义 10–29 mm、非同时释放或人工手势分布。

## 指标及解释

| 指标 | 计算方法 | 可作出的判断与限制 |
| --- | --- | --- |
| 触发率 | 每高度和动作的 5 个种子中，正式观测出现下降穿越的比例 | 未触发必须保留；不能替换成零时刻开始记录 |
| 两周期可处理率 | 找到局部识别接受的恰好两个主周期并通过当前端点/周期提交的比例 | 沿用产品门禁，不新增质量阈值 |
| 可识别主周期跨度 | 全记录主极值序号差的一半 | 描述现有算法输出，不等于人工确认的全部可用周期 |
| 振幅/噪声比 | 选区内最小相邻主极值压差 ÷（2 × 当前算法估计的噪声底） | 仅是观测质量代理量，不是独立测得的传感器 SNR，不设新的合格阈值 |
| 局部周期宽度变异 | 选区内相隔两个主极值的时间差的样本变异系数 | 含重叠区间，仅为描述性指标 |
| 观测重复性 | 同物理动作、同高度在 5 个种子下显示 T 的样本标准差和变异系数 | 只覆盖候选传感器扰动，不能代表人手重复性；零方差可能来自离散采样舍入 |
| 机械余量 | 全下压与释放轨迹的最低高度，以及 80 mm 减最高高度的参考差值；上侧实物机械净空记录为未知 | 0 mm是当前刚性下限；80 mm仅为名义平衡高度设置参考线，不能当作已测得的上行碰撞边界。采样间极值和真实装置间隙需另测 |
| 压力范围 | 全下压与释放轨迹的真实压力最小/最大值 | 用于模型诊断，不能混入学生答案；与当前模型 20–200 kPa 能力范围比较 |
| 结果偏差 | 固定窗口得到的显示 T→精确十进制平方→显示拟合坐标→显示斜率→A→γ→相对误差 | 直接调用当前产品计算；与1.40的差是模型教学偏差，不证明物理参数正确或错误 |

不会把“5/5成功”“误差小于若干百分比”写成新的科学标准。每个指标保留分母、失败原因和样本数量。三高度与六高度拟合分别统计，不相互替代；种子重复只有五次，不报告总体置信区间。

## 可追溯性和实测边界

现有参考文件 `capstone-piston-oscillation-4runs-1000hz.csv` 只有 50/40/30/20 mm 四条波形；第四组实际为20 mm，原表头不能改写。它缺少同步手部位移、完整下压时间、停留和释放前状态，也没有各条件重复试验，不能唯一识别多个损耗与观测参数。本批不重新拟合这份数据，也不把它当作扫描成功率的实测分母。

实测原件与解释：[真实采样参考数据](../references/real-data/README.md)。后续采样需记录每次名义高度和实际高度、完整按压/释放前后压强、同步手部位移或时间标记、释放时间差、环境、运动质量、采样配置及重复编号；原始观测必须保留。热损耗、机械阻尼和传感器参数的重新识别分别属于 PO-CAL-002/003。

上行范围另按证据分层：[PASCO产品规格](https://www.pasco.com/products/lab-apparatus/thermodynamics/heat-engine/td-8572)列出最大活塞位移约10 cm（2026-09-14核验）。这提供总行程量级，不能直接等同本机零刻度下的精确碰撞上限。源码的80 mm仅限制可设平衡高度，显示位置仍叠加振动偏移；报告单列越过80 mm参考线的次数，并保留上侧实物净空为未知。

## 复现与交付

在仓库根目录执行：

```powershell
node scripts/analysis/runPistonOperationSweep.ts
node scripts/analysis/runPistonOperationSweep.ts --check
npm.cmd test -- pistonOperationSweep.test.ts
```

生成目录为 `docs/instrument-modeling/piston-oscillation/validation/operation-sweep-v1/`。脚本只写该专用证据目录；`--check` 重新计算并比较，不写文件。结果保存全量逐例指标、三/六高度拟合、源文件指纹和代表性原始观测，报告保留全部失败条件。它不导入浏览器、工作区或持久化接口，也不参与应用构建。
