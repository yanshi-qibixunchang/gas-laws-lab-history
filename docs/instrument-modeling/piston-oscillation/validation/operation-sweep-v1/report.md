本轮 2160 个观测实例中，1706 个可按固定策略处理两个主周期，454 个未发生下降触发，另有 0 个未找到可接受的两周期选区。以上分母包括失败情况。采样点低于0 mm下限共 0 个，超出当前模型20–200 kPa压力范围共 0 个。

另有 360 个实例的反弹超过80 mm名义设置参考线，最高约 90.15 mm。源码中的80 mm限制用于平衡高度设置，振动位移继续叠加；不能据此认定真实装置已撞到上限。[PASCO当前产品规格](https://www.pasco.com/products/lab-apparatus/thermodynamics/heat-engine/td-8572)给出最大活塞位移约10 cm（2026-09-14核验），但该近似行程不是本机零刻度下的精确机械上限；本报告将上侧实物净空记录为未知。

扫描协议、指标定义和限制见[固定口径](../operation-sweep-protocol.md)。行程、时间和停留共同决定释放状态；不能从本模型的可处理率直接确定科学操作标准。以下所有范围包含5个固定种子，零变异可能来自采样和显示舍入。

## 证据边界与下一步

此次是固定候选参数下的模型扫描。现有四条实测未记录完整下压、停留和同步释放，且缺少80/70/60 mm及各条件重复，不能用于验证当前网格的操作成功率。此报告不把任何行程、时间、压强区间或误差上限升级为科学标准，也不重标定阻尼、热交换或传感器。
