# 比热容比实验：当前不确定度教学方案

更新：2026-09-24。两个实验的自由模式均采用 A 类、B 类与合成标准不确定度教学，最终报告为 γ（或平均 γ）± 合成标准不确定度，不乘覆盖因子。本文记录当前题单；绝热法详见 [A＋B 教学说明](../../instrument-modeling/adiabatic-ab-teaching.md)。

## 当前流程与教学颗粒度

保持现有二级计算弹窗、公式字体及“变量—数值—变量—数值”表格。前面完成周期、T²、拟合、面积、γ 和相对误差后，在同一弹窗继续不确定度计算。各阶段先短说明，再由学生作答和核验。

| 阶段 | 学生计算 | 系统公开数据 |
|---|---|---|
| A1 | T²̄=ΣTᵢ²/n | 各次 T² 和 n；单位 s² |
| A2 | Sxx=Σ(Tᵢ²−T²̄)² | 各次 T² 和已核验 T²̄；单位 s⁴ |
| A3 | sr=√[Q/(n−2)] | n、残差平方和 Q；可展开拟合点与残差 |
| A4 | uA(a)=sr/√Sxx | 已核验 Sxx、sr |
| A5 | uA(γ)=abs(γ/a)uA(a) | 同一计算链的 γ、a 和 uA(a) |
| B1 | uB(m)=Δm/√3 | Δm=0.0006 kg |
| B2 | uB(d)=Δd/√3 | Δd=0.1 mm，并在本题代入区给出 m 单位 |
| B3 | uB(γ)=abs(γ)√[(uB(a)/a)²+(uB(m)/m)²+(2uB(d)/d)²+(u仪器(P)/P)²] | u仪器(P)=100 Pa；按本次数据计算的 uB(a)；其余已核验量 |
| C1 | uc(γ)=√[uA²(γ)+uB²(γ)] | 已核验 A、B 类分量 |
| C2 | ur=uc(γ)/abs(γ)×100% | uc 和同一 γ |
| C3 | 报告中 uc(γ) 的修约 | uc 保留两位有效数字 |
| C4 | γ±uc(γ) 的结果表达 | γ 末位与报告中的 uc 对齐 |

A 类使用拟合斜率的统计公式，不把不同高度的点当作同条件重复测量。质量、直径保留误差限除以 √3 的训练。压强给定值已经是标准不确定度，不再除以 √3，也不追加显示分辨率项。传播公式说明各量及系数 2 的含义，不要求学生推导偏导数。

## 系统计算与附录边界

- 系统计算拟合、残差、Q；学生填写 T²̄ 和 Sxx，核验后进入上方表格。强调 T²̄ 是周期平方的平均值，不是平均周期的平方；无需逐项填写差值与平方。
- 标尺比例、时基比例、端点定位、逐点敏感系数及现有重叠处理仍保留在计算内核，不设逐项手算题。
- uB(a) 使用本次数据和同一计算链的 uA(a)，在 uA(a) 完成核验后进入上方表格。
- 学生后续所需操作数全部公开；每题通过核验的数即后续使用的数。
- 只在当前教学需要时提供简短说明和“为什么 n−2”折叠解释；√12、Hᵢ/Kᵢ、共用与独立分量及去重细节进入[附录待办](../../instrument-modeling/piston-oscillation/piston-uncertainty-teaching-appendix-todo.md)。
- 仪器依据及教学假设见[参数来源记录](../../instrument-modeling/piston-oscillation/references/piston-oscillation-uncertainty-source-audit-2026-09-20.md)。

## 计算与恢复

- 活塞当前课程：`piston-free-fit-statistics-uncertainty-v4`；精度链：`piston-continuous-precision-v1`。
- 当前仅有统一计算内核。无统一精度计划的旧拟合不能启动另一套不确定度计算。
- 旧 v1/v2 课程仅在迁移层识别，保留测量记录并提示重算。旧 v3 保留周期、拟合和基础计算，清除不确定度段的旧核验状态并提示重新完成；缺失的新题不会被视为已完成。
- 旧压强元数据只在迁移层辨认，当前仪器预算不保留这些字段。
- 答案的数值与书写精度均需通过核验，沿用现有精度计划与五成双规则。Sxx 使用已核验平均值，后续斜率 A 类使用已核验 Sxx。零值正常接受，不追加重复提示。
- 报告内容引用同一题单和计算结果，不保留独立的旧题目内容。报告样式留待下一轮调整。

## 界面与适用范围

- 两个实验沿用既定的[真实／理想及记录条件](../../instrument-modeling/uncertainty-teaching-eligibility.md)，不扩展物理模型。
- 保留现有四列表格、弹窗大小和正式公式样式，标题统一为“不确定度”。必要的定义、单位、精度和评定范围继续保留。
- 活塞题目统一复用同一答案组件；正确、错误、重试和查看答案状态一致。绝热法查看单次 γ 的答案后停留原页，由学生手动进入下一次或汇总。
- 当前清理不重新调整精度算法；附录整理和导出报告的视觉优化留待后续。
