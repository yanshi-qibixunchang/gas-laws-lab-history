## 1. 任务目标

1. 先以当前真实的“空气比热容比实验—自由模式—正常实验状态”为基线，制作恰好三套可比较的工程软件视觉方向，并等待用户选择。
2. 选定方案后，建立可回退的 Git 基线，清理本批新增/重构范围内被替代的旧实现、旧状态、旧样式、旧持久化、旧测试与错误文档口径。
3. 将产品身份统一为“采用绝热膨胀法测定空气比热容比的实验”，FD-NCD-C 仅作为主要参考仪器之一，不再作为产品身份。

5. 在独立分支 `codex/engineering-ui-redesign` 上，在完全保留现有布局、信息架构、控件位置、区域尺寸和交互关系的前提下，只统一软件自绘 UI 的配色、字体和字号层级，并仅为防止文字裁切做必要的局部适配。
6. 通过阶段提交、私有远端推送、测试、真实浏览器视觉检查和许可证核对形成可回退交付。

## 3. 已确认设计口径

### 3.1 视觉身份

- 主体是 MATLAB 式平面、紧凑、信息清晰；吸收 Inventor 式冷灰层级和克制工程蓝，不照搬任一软件。
- 亮色主题：冷灰、暖度受控的非刺眼白、浅蓝；暗色主题：深蓝、深灰、近黑，避免纯黑大面积铺陈。
- 区域主要通过表面明度、留白、对齐和必要中性分隔划分，避免卡片墙、彩色描边、发光边框和大面积渐变。
- 工程蓝用于主操作/选中/信息，绿色用于成功/安全，琥珀用于注意，红色用于危险/破坏性操作，中性灰用于禁用和次要信息。
- 大型区域优先直角或极小圆角；单行控件用克制小圆角；胶囊只用于开关和状态；菜单/弹窗仅用轻微阴影。

### 3.2 字体与图标

- 界面主字体：Noto Sans SC；数字、参数和技术数据：JetBrains Mono。
- 只引入实际使用的字重，登记来源与 SIL Open Font License。
- 主图标库优先沿用项目已有 `lucide-react`（当前版本 `0.292.0`，MIT），统一尺寸、线宽、端点和视觉重量；只有确实缺失的项目语义才补少量原创图标。

### 3.3 UI 范围

- 包含顶部菜单/工具栏/标签、左侧文件树、中央工作区、右侧数据与参数区、底部控制台、热容比/理想气体/标准模拟、结果页、设置/帮助/关于/更新、提示/警告/确认、菜单/浮层/Tooltip、空/加载/禁用/错误状态、软件自绘文件管理窗口。
- 排除 Windows 原生文件/保存窗口、系统通知、安装器、操作系统原生界面、3D 器材（唯一例外见上）、三维分子与科学可视化逻辑。

### 3.4 科学图表与动画

- 图表只改外围容器、背景、标题/坐标轴/图例/工具栏的主题一致性；保留曲线颜色、数据映射和科学关系。
- 本任务冻结所有动画实现与参数。最终只给出协调性审查建议，不修改动画代码。

### 3.5 尺寸与可读性

- 检查 1280×720、1920×1080、Windows 125%/150% 缩放、亮/暗主题、主界面、菜单、提示、侧栏、控制台、结果页与表格。
- 不允许文字裁切、控件重叠、菜单越界、弹窗按钮不可见、标签错位、异常横向溢出或高缩放信息缺失。

## 5. 阶段 0：三套 UI 方向

统一样例基线：1440×1024；空气比热容比实验、自由模式、正常实验状态；包含顶部菜单和标签、左侧文件树、中央实验工作区局部、模式按钮和常用控件、右侧数据/参数栏、底部控制台、一个二级菜单和一个普通信息提示。每套图均由亮色主界面与较小暗色局部样例组成。

### 方案 1（内部方向：平面技术控制台）

- MATLAB / Inventor 比例约 70 / 30。
- 字体层级：紧凑 12–14 px 信息层，15–17 px 区域标题，数字使用等宽字体；通过字重和对齐而非夸张字号建立层级。
- 信息密度：三套中最高，强调每屏可见信息量和快速扫描。
- 表面与边界：少量浅灰表面层，主要使用 1 px 中性分隔线；大型区域直角。
- 控件：28–30 px 高、2–3 px 圆角，选中态用工程蓝底条/细边强调。
- 特点与取舍：最像严谨的计算/控制工作台，效率高；对新用户的视觉缓冲最少。

### 方案 2（内部方向：结构化工程工作台）

- MATLAB / Inventor 比例约 50 / 50。
- 字体层级：正文 13 px，区域标题 16 px，关键数据以较稳定的 18–22 px 等宽数字显示。
- 信息密度：中等；在不改变分区的前提下给常用操作和实时数据留出更清楚的呼吸空间。
- 表面与边界：冷灰工作区、白色/近白工具面，通过标题带、表面明度和少量分隔线构造层级。
- 控件：30–32 px 高、4 px 左右圆角，按钮和输入采用统一工程蓝状态语法。
- 特点与取舍：效率与可读性最均衡，适合长时间实验教学与日常工程使用；密度不及方案 1 极致。

### 方案 3（内部方向：层级装配工作区）

- MATLAB / Inventor 比例约 35 / 65。
- 字体层级：区域标题更明确，信息仍保持紧凑；使用结构栏、工具带和分段标题强化空间归属。
- 信息密度：三套中最低但仍为工程软件密度，不做消费级卡片墙。
- 表面与边界：冷灰结构层、深浅工具带与工作区嵌套，边界最少，更多依赖明度台阶和对齐。
- 控件：30–32 px 高、3–5 px 圆角，强调机械装配式的区域秩序。
- 特点与取舍：空间层级最强、复杂界面最易定位；相较方案 1 会占用更多纵向/横向结构空间。

### 最终选择

- 状态：`已完成选择`
- 选中方案：`不采用 1 / 2 / 3；保留当前 UI 布局`
- 用户调整意见：`只调整配色、字体、字号；禁止改变 UI 大方向布局，只允许防裁切所需的局部适配。`
