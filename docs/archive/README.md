# 历史归档说明

> 状态：历史归档入口
> 建立日期：2026-08-31

本目录保存已经完成、被替代、只用于交接或只用于历史审计的材料。归档是为了保留决策背景和证据，不表示这些文件仍是当前实施入口。

## 分类

| 目录 | 内容 |
| --- | --- |
| `handoffs/` | 已完成阶段的对话交接和恢复提示 |
| `implementation-plans/` | 历史实施清单，包括当时未勾选但已失效或已完成的事项 |
| `historical-specs/` | 被当前实现或新规范替代的设计稿 |
| `design-qa/` | 历史视觉方案及截图证据 |
| `model-candidates/` | 模型迭代候选、对照图和审计记录 |
| `research-report/` | 基于旧版本生成的报告材料包和演示成果 |
| `instrument-modeling/` | 已完成或被当前实验合同替代的验证方案、交互草稿和开发路线图 |
| `drafts/` | 已被修订版替代的正文或建模草稿 |
| `snapshots/` | 基于特定日期和代码状态生成的静态盘点 |

## 使用规则

- 不从归档文档直接恢复任务；需要继续的内容先写入 `docs/ideas/improvement-ideas.md`。
- 归档文档中的分支名、提交号、版本号、本机路径和复选框均按历史现场理解。
- 当前代码或规范可以引用归档证据，但必须明确它只是来源或历史基线。
- 不为“让历史文档看起来最新”而重写其结论；必要时只增加归档状态和替代关系。
