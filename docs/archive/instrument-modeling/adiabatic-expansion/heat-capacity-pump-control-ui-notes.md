# 比热容实验打气控制与轻微压差说明

用途：记录后续演示模式 UI 可考虑加入的说明内容，重点解释为什么真实实验中不应鼓励过高压差。

## 1. 放气过程更容易被当成一次干净的快速绝热过程

压差很大时，气体喷出会更剧烈，瓶内温度和压强分布更不均匀，旋塞关闭时机也更敏感。理论上较高压差会让放气更快、更偏绝热，但同时也会引入更强的流动非均匀、过冲和阀门时机误差。

## 2. 漏气和安全误差更小

等待记录 U1、U2 的过程中，压差越大，漏气驱动力越大。高压差会让等待阶段的漏气影响更明显，也更容易进入预警或报警区域。

## 3. 仪器线性范围更可靠

传感器、导管、阀门和容器都更适合在有限范围内工作。压差太大时，读数可能仍然有值，但它不一定还处在“线性、可解释、接近真实实验”的范围内。
