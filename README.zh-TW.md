# 氣律實驗室 · Gas Laws Lab

[English](./README.md) · [简体中文](./README.zh-CN.md)

氣律實驗室是 Windows 實驗教學工作臺，將三維儀器操作、物理模擬、資料採集、逐步計算及實驗報告放在同一流程中。適用於硬球分子動力學、理想氣體關係，以及空氣和氦氣比熱容比實驗。

**目前正式版：6.5.0**

[下載 Windows 64 位元安裝程式](https://github.com/yanshi-qibixunchang/gas-laws-lab-release/releases/download/v6.5.0/heat-capacity-lab-setup-6.5.0.exe) · [版本說明與全部資產](https://github.com/yanshi-qibixunchang/gas-laws-lab-release/releases/tag/v6.5.0) · [發行核驗記錄](docs/releases/v6.5.0.md)

## 實驗內容

| 實驗 | 主要內容 |
| --- | --- |
| 標準硬球模擬 | 三維分子運動、即時圖表、統計與結果分析 |
| 理想氣體關係 | P–T、P–V、P–N 取樣、擬合、關係驗證與歷史記錄 |
| 絕熱膨脹法 | 儀器操作、壓強與溫度訊號、重複實驗、比熱容比及不確定度計算 |
| 活塞振動法 | 雙手按壓與釋放、振動採集、週期選取、高度與週期平方擬合、比熱容比及不確定度計算 |

兩種比熱容比實驗均支援**空氣／氦氣、理想／真實條件**，以及演示、引導、自由模式。介面提供簡體中文、繁體中文及英文，支援明暗主題。桌面版可依實驗支援的項目匯出 PDF 報告、PDF／PNG 圖像、CSV 及資料包。

## 6.5.0 更新重點

- 重新標定氣體參數，依事先確認的工況範圍核驗。活塞計算採用缸內平衡壓強；底層物理精度與教學答題的數值修約分開處理。
- 活塞理想模式加入內部耗散，機械能轉為氣體內能，振幅自然衰減；採集時間上限提高至 3 秒。真實模式保留已確認的損耗參數，大鬆手時間差不再被舊上限截斷。
- 加入由現場回彈錄音擬合的振動音效，聲音隨振動事件調整長度。
- 完善計算與 A、B 類不確定度說明、變數懸浮解釋、自動聚焦及捲動，統一結果框、圓角與提示樣式。
- 兩個視覺化開關使用同一種說明面板：懸停 1 秒後滑入，移出時滑出淡隱；點擊開關不會讓提示一直停留。
- 修正取樣頻率及觸發閾值過早鎖定、理想活塞儲存曲線後無法繼續測量、較大工作區結束儲存逾時及桌面匯出環境誤報。
- 絕熱膨脹法自由模式可輸入或選擇至少 3 次的實驗次數；微觀視覺化增加連續溫度色條。
- 所有實驗類型共用唯一檔名，重名追加 `(1)`、`(2)` 等編號；舊檔載入時也會檢查名稱，實驗內容保持不變。

## 安裝、升級與資料

下載正式安裝程式並依精靈操作。已安裝 **6.4.4** 的使用者可在軟體中檢查更新，也可先儲存並正常結束，再將完整安裝程式裝到原安裝目錄。

已安裝本地 **6.5.0 候選版** 的使用者，請手動下載本頁正式安裝程式覆蓋安裝；相同版本號不會觸發自動更新。升級沿用應用識別及資料目錄。舊實驗保留歷史模型、參數快照、原始記錄與計算進度，新建實驗使用現行模型。較早版本若觸發既有遷移規則，以軟體提示為準。

核心實驗在本機運行，不需註冊帳戶。網頁版與桌面版分別儲存進度，安裝不會自動搬移瀏覽器中的實驗。網頁版可體驗操作與計算；報告、圖像及表格匯出使用 Windows 桌面版。

## 模型與使用範圍

「理想／真實」表示實驗過程條件。理想條件仍需正確操作；真實條件加入已標定的熱交換、機械損耗與測量影響，不代表所有實體裝置都會得到相同結果。氦氣部分工況採用已確認的空氣誤差範圍按理論值等比例確定驗收範圍，不應視為氦氣實測曲線。

三維儀器模型負責展示與互動，數值由軟體物理模型產生。絕熱膨脹裝置參考多種教學儀器，其中包括 FD-NCD-C；本專案不是該設備的官方模擬或數位複刻。模型、音效及物理文獻來源可在軟體「關於」及 [第三方說明](THIRD_PARTY_NOTICES.md) 中查看。
