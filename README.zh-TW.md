# 氣律實驗室

[简体中文](./README.zh-CN.md) · [English](./README.md)

氣律實驗室是面向 Windows 的工程軟體工作臺，用於硬球分子動力學模擬、理想氣體關係研究，以及絕熱膨脹法和活塞振動法空氣比熱容比實驗。

目前已公開發佈的桌面穩定版是 `v6.4.2`。乾淨 Windows 環境下從 6.4.0 和 6.4.1 升級均已通過，包括重啟後的工作區還原。`main` 可以包含正式標籤之後已評審的開發內容。

- 公開下載與更新中繼資料：[gas-laws-lab-release](https://github.com/yanshi-qibixunchang/gas-laws-lab-release)
- 安全與漏洞報告規則：[SECURITY.md](./SECURITY.md)
- 協作、提交與隱私檢查：[CONTRIBUTING.md](./CONTRIBUTING.md)

## 產品範圍

- 標準硬球模擬：即時 3D 預覽、即時圖表和結果分頁。
- 理想氣體關係研究：`P-T`、`P-V`、`P-N` 取樣、驗證和歷史檢視。
- 絕熱膨脹法空氣比熱容比實驗：演示、引導和自由三種模式。
- 活塞振動法空氣比熱容比實驗：完整演示、引導和自由模式、即時採集、週期處理、擬合與結果計算。
- 桌面端本機匯出：PDF 報告、PDF/PNG 圖像、CSV 資料和中繼資料。
- 支援簡體中文、繁體中文和英文介面。

## 倉庫結構

- `src/app/`：React 應用程式進入點。
- `src/components/`：共用視覺元件。
- `src/features/`：工作臺、理想氣體、絕熱膨脹法和活塞振動法介面及編排邏輯。
- `src/domain/`：模擬和實驗計算模型。
- `src/shared/`：共用型別和工具。
- `src/i18n/`：應用程式多語言文案。
- `tests/`：硬球、理想氣體、兩種熱容比實驗、工作臺、更新器、授權材料和匯出器迴歸測試。
- `electron/`：Electron 主程序、preload 橋接和自動更新整合。
- `tools/exporter/`：Python 匯出器原始碼。
- `scripts/`、`build/`：建置、驗證、打包和安裝程式輔助指令碼。
- `public/`：執行時模型、字型、圖示、介面素材和生成的第三方授權說明。
- `resources/`：桌面圖示和生成的匯出器資源。
- `docs/`：統一文件地圖、發佈說明、理論資料、儀器建模參考、目前待辦和獨立歷史歸檔；閱讀從 `docs/README.md` 開始。

`node_modules/`、`dist/`、`release/`、`output/`、`tmp/` 等依賴或生成目錄均被 Git 忽略。

## 本機開發

依鎖定檔安裝依賴：

```powershell
npm.cmd ci
```

使用固定連接埠啟動預覽：

```powershell
npm.cmd run dev -- --host 127.0.0.1 --port 5174 --strictPort
```

預覽位址：`http://127.0.0.1:5174/`

執行常規品質檢查：

```powershell
npm.cmd run check
npm.cmd run build
```

本機執行 Electron 桌面程式：

```powershell
npm.cmd run desktop:dev
```

瀏覽器預覽涵蓋模擬器和工作臺介面；本機報告／圖像匯出依賴 Electron 橋接和匯出器環境。

## 桌面發佈邊界

不能因為 `main` 有新提交就直接製作安裝包。只有明確確定版本號，並同步更新 `package.json` 和 `package-lock.json` 後，才能進入桌面發佈流程。

正式發佈時，公開更新倉庫必須同時收到 `release/` 中版本一致的三個更新資產：

- `heat-capacity-lab-setup-<version>.exe`
- `heat-capacity-lab-setup-<version>.exe.blockmap`
- `latest.yml`

公開更新倉庫可以保留面向使用者的 README、更新日誌、安全說明和結構化發佈說明，但不能包含本倉庫原始碼、開發分支、建置輸入、本機報告、憑證或個人資訊。

## 隱私與倉庫衛生

- Git 提交統一使用 GitHub 提供的 `noreply` 郵箱。

- 任何倉庫轉為公開前，都要檢查目前檔案、全部已推送分支和標籤、提交身分、歷史刪除物件、發佈資產和二進位中繼資料。
- 開源授權和學術引用中依法或依規範保留的第三方作者屬於來源歸屬，不等同於專案成員身分；兩者必須分開判斷。

## 儀器模型邊界

絕熱膨脹法 3D 模型只作為狀態機驅動的顯示和互動載體，不能成為 `P0`、`P1`、`P2`、`U_p`、`U_T` 或 `gamma` 的資料來源。

活塞振動法模型同樣由軟體狀態驅動。執行時只綁定經過審核的節點名稱、層級、原點、運動軸、縮放、命中區域、磁吸點和相機目標；正式混合 GLB 保留原有功能契約，同時精修 v1.3 主機介面子樹。來源版本、檔案雜湊、權利狀態和最終資產摘要記錄在 `public/models/piston-oscillation/model-provenance.json`。

Blender 接入規則位於：

```text
docs/instrument-modeling/adiabatic-expansion/references/instrument/Blender模型接入规则-v4.0.1.md
```
