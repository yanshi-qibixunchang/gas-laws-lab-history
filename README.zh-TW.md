# 氣律實驗室 · Gas Laws Lab

[English](./README.md) · [简体中文](./README.zh-CN.md)

氣律實驗室是 Windows 實驗教學工作臺，將三維儀器操作、物理模擬、資料採集、逐步計算及實驗報告放在同一流程中。適用於硬球分子動力學、理想氣體關係，以及空氣和氦氣比熱容比實驗。

**目前正式版：6.5.1**

[下載 Windows 64 位元安裝程式](https://github.com/yanshi-qibixunchang/gas-laws-lab-release/releases/download/v6.5.1/heat-capacity-lab-setup-6.5.1.exe) · [版本說明與全部資產](https://github.com/yanshi-qibixunchang/gas-laws-lab-release/releases/tag/v6.5.1) · [發行核驗記錄](docs/releases/v6.5.1.md)

## 實驗內容

| 實驗 | 主要內容 |
| --- | --- |
| 標準硬球模擬 | 三維分子運動、即時圖表、統計與結果分析 |
| 理想氣體關係 | P–T、P–V、P–N 取樣、擬合、關係驗證與歷史記錄 |
| 絕熱膨脹法 | 儀器操作、壓強與溫度訊號、重複實驗、比熱容比及不確定度計算 |
| 活塞振動法 | 雙手按壓與釋放、振動採集、週期選取、高度與週期平方擬合、比熱容比及不確定度計算 |

兩種比熱容比實驗均支援**空氣／氦氣、理想／真實條件**，以及演示、引導、自由模式。介面提供簡體中文、繁體中文及英文，支援明暗主題。桌面版可依實驗支援的項目匯出 PDF 報告、PDF／PNG 圖像、CSV 及資料包。

## 6.5.1 更新重點

- 修正關閉或刪除實驗時的儲存衝突，以及零斜率練習資料導致的儲存失敗。儲存警告可點擊外部收起，新失敗仍會提示；原始曲線與答題記錄繼續保留。
- 兩種比熱容比計算視窗新增可拖動計算機，支援平方、開方、乘方、對數及科學記號。自由實驗計算完成並關閉計算視窗後自動開啟過程回顧，入口介紹全軟體只提示一次。
- 全部活塞記錄儲存後保留最後曲線，顯示本組採集已完成；補測、重開及檔案切換同步更新。兩種方法明確區分採集完成與計算完成，修正底部狀態提示。
- 修正頂板與支架連接，鎖緊後鬆手不再提前觸發下沉。密封、鬆開螺釘並解除手部支撐後才進入承重平衡。新演示與引導方案採用 70、60、50 mm，舊方案依原記錄恢復；物理參數配置不變。
- 框選採用深色十字與白色描邊，新增延時規則氣泡，明確起止波峰或波谷並整理圖表說明。移除提示左側色條，計算警告採用統一圓角淡色框，確認視窗使用對齊的純文字說明。

## 安裝、升級與資料

下載正式安裝程式並依精靈操作。已安裝 **6.4.4 或 6.5.0** 的使用者可在軟體中檢查更新，也可先儲存並正常結束，再將完整安裝程式裝到原安裝目錄。

升級沿用應用識別及資料目錄。舊實驗保留歷史模型、參數快照、原始記錄與計算進度，新建實驗使用現行模型。較早版本若觸發既有遷移規則，以軟體提示為準。

核心實驗在本機運行，不需註冊帳戶。網頁版與桌面版分別儲存進度，安裝不會自動搬移瀏覽器中的實驗。網頁版可體驗操作與計算；報告、圖像及表格匯出使用 Windows 桌面版。

## 模型與使用範圍

「理想／真實」表示實驗過程條件。理想條件仍需正確操作；真實條件加入已標定的熱交換、機械損耗與測量影響，不代表所有實體裝置都會得到相同結果。氦氣部分工況採用已確認的空氣誤差範圍按理論值等比例確定驗收範圍，不應視為氦氣實測曲線。

三維儀器模型負責展示與互動，數值由軟體物理模型產生。絕熱膨脹裝置參考多種教學儀器，其中包括 FD-NCD-C；本專案不是該設備的官方模擬或數位複刻。模型、音效及物理文獻來源可在軟體「關於」及 [第三方說明](THIRD_PARTY_NOTICES.md) 中查看。
