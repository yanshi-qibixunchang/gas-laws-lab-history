# 氣律實驗室 · Gas Laws Lab

[English](./README.md) · [简体中文](./README.zh-CN.md)

氣律實驗室是 Windows 實驗教學工作臺，將三維儀器操作、物理模擬、資料採集、逐步計算及實驗報告放在同一流程中。適用於硬球分子動力學、理想氣體關係，以及空氣和氦氣比熱容比實驗。

**目前正式版：6.5.2**

[下載 Windows 64 位元安裝程式](https://github.com/yanshi-qibixunchang/gas-laws-lab-release/releases/download/v6.5.2/heat-capacity-lab-setup-6.5.2.exe) · [版本說明與全部資產](https://github.com/yanshi-qibixunchang/gas-laws-lab-release/releases/tag/v6.5.2) · [發行核驗記錄](docs/releases/v6.5.2.md) · [原始碼 Release](https://github.com/yanshi-qibixunchang/gas-laws-lab-history/releases/tag/v6.5.2)

## 實驗內容

| 實驗 | 主要內容 |
| --- | --- |
| 標準硬球模擬 | 三維分子運動、即時圖表、統計與結果分析 |
| 理想氣體關係 | P–T、P–V、P–N 取樣、擬合、關係驗證與歷史記錄 |
| 絕熱膨脹法 | 儀器操作、壓強與溫度訊號、重複實驗、比熱容比及不確定度計算 |
| 活塞振動法 | 按壓釋放與週期測量；未知體積多高度擬合，或真實空氣已知總體積單次直接計算 |

兩種比熱容比實驗均支援**空氣／氦氣、理想／真實條件**，以及演示、引導、自由模式。介面提供簡體中文、繁體中文及英文，支援明暗主題。桌面版可依實驗支援的項目匯出 PDF 報告、PDF／PNG 圖像、CSV 及資料包。

## 6.5.2 更新重點

- 活塞自由模式新增「未知體積／已知體積」。已知體積限真實空氣，固定一次、目標高度 50 mm；使用該次儲存的加載平衡總體積、同狀態壓力及實測週期，直接計算面積、比熱容比及相對誤差，不經過擬合或不確定度計算。
- 首次進入自由模式先展開參數欄，再由三維視圖內既有按鈕確認計畫。未知體積保留 3–6 次、多高度流程；已知體積顯示固定計畫確認窗。無計畫且參數欄展開時，閒置 10 秒提示計畫入口；體積下拉選單統一字級、尺寸及鍵盤互動。
- 真實空氣自由實驗的新建、完整重設及恢復預設參數採用 0.5 s，原為 1.2 s。保留舊存檔、明確設定及凍結快照中的時長；理想條件、氦氣及演示／引導流程不變。物理參數配置沿用 6.5.0。
- 單次方法儲存來源記錄及總體積快照，重做後同步更新並使舊週期與答案失效。計算顯示、答案驗證及匯出共用顯示值；過程回顧使用總體積及週期，不因缺少擬合扣分。報告與資料表依方法輸出公式及來源，三語說明與第三方清單同步更新。兩種方法透過相對誤差比較，不預設單次實驗更準確。

## 安裝、升級與資料

下載正式安裝程式並依精靈操作。已安裝 **6.5.0 或 6.5.1** 的使用者可在軟體中檢查更新，也可先儲存並正常結束，再將完整安裝程式裝到原安裝目錄。

升級沿用應用識別及資料目錄。舊實驗保留歷史模型、參數快照、原始記錄與計算進度，新建實驗使用現行模型。較早版本若觸發既有遷移規則，以軟體提示為準。

核心實驗在本機運行，不需註冊帳戶。網頁版與桌面版分別儲存進度，安裝不會自動搬移瀏覽器中的實驗。網頁版可體驗操作與計算；報告、圖像及表格匯出使用 Windows 桌面版。

## 模型與使用範圍

「理想／真實」表示實驗過程條件。理想條件仍需正確操作；真實條件加入已標定的熱交換、機械損耗與測量影響，不代表所有實體裝置都會得到相同結果。氦氣部分工況採用已確認的空氣誤差範圍按理論值等比例確定驗收範圍，不應視為氦氣實測曲線。

三維儀器模型負責展示與互動，數值由軟體物理模型產生。絕熱膨脹裝置參考多種教學儀器，其中包括 FD-NCD-C；本專案不是該設備的官方模擬或數位複刻。模型、音效及物理文獻來源可在軟體「關於」及 [第三方說明](THIRD_PARTY_NOTICES.md) 中查看。
