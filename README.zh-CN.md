# 气律实验室 · Gas Laws Lab

[English](./README.md) · [繁體中文](./README.zh-TW.md)

气律实验室是一款 Windows 实验教学工作台，将三维仪器操作、物理模拟、数据采集、逐步计算和实验报告放在同一流程中。适用于硬球分子动力学、理想气体关系，以及空气和氦气比热容比实验。

**当前正式版：6.5.2**

[下载 Windows 64 位安装包](https://github.com/yanshi-qibixunchang/gas-laws-lab-release/releases/download/v6.5.2/heat-capacity-lab-setup-6.5.2.exe) · [版本说明与全部资产](https://github.com/yanshi-qibixunchang/gas-laws-lab-release/releases/tag/v6.5.2) · [发行核验记录](docs/releases/v6.5.2.md) · [源码 Release](https://github.com/yanshi-qibixunchang/gas-laws-lab-history/releases/tag/v6.5.2)

## 可以做哪些实验

| 实验 | 主要内容 |
| --- | --- |
| 标准硬球模拟 | 三维分子运动、实时图表、统计与结果分析 |
| 理想气体关系 | P–T、P–V、P–N 采样、拟合、关系验证与历史记录 |
| 绝热膨胀法 | 仪器操作、压强与温度信号、重复实验、比热容比及不确定度计算 |
| 活塞振动法 | 按压释放与周期测量；未知体积多高度拟合，或真实空气已知总体积单次直接计算 |

两种比热容比实验均支持**空气／氦气、理想／真实条件**，以及演示、引导、自由模式。界面提供简体中文、繁体中文和英文，支持明暗主题。桌面版可按实验支持的项目导出 PDF 报告、PDF／PNG 图像、CSV 和数据包。

## 6.5.2 更新重点

- 活塞自由模式新增“未知体积／已知体积”。已知体积限真实空气，固定一次、目标高度 50 mm；使用该次保存的加载平衡总体积、同状态压力和实测周期，直接计算面积、比热容比及相对误差，不经过拟合或不确定度计算。
- 首次进入自由模式先展开参数栏，再由三维视图内现有按钮确认计划。未知体积保留 3–6 次、多高度流程；已知体积显示固定计划确认窗。无计划且参数栏展开时，闲置 10 秒提示计划入口；体积下拉框统一字号、尺寸及键盘交互。
- 真实空气自由实验的新建、完整重置及恢复默认参数采用 0.5 s，原为 1.2 s。保留旧存档、明确设置和冻结快照中的时长；理想条件、氦气及演示／引导流程不变。物理参数配置沿用 6.5.0。
- 单次方法保存来源记录及总体积快照，重做后同步更新并使旧周期与答案失效。计算显示、答案校验与导出共用显示值；过程回顾使用总体积和周期，不因缺少拟合扣分。报告及数据表按方法输出公式与来源，三语说明与第三方清单同步更新。两种方法通过相对误差比较，不预设单次实验更准确。

## 安装、升级与数据

1. 下载正式安装包，按向导完成安装。
2. 已安装 6.5.0 或 6.5.1 的用户可在软件中检查更新，也可先保存并正常退出，再将完整安装包装到原安装目录。
3. 升级沿用应用身份和资料目录。旧实验保留历史模型、参数快照、原始记录和计算进度；新建实验使用现行模型。早期版本若触发既有迁移规则，以软件提示为准。

实验和报告默认保存在本机，无需注册账户。网页版与桌面版分别保存进度，下载安装不会自动迁移浏览器中的实验。网页版可体验操作和计算，报告、图像及表格导出使用 Windows 桌面版。

## 模型与使用边界

“理想／真实”表示实验过程条件。理想条件仍需正确操作；真实条件加入已标定的热交换、机械损耗和测量影响，不代表所有实物装置都会得到相同结果。氦气部分工况采用已确认的空气误差范围按理论值等比例确定验收范围，不应当作氦气实测曲线。

仪器三维模型负责展示和交互，数值由软件物理模型产生。绝热膨胀装置参考了多种教学仪器，其中包括 FD-NCD-C；本项目不是该设备的官方仿真或数字复刻。模型、声音和物理文献来源可在软件“关于”及 [第三方说明](THIRD_PARTY_NOTICES.md) 中查看。
