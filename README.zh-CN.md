# 气律实验室

[English](./README.md) · [繁體中文](./README.zh-TW.md)

气律实验室是面向 Windows 的工程软件工作台，用于硬球分子动力学模拟、理想气体关系研究，以及绝热膨胀法和活塞振动法空气比热容比实验。

当前已公开发布的桌面稳定版是 `v6.4.0`。`main` 可以包含该标签之后已经评审的开发内容；只有在明确确定版本号、同步更新版本文件并发布完整更新资产后，主线源码才构成新的桌面版本。

- 公开下载与更新元数据：[gas-laws-lab-release](https://github.com/yanshi-qibixunchang/gas-laws-lab-release)
- 安全与漏洞报告规则：[SECURITY.md](./SECURITY.md)
- 协作、提交与隐私检查：[CONTRIBUTING.md](./CONTRIBUTING.md)

## 产品范围

- 标准硬球模拟：实时 3D 预览、实时图表和结果标签页。
- 理想气体关系研究：`P-T`、`P-V`、`P-N` 采样、验证和历史视图。
- 绝热膨胀法空气比热容比实验：演示、引导和自由三种模式。
- 活塞振动法空气比热容比实验：完整演示、引导和自由模式、实时采集、周期处理、拟合与结果计算。
- 桌面端本地导出：PDF 报告、PDF/PNG 图像、CSV 数据和元数据。
- 支持简体中文、繁体中文和英文界面。

## 当前源码重点

- 工作台已按职责拆分为命令、设置、更新器、参数、持久化和实验功能模块。
- 两种热容比实验均与标准模拟、理想气体文件保持明确的运行态和持久化边界。
- `v6.4.0` 为活塞振动法自由模式补齐完整的过程回顾与评分工作区。每次实验分别呈现仪器操作时间条、保存曲线、周期选择结果和可展开的评分证据，并可按“第几次”统一切换；面向用户的界面不再使用底层 `Run` 名称。
- `v6.4.0` 新增活塞振动法本地 PDF 实验报告。报告沿用绝热膨胀法的既有排版，只呈现实验文件信息、实际记录数据、计算结果、过程证据和评分摘要，不额外加入独立的原理或公式章节。
- `v6.4.0` 新增与另一热容比实验一致的自由模式参数栏。环境压强、环境温度、采样率、触发线和键位可视化直接可见；热过程、传感器、双手松手差和尾段观测参数置于需确认风险的高级设置中，并在首条正式曲线保存后随实验文件固化。
- `v6.4.0` 让下降触发线的允许范围随环境压强同步变化，同时保留标准大气压下已经审核的窗口。参数修改会贯通实验快照、物理过程、采集、处理、回顾和导出，不会重新解释旧文件。
- `v6.3.1` 完成活塞振动法自由模式的数据质量闭环：区分整条记录不可用与局部框选过窄，只自动重做受影响 Run，保留排除尝试作为证据，并将 `t₁ / t₂ / T` 和最终三项计算改为可回改的统一校验。
- `v6.3.1` 加入按实验种子固定的尾段不规则观测和短时双手松手差损耗；新实验的虚拟手按压与自由振动统一使用版本化 `1.1 N·s/m` 等效损耗，旧存档中的 `0.434 N·s/m` 及其他受支持快照保持原义。
- `v6.3.1` 通过 `0.300 s` 呈现延迟和前 `0.400 s` 物理曲线的 `0.55` 倍显示节奏，为暂停操作留出反应时间，同时不改变采样点和计算。未触发后再次按压的实时监测、偶发音效响应以及统一校验按钮溢出也已修复。
- `v6.3.0` 建立连续热过程、压力传感、按压与虚拟双手采集链，补齐活塞交互音效，并完成引导步骤、`0.500 s` 冻结、参数输入、旋钮方向提示和演示节奏修复；这些能力继续作为本补丁的基础。
- `v6.2.1` 是此前的活塞稳定性补丁，主要修复首次采集、周期框选、回弹验证、显示恢复与跨重启自由模式数据。
- `v6.2.0` 完成活塞振动法自由模式：支持 3–6 次实验计划、系统与 `10–80 mm` 自定义高度、按高度推进、会话恢复、逐次采集设置、动态监测、重做与整轮重置、周期核验、拟合和自动进入计算。
- `v6.2.0` 同时统一两种热容比实验的次数与进度组件，按模式动态显示左侧资料入口，统一新增界面的配色与菜单交互，修复演示和引导操作，并让活塞三种模式共用同一套可保存的真实加载平衡模型。松开锁紧螺钉后会记录 `0.2 s` 单向下沉，精确真实高度只在后台参与物理计算。
- `v6.1.1` 新增通过审核的活塞仪器模型、电源门控实时数据、完整演示与引导流程，以及严格引导顺序。
- `v5.3.1` 完成绝热膨胀法多组实验、实验次数自动推进、按次/按组重新开始、整组过程回顾与评分，以及报告、图表和实验包导出的完整闭环。
- `v5.2.2` 修复工作区已经恢复完成后，开屏仍停留在 100% 无法进入软件的问题。
- `v5.2.1` 新增完整的三语言首次使用流程、可重录动态产品介绍、统一工程软件提示体系、教程会话恢复，以及由真实工作区恢复进度驱动的开屏动画。
- `v5.2.0` 将经过回读校验的 V3 保存移出界面主线程，为长时间 Free 轨迹设置硬上限，并无损兼容 4.2.3 和 5.1.1 的有效工作区，同时保持既有用户资料目录和更新身份不变。已撤回的 5.1.2 废版所写实验数据不在兼容承诺内。
- 桌面发布目标只指向公开更新仓库，源码仓库不是更新通道。

## 仓库结构

- `src/app/`：React 应用入口。
- `src/components/`：共享可视化组件。
- `src/features/`：工作台、理想气体、绝热膨胀法和活塞振动法界面及编排逻辑。
- `src/domain/`：模拟和实验计算模型。
- `src/shared/`：共享类型和工具。
- `src/i18n/`：应用多语言文案。
- `tests/`：硬球、理想气体、两种热容比实验、工作台、更新器、许可材料和导出器回归测试。
- `electron/`：Electron 主进程、preload 桥接和自动更新集成。
- `tools/exporter/`：Python 导出器源码。
- `scripts/`、`build/`：构建、校验、打包和安装器辅助脚本。
- `public/`：运行时模型、字体、图标、界面素材和生成的第三方许可说明。
- `resources/`：桌面图标和生成的导出器资源。
- `docs/`：统一文档地图、发布说明、理论资料、仪器建模参考、当前待办和独立历史归档；阅读从 `docs/README.md` 开始。

`node_modules/`、`dist/`、`release/`、`output/`、`tmp/` 等依赖或生成目录均被 Git 忽略。

## 本地开发

按锁文件安装依赖：

```powershell
npm.cmd ci
```

使用固定端口启动预览：

```powershell
npm.cmd run dev -- --host 127.0.0.1 --port 5174 --strictPort
```

预览地址：`http://127.0.0.1:5174/`

运行常规质量检查：

```powershell
npm.cmd run check
npm.cmd run build
```

本地运行 Electron 桌面程序：

```powershell
npm.cmd run desktop:dev
```

浏览器预览覆盖模拟器和工作台界面；本地报告/图像导出依赖 Electron 桥接和导出器环境。

## 桌面发布边界

不能因为 `main` 有新提交就直接制作安装包。只有明确确定版本号，并同步更新 `package.json` 和 `package-lock.json` 后，才能进入桌面发布流程。

正式发布时，公开更新仓库必须同时收到 `release/` 中版本一致的三个更新资产：

- `heat-capacity-lab-setup-<version>.exe`
- `heat-capacity-lab-setup-<version>.exe.blockmap`
- `latest.yml`

公开更新仓库可以保留面向用户的 README、更新日志、安全说明和结构化发布说明，但不能包含本仓库源码、开发分支、构建输入、本地报告、凭据或个人信息。

## 隐私与仓库卫生

- Git 提交统一使用 GitHub 提供的 `noreply` 邮箱。
- 禁止提交凭据、`.env` 文件、个人联系方式、参赛者姓名、学校信息、用户绝对路径，以及文档/图片作者元数据。
- 任何仓库转为公开前，都要检查当前文件、全部已推送分支和标签、提交身份、历史删除对象、发布资产和二进制元数据。
- 开源许可证和学术引用中依法或规范保留的第三方作者属于来源归属，不等同于项目成员身份；两者必须分开判断。

## 仪器模型边界

绝热膨胀法 3D 模型只作为状态机驱动的显示和交互载体，不能成为 `P0`、`P1`、`P2`、`U_p`、`U_T` 或 `gamma` 的数据源。

活塞振动法模型同样由软件状态驱动。运行时只绑定经过审核的节点名称、层级、原点、运动轴、缩放、命中区域、磁吸点和相机目标；正式混合 GLB 保留原有功能契约，同时精修 v1.3 主机界面子树。来源版本、文件哈希、权利状态和最终资产摘要记录在 `public/models/piston-oscillation/model-provenance.json`。
